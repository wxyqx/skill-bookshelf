## 逐条结果

### ✅ should-trigger-01
- **Prompt**: "最近总觉得脑子转不动，注意力不集中，老是忘事，是不是年纪大了变笨了"
- **判断**: 应该触发
- **理由**: "脑子转不动""注意力不集中""忘事"是带宽不足的典型症状，且用户自我归因为"变笨"（特质），正需要带宽理论的解释（状态而非特质）
- **预期匹配**: ✅ 匹配

### ✅ should-trigger-02
- **Prompt**: "我发现早上做事情效率特别高，一到下午就不行了，怎么回事"
- **判断**: 应该触发
- **理由**: 用户观察到了效率的时间波动，这正是带宽周期性波动的表现
- **预期匹配**: ✅ 匹配

### ✅ should-trigger-03
- **Prompt**: "为什么我压力一大就管不住嘴，明知道要减肥还是忍不住吃垃圾食品"
- **判断**: 应该触发
- **理由**: 自控力下降（执行控制力不足）是带宽负担的核心表现之一
- **预期匹配**: ✅ 匹配

### ✅ should-not-trigger-01
- **Prompt**: "我连续熬了三个通宵，困得不行"
- **判断**: 不应触发
- **理由**: 纯生理睡眠不足，最需要的是睡觉。带宽管理是认知层面的优化，不能替代休息
- **预期匹配**: ✅ 匹配

### ⚠️ should-not-trigger-02 (跨skill混淆)
- **Prompt**: "项目明天就上线了，我总觉得哪里漏了什么但想不起来"
- **判断**: 容易误触发
- **理由**: "想不起来"可能被理解为带宽不足导致的记忆问题，但实际上是管窥导致的注意力盲区。两个 skill 确实有重叠，需要在 description 中明确区分
- **预期匹配**: ⚠️ 部分匹配（与 tunneling-decision-check 存在边界模糊）

### ✅ edge-01
- **Prompt**: "我最近心情很差，什么都不想做"
- **判断**: 边界——需要先判断严重程度
- **理由**: 情绪低落可能是压力导致的带宽消耗（适用），也可能是临床抑郁（不适用，需专业帮助）。skill 应该有严重程度筛查
- **预期匹配**: ✅ 匹配

## 失败分析与改进

### 问题：与 tunneling-decision-check 的边界模糊
- **原因**: 带宽不足和管窥经常同时出现，用户描述也经常重叠
- **改进方案**: 明确两个 skill 的触发分工：
  - 带宽管理："整体状态差""效率低""自控力差""忘事" → 容量问题
  - 管窥校验："当时怎么没想到""光顾着A忘了B""视野窄" → 方向问题
