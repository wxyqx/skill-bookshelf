# 借用警觉清单

## R — 原文 (Reading)

> "当我们有了管窥之见时，借用就会超越得失均衡的限度。
> 当面临稀缺状况时，我们的借用，从长期来看通常是不合理的。
> 稀缺致使我们借用，并且让我们在稀缺的泥潭中越陷越深。
> 借用，从短期来看可能有用，但从长远来看，我们会为此付出代价。"
>
> — 塞德希尔·穆来纳森 & 埃尔德·沙菲尔，《稀缺》第5章、第6章

---

## I — 方法论骨架 (Interpretation)

"借用"就是向未来透支资源来解决当下之急。金钱上的借贷、时间上的拖延、
健康上的透支、精力上的熬夜，本质上都是借用。

管窥心态下，借用特别有吸引力——当下之急在管子里被放大，
借用的未来成本在管子外被低估。因此，人会系统性地过度借用：
每次都觉得"就这一次""先渡过这个难关"，但利息像复利一样累积，
最终把人拖入稀缺陷阱。

借用警觉清单的作用是：**在你最想借用的时候（管窥最严重、判断力最差的时候），
提供一个强制检查的流程**，帮你把管子外的"未来成本"拉回视野，
做出更理性的判断。借用不全是坏事，但必须看清真实代价后再决定。

## A1 — 书中的应用 (Past Application)

### 案例 1：桑德拉工薪日贷款陷阱
- **问题**: 桑德拉因丈夫失业经济紧张，用工薪日贷款续保车险，
  觉得"就这一次，先渡过难关"。
- **方法论的使用**: 管窥心态下，她只看到当下必须付的账单（管子里），
  而低估了贷款的长期成本（管子外）。每笔贷款的利息看起来不多，
  但累积起来是天文数字。6个月后她同时欠6笔贷款，每月手续费495-600美元，
  最终破产。这就是借用的复利效应——每次借用都让未来更稀缺，
  未来更稀缺时又更想借用，形成正反馈循环。
- **结论**: 借用的吸引力在管窥下被放大，而代价被低估。
  "就这一次"是借用陷阱的标准开场白。
- **结果**: 从一笔小额贷款开始，6个月后彻底破产、车被收回、被驱逐。

### 案例 2：家庭问答游戏实验
- **问题**: 稀缺状态下的人是否会过度借用？借用的净效应是正还是负？
- **方法论的使用**: 基于《家庭问答》游戏的实验室实验：玩家在有限时间内答题，
  "穷人"时间少，"富人"时间多。玩家可以"借用"下一轮的时间，
  但利息是100%（借1秒还2秒）。结果：穷人更专注，每秒钟得分更高（专注红利）；
  但他们也借用得更多，而高利息的借用最终让他们总得分更低。
  当取消借用功能时，穷人的分数比有借用时高了60%。
- **结论**: 借用在管窥心态下看起来很有吸引力，但从全局看是净损失。
  穷人的专注红利，还不足以弥补借用的利息损失。
- **结果**: 实验室中直接验证了借用对稀缺人群的伤害。
  没有借用时，穷人的表现反而更好。

### 案例 3：印度小贩日息贷款循环
- **问题**: 印度金奈街头小贩每天借1000卢比进货，日息5%，
  理论上每天省5卢比50天就能摆脱债务，但平均借贷9.5年。
- **方法论的使用**: 为什么这么简单的数学题他们算不过来？
  不是笨，而是管窥——每天想的都是"今天的货从哪来""今天的利息怎么还"，
  完全没有带宽去想"50天后我就能自由了"。50天的自由在管子外面，
  今天的1000卢比货款在管子里面。管子里的事永远赢。
  日息5%看起来不多，但年化利率是惊人的1800%——但管窥心态下，
  人算的是"今天能不能过"，不是"年化利率多少"。
- **结论**: 管窥导致短视，让人只看今天不看明天，
  因此会接受从长期看极其不合理的借用条件。
- **结果**: 平均借贷9.5年，本可以50天解决的问题拖了近十年。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **即将做出借用决策时** — 用户正在考虑借钱、刷信用卡、
   拖延任务、熬夜赶工，觉得"先解决眼前的再说"。
   这是最需要激活本 skill 的时刻——因为此时管窥最严重，判断力最差。
2. **已经有多个借用在周转时** — 用户在多个贷款/多个拖延项目之间
   "拆东墙补西墙"，需要评估整体状况和逃离路径。
3. **回顾一个借用决策时** — 用户事后觉得"当时不该借/不该拖"，
   需要分析为什么会做出那个决定，以及如何避免下次重犯。
4. **设计产品/政策时** — 用户是金融产品设计者、信贷机构、
   政策制定者，需要考虑如何防止用户过度借贷。

### 语言信号 (用户的话里出现这些就应激活)

- "先借点再说" / "周转一下"
- "先渡过这个难关" / "救个急"
- "就这一次" / "下次一定还"
- "拆东墙补西墙" / "倒卡"
- "以后再说" / "先放一放"（指拖延任务）
- "今晚熬夜赶完"（时间借用）
- "利息不高" / "没多少钱"
- "payday loan / 工薪日贷款"

### 与相邻 skill 的区分

- 与 `tunneling-decision-check` 的区别：本 skill 是管窥决策校验法
  在"借用行为"这一特定场景下的应用。管窥校验是通用的决策盲区检查，
  借用警觉清单是针对借用这一特定高风险行为的深度检查清单。
  如果问题明确涉及借钱/拖延/透支，用本 skill 更精准。
- 与 `scarcity-trap-escape` 的区别：本 skill 是单点工具
  （评估单次借用决策），稀缺陷阱逃离是系统方案（如何整体逃离陷阱）。
  借用警觉是逃离路线图中"第一步：止血"的核心工具。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **识别：这是借用吗？**
   - 完成标准：确认当前行为是不是"向未来透支资源"
   - 借用的各种形式（帮用户识别，有些借用很隐蔽）：
     - **金钱借用**: 贷款、信用卡分期、向朋友借钱、透支花呗/借呗、拖欠账单
     - **时间借用**: 拖延任务、加班赶工、牺牲睡眠/休息时间
     - **质量借用**: 跳过测试/审查、偷工减料、技术债务
     - **健康借用**: 熬夜、不吃东西、带病工作、透支体力
     - **关系借用**: 消耗人情、爽约、把压力转嫁他人
   - 判断标准：如果你现在做的事，会让未来的你付出更多代价/时间/钱，
     那就是借用。

2. **计算：真实利息是多少？**
   - 完成标准：帮用户算清借用的全部成本，而不只是表面上的利息
   - 检查清单（逐一确认）：
     a) **直接利息/成本**：明面上的利息、手续费、滞纳金是多少？
     b) **复利效应**：如果不能按时还，利滚利后的总成本是多少？
        （日息1%看起来不多，年化是3678%！）
     c) **机会成本**：因为要还债/补坑，未来会错过什么机会？
     d) **带宽成本**：债务/拖延带来的心理压力，会消耗多少带宽？
        （带宽负担相当于降13-14分IQ，这也是成本）
     e) **连锁反应**：这次借用会不会开启一个恶性循环？
        （如：拖延这个任务→导致下一个任务也拖延→整体项目延期）
   - 关键提醒：管窥心态下，你会系统性低估这些成本——
     因为它们都在"管子外面"。现在花5分钟算清楚，未来省5个月的痛苦。

3. **寻找：有没有不借用的替代方案？**
   - 完成标准：至少想出 2-3 个不借用的替代方案
   - 常见替代方向：
     a) **减少需求**：能不能不做这件事？能不能降低标准？
        （不一定要完美完成，"过得去"可能就够了）
     b) **动用余闲**：有没有储蓄/缓冲时间/备用资源可以用？
        （余闲就是为此而存在的！）
     c) **寻求帮助**：能不能找人帮忙/延长deadline/协商条件？
        （大多数人愿意通融，只要你提前说）
     d) **重新排序**：能不能调整优先级，先做更重要的？
        （有些事拖着不做也没什么大不了）
     e) **分拆任务**：能不能先做一部分，而不是全部？
        （部分交付 > 拖延到最后）
   - 判停条件：如果能找到不借用的替代方案，且代价低于借用的真实成本，
     就选替代方案。

4. **决策：借还是不借？**
   - 完成标准：做出明确决策，并设定边界
   - 如果决定借：
     a) 明确还款/补坑计划（具体日期、具体金额）
     b) 设定"止损线"——最多借多少，超过就坚决停止
     c) 找一个"监督人"——朋友/家人/同事，帮你盯着不要越借越多
     d) 设置提醒——还款日前几天就提醒，不要产生滞纳金
   - 如果决定不借：
     a) 立即执行替代方案
     b) 记录下这次"成功抵制借用"的经历，下次想借的时候翻出来看
   - 关键原则：借用不一定都是坏事（如房贷、教育贷款是良性债务），
     但必须是**看清全部成本后的理性选择**，而不是管窥下的冲动决定。

5. **事后：如果已经借了很多，怎么办？**
   - 完成标准：如果用户已经陷入借用循环，引导到稀缺陷阱逃离路线图
   - 判断信号：
     a) 同时有3笔以上的借款/拖延项目
     b) 在多个债务/任务之间周转（拆东墙补西墙）
     c) 每个月/周都在还，但总债务/总拖延不见减少
   - 如果符合以上条件，告诉用户：你可能已经落入稀缺陷阱，
     需要的不是单次借用决策，而是系统性的逃离方案。
     建议使用 `scarcity-trap-escape` skill。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **紧急求生场景** — 生命危险、紧急医疗等真正的生死关头，
  先活下来再说，不要在这种时候算"利息是多少"。
- **经过深思熟虑的良性投资** — 房贷、教育贷款、有明确回报预期的投资，
  这些是经过理性计算的，不是管窥下的冲动借用，本 skill 不适用。
- **用户已经下定决心且清楚后果** — 如果用户已经仔细考虑过，
  清楚全部成本和风险，仍然决定借用，那就尊重其选择，不必反复劝说。

### 作者在书中警告的失败模式

- **"就这一次"的幻觉** — 几乎每一个陷入债务陷阱的人，
  一开始都觉得"就这一次"。但借用会改变你的资源状态，
  让下一次借用变得更有必要。一旦开了头，就很容易滑下去。
- **低估复利效应** — 人类大脑天生不擅长理解指数增长。
  日息5%看起来不多，但年化是1800%。"没多少利息"是管窥心态下的典型错觉。
  一定要算总账，不要只看每次的利息。
- **借用时觉得"以后会更好"** — 管窥心态下，人会天真地认为
  "现在是特殊情况，以后就好了"。但实际上，如果你现在靠借用度日，
  以后只会更难——因为借用的利息会让未来更稀缺。
  不要假设未来会自己变好，要假设未来会更糟（因为有利息）。

### 作者的盲点 / 时代局限

- **对"必要借用"和"过度借用"的界线讨论不足** — 不是所有借用都是坏事。
  房贷、助学贷款、企业经营性贷款，这些是现代经济的正常组成部分。
  本书主要强调借用的危险性，对"如何区分良性和恶性借用"的讨论不够系统。
- **结构性因素** — 本书主要从个人心理层面分析借用行为，
  对放贷者的主动设计（如工薪日贷款专门瞄准穷人、信用卡设计鼓励最低还款）
  讨论不足。很多人落入债务陷阱，不完全是个人管窥的问题，
  也是产品设计有意为之的结果。
- **数字时代的新借用形式** — 本书出版时，花呗、借呗、"先用后付"等
  互联网消费信贷还不普及。今天，借用的门槛更低、更隐蔽、更容易冲动，
  借用陷阱的风险比十年前大得多。

### 容易混淆的邻近方法论

- **"债务管理" (Debt Management)** — 债务管理是更宽泛的领域，
  包括债务合并、债务协商、信用修复等。借用警觉清单是从稀缺心理学角度
  出发的、针对"是否应该借"的决策工具，是债务管理的"入口端"。
- **"延迟满足" (Delayed Gratification)** — 延迟满足是心理学概念，
  强调为长远利益抵制眼前诱惑。借用警觉与延迟满足相关，但角度不同：
  延迟满足是"意志力/自律"视角，借用警觉是"认知机制/管窥"视角——
  不是你意志力差，而是管窥机制让你低估了未来成本。
  因此解决方案是"用流程检查弥补认知盲区"，而不是"增强意志力"。
