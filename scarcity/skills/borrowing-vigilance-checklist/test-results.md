## 逐条结果

### ✅ should-trigger-01
- **Prompt**: "这个月钱不够花了，想借点网贷周转一下，下个月就还，应该可以吧"
- **判断**: 应该触发
- **理由**: "借点网贷""周转一下""下个月就还"是典型的管窥下借用冲动，强触发信号
- **预期匹配**: ✅ 匹配

### ✅ should-trigger-02
- **Prompt**: "项目来不及了，我打算先赶个粗糙版本上线，后面再优化，你觉得呢"
- **判断**: 应该触发
- **理由**: "先上线后优化"是时间维度的借用（技术债务），需要评估返工成本
- **预期匹配**: ✅ 匹配

### ✅ should-trigger-03
- **Prompt**: "用信用卡分期买个东西，每月才还几百块，感觉挺划算的"
- **判断**: 应该触发
- **理由**: "每月才还几百"是典型的低估总成本的表述，分期的真实利率往往被低估
- **预期匹配**: ✅ 匹配

### ✅ should-not-trigger-01
- **Prompt**: "帮我比较一下房贷的几种还款方式"
- **判断**: 不应触发
- **理由**: 房贷是经过深思熟虑的良性债务/投资性借贷，不是管窥下的冲动借用。借用警觉针对的是"先渡难关再说"的短期冲动借用
- **预期匹配**: ✅ 匹配

### ✅ should-not-trigger-02 (跨skill混淆)
- **Prompt**: "我感觉越忙越乱，一直在赶进度，走不出来了"
- **判断**: 不应触发（应触发 scarcity-trap-escape）
- **理由**: 用户已经陷入系统性循环了，需要的是完整的逃离路线图，而不是单次借用决策的检查清单
- **预期匹配**: ✅ 匹配

### ✅ edge-01
- **Prompt**: "我想贷款创业，你觉得可行吗"
- **判断**: 边界——投资性借贷 vs 冲动借用
- **理由**: 如果有详细商业计划、经过理性计算，属于投资性借贷（不适用）；如果是冲动决定、没算过账、"先做起来再说"，则适用借用警觉。需要先了解更多信息
- **预期匹配**: ✅ 匹配

## 分析

本 skill 的 trigger 区分度很好，因为"借钱""先上后优化""分期"等信号
非常明确。主要边界是"良性投资性借贷"和"冲动借用"的区分，
skill 中已经包含了计算真实成本、寻找替代方案等步骤来帮助判断。
