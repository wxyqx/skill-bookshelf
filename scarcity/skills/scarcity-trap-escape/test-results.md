## 逐条结果

### ✅ should-trigger-01
- **Prompt**: "我感觉越忙越穷越穷越忙，永远在赶进度，好像陷进去了走不出来"
- **判断**: 应该触发
- **理由**: "越忙越穷""恶性循环""走不出来"是稀缺陷阱的最强触发信号
- **预期匹配**: ✅ 匹配

### ✅ should-trigger-02
- **Prompt**: "我同时欠着好几张信用卡，每个月都在倒卡，越还欠得越多，怎么办"
- **判断**: 应该触发
- **理由**: "好几张信用卡""倒卡""越还越多"是典型的债务陷阱，稀缺陷阱的财务形态
- **预期匹配**: ✅ 匹配

### ✅ should-trigger-03
- **Prompt**: "我们团队永远在救火，问题一个接一个，永远没时间做改进，怎么打破这个循环"
- **判断**: 应该触发
- **理由**: "永远在救火""没时间做改进""打破循环"是组织层面稀缺陷阱的典型表述
- **预期匹配**: ✅ 匹配

### ✅ should-not-trigger-01
- **Prompt**: "我最近有点忙，过了这阵就好了"
- **判断**: 不应触发
- **理由**: 暂时的、短期的压力不是稀缺陷阱。稀缺陷阱的核心是"循环"和"走不出来"，用户说"过了这阵就好了"说明不认为是循环
- **预期匹配**: ✅ 匹配

### ✅ should-not-trigger-02 (跨skill混淆)
- **Prompt**: "我想借点钱周转一下，帮我看看合不合算"
- **判断**: 不应触发（应触发 borrowing-vigilance-checklist）
- **理由**: 单次借用决策，用借用警觉清单即可。稀缺陷阱是系统性方案，适用于已经陷入循环的情况
- **预期匹配**: ✅ 匹配

### ✅ edge-01
- **Prompt**: "我刚失业了，存款不多，有点慌"
- **判断**: 边界——单次危机 vs 长期陷阱
- **理由**: 刚遇到挫折，还没形成循环。此时重点是如何用好现有资源（余闲/充裕期思路），而不是"逃离陷阱"。如果几个月后还没找到工作并开始借债，则进入陷阱
- **预期匹配**: ✅ 匹配

## 分析

本 skill 的 trigger 区分度很好，因为"恶性循环""走不出来""永远在救火"
等表述非常独特，不容易与其他 skill 混淆。
这是一个"重度"skill，只在用户明确表示陷入循环时触发。
