      - 第10章：储蓄因落在管子外面被忽略（个人理财领域）
    reasoning: |

  V2_predictive_power:
    passed: true
    novel_question: "一个正在赶产品上线 deadline 的创业团队，最可能忽略什么重要事情？"
    derived_answer: |
      根据管窥机制预测：上线日期（紧迫）占据管子视野，团队最可能忽略
      1) 代码质量和技术债务（重要但不紧急，在管子外）；
      2) 用户调研和产品战略规划（遥远，在管子外）；
      3) 团队健康和 burnout 预防（长期影响，在管子外）；
      4) 安全审查和合规事项（"不会那么倒霉"，在管子外）。
      验证方式：在 deadline 前主动拉一个"管子外检查清单"会议，
      专门讨论不在当前紧迫任务列表上的重要事项。
  V3_exclusivity:
    passed: true
    why_not_common: |
      常识说法是"忙的时候要分清主次""不要因小失大"——这是道德/态度层面的建议，
      暗示人可以靠意志力选择关注什么。但本书的洞见是反直觉的：
      管窥是潜意识的目标抑制机制，不由意识控制——不是你"选择了忽略"，
      而是你"根本看不到"。因此解决方案不是"更努力专注"，
      而是"在做决策前主动检查盲区"（改变流程而非改变态度）。

      - 第2章："心形—花形"测验（执行控制力下降）
      - 第7章：穷人的"无能"是带宽负担的结果（多领域表现下降）
      - 第6章：孤独者社交发挥失常（社交稀缺→带宽消耗）
    reasoning: |
      带宽负担效应在金钱稀缺、时间稀缺、社交稀缺等多个独立场景中被验证，
      且有实验室实验和田野实验的双重证据，因果关系明确。
  V2_predictive_power:
    passed: true
    novel_question: "为什么连续加班一周的程序员，写出的 bug 反而更多？"
    derived_answer: |
      用带宽理论分析：不是因为"累了"（生理疲劳可以靠咖啡暂时缓解），
      而是因为时间稀缺导致带宽负担——执行控制力下降，具体表现为：
      1) 工作记忆容量减少，难以同时追踪多个变量的关系；
      2) 抑制控制减弱，更容易跳过边界检查和错误处理；
      3) 认知灵活性下降，难以切换视角发现自己代码的问题。
      推论：让加班程序员写代码是低效率的，但让他们做机械性重复工作
      （如数据录入、简单修复）影响较小。重要代码和代码审查
      应该安排在带宽充足的时段（上午、项目初期）。
  V3_exclusivity:
    passed: true
    why_not_common: |
      常识是"压力大表现差""累了容易出错"——模糊的定性描述。
      本书的独特贡献：1) 量化了影响幅度（13-14分IQ，相当于一夜没睡）；
      2) 区分了两种带宽（流体智力 vs 执行控制力）及其不同影响；
      3) 指出这是状态而非特质——同一个人在不同状态下差异巨大；
      4) 最反直觉：影响是潜意识的，当事人自己可能意识不到。
      这些都不是"聪明人也能想到"的常识。

      - 第9章：NASA满负荷赶进度导致探测器坠毁（航天组织）
      - 第9章：道路占用率超85%就堵车（交通系统）
    reasoning: |
      余闲的必要性在个人财务、组织管理、交通系统、项目管理等至少5个独立领域
      得到验证，且结论一致：100%利用的系统是脆弱的，适当余闲反而提升整体效率。
  V2_predictive_power:
    passed: true
    novel_question: "为什么客服中心把坐席利用率从90%提高到95%后，客户满意度反而下降了？"
    derived_answer: |
      用余闲理论预测：坐席利用率从90%→95%，意味着余闲从10%→5%。
      当来电量出现正常波动（如突发咨询高峰）时，没有余闲吸收波动，
      导致：1) 排队等待时间变长；2) 客服为了赶时间缩短每个电话，
      服务质量下降；3) 客服处于持续救火状态，带宽负担加重，
      更容易出错和态度不好。推论：最优利用率不是越高越好，
      而应该根据波动大小预留足够余闲——波动越大，需要的余闲越多。
  V3_exclusivity:
    passed: true
    why_not_common: |
      常识是"效率至上""资源要充分利用""别浪费时间/钱"。
      本书的洞见完全反直觉：余闲不是浪费，是系统正常运转的必需品；
      追求100%利用率反而降低整体效率和产出；主动留余闲是更高级的管理。
      这与大多数人的直觉和"勤奋文化"直接冲突。

      - 第10章：把警醒型行为转为一次性行动（行为设计）
      - 第8章：默认选项设计（政策/产品设计）
      - 第10章：截止日期和节点设置（时间管理）
    reasoning: |
      "把重要的事拉进管子视野"这一原则在储蓄、教育、行为设计、政策、
      时间管理等多个独立场景中被验证，核心逻辑一致：
      管窥下管子外的激励/事项无效，必须让它进入当下视野。
  V2_predictive_power:
    passed: true
    novel_question: "如何让忙碌的职场人真正坚持每周健身？"
    derived_answer: |
      用拉入管子法设计：不要靠"意志力"或"健康意识"（这些都在管子外面）。
      具体方法：
      1) 提醒设计：工作日下午3点发一条健身提醒（把健身从"晚上的事"拉到当下）；
      2) 环境设计：把健身包放在办公室门口（视觉提醒，进入管子视野）；
      3) 一次性行动：提前买好私教课/约好健身伙伴（取消成本变高，自动进入管子）；
      4) 冲动设计：把健身变成有趣的事（如喜欢的运动、社交运动），
         让它本身就能俘获注意力，而不是靠意志力推动。
      推论：任何"重要但不紧急"的事，都可以用这套框架来设计干预。
  V3_exclusivity:
    passed: true
    why_not_common: |
      常识是"要重视健康""要有毅力""定计划"——都是态度和意志力层面的建议。
      本书的独特方法：承认管窥是不可避免的，不跟意志力较劲，
      而是通过设计（提醒、默认选项、环境、一次性行动）让重要的事
      自动进入管子视野。这是从"改变人"到"设计环境"的范式转换。

- id: v05
  title: 稀缺陷阱逃离路线图
  source_ids: [f04, f05, f06, p07, p08, ce03, ce09]
  type: framework
  V1_cross_domain:
    passed: true
    evidence:
      - 第5-6章：桑德拉工薪日贷款陷阱（个人财务）
      - 第6章：印度小贩九年半债务循环（微型企业）
      - 第6章：学生期末熬夜→成绩差→更忙（教育）
      - 第9章：NASA救火模式→探测器坠毁（组织）
      - 第9章：圣约翰医院手术室满负荷→救火→效率低（医疗组织）
    reasoning: |
      稀缺陷阱的自我强化机制在个人财务、小微企业、学生、大型组织、
      医疗机构等至少5个独立语境中被观察到，循环路径高度一致：
      稀缺→管窥→借用→杂耍→更深的稀缺。
  V2_predictive_power:
    passed: true
    novel_question: "一个创业团队一直在赶进度、加班、bug不断，如何逃离救火陷阱？"
    derived_answer: |
      用稀缺陷阱逃离路线图分析，分四步走：
      第一步：停止借用——不要再把技术债务、测试、文档往后推（停止借新债）；
      第二步：挤出第一笔余闲——哪怕每周只挤出半天时间，专门用于"重要但不紧急"的事
      （代码重构、自动化工具、流程改进）；
      第三步：用余闲做杠杆最高的事——先解决那些"每次救火都出现"的重复性问题，
      用一次性投入减少未来的救火时间（如自动化测试、CI/CD）；
      第四步：逐步扩大余闲，进入正循环——每解决一个根源问题，
      就多一点时间，再用多出来的时间解决更多根源问题。
      关键反直觉点：不是加速，而是先"减速"来构建余闲。
  V3_exclusivity:
    passed: true
    why_not_common: |
      常识是"更努力""提高效率""加强管理"——都是在现有框架内加速。
      本书的洞见是反直觉的：稀缺陷阱中，越努力可能陷得越深
      （因为更专注于当下，更管窥，更借用）。正确的逃离路径是
      "先减速、建缓冲、再加速"，这与大多数人的本能反应相反。
      而且逃离的关键不是"意志力"而是"时机"——必须在带宽充裕时行动。
  skill_slug: scarcity-trap-escape

- id: v06
  title: 充裕期资源配置法
  source_ids: [f06, f09, p14, c10]
  type: framework
  V1_cross_domain:
    passed: true
    evidence:
      - 第10章：肯尼亚农民收获时买肥料vs种植时没钱（农业）
      - 第6章：发薪日/收获后vs月底/收获前带宽差异（个人财务）
      - 第9章：项目初期vs项目后期时间管理（项目管理）
      - 第10章：月初vs月底时间/金钱分配（日常生活）
    reasoning: |
      "在充裕期为稀缺期做准备"的原则在农业、个人理财、项目管理、
      日常生活等多个独立场景中被验证，核心逻辑一致：
      稀缺期没有带宽做规划，必须在充裕期提前行动。
  V2_predictive_power:
    passed: true
    novel_question: "为什么大多数人的新年健身计划都坚持不到3月？"
    derived_answer: |
      用充裕-稀缺循环分析：元旦时（时间/精力相对充裕，且有新年新气象的心理）
      人们制定健身计划，但没有"锁定"为一次性行动。等工作忙起来
      （时间稀缺期到来），健身就被挤出管子视野了。
      正确做法：在元旦（充裕期）就做一次性投入：
      1) 买全年私教课/健身卡（沉没成本让它更容易进入管子）；
      2) 约固定健身伙伴（社交承诺增加爽约成本）；
      3) 把健身服/装备放在显眼位置（环境设计）；
      4) 设置自动提醒（拉入管子）。
      等稀缺期到来时，这些"锁定"措施会让健身不那么容易被忽略。
  V3_exclusivity:
    passed: true
    why_not_common: |
      常识是"要有规划""未雨绸缪"——这是正确的废话，人人都知道但做不到。
      本书的独特贡献在于解释了"为什么做不到"（因为带宽周期波动，
      稀缺期没有执行规划的认知资源），并给出了具体可操作的方法：
      在带宽充裕时做"一次性锁定"，而不是靠持续警醒。
      关键不是"知道要规划"，而是"知道在什么时候、用什么方式规划"。
  skill_slug: abundance-planning

- id: v07
  title: 借用警觉清单
  source_ids: [f04, p06, ce02, c12]
  type: principle
  V1_cross_domain:
    passed: true
    evidence:
      - 第5章：桑德拉工薪日贷款陷阱（金钱借用）
      - 第5章：家庭问答游戏实验中穷人过度借用时间（时间借用）
      - 第6章：印度小贩日息5%贷款循环（金钱借用）
      - 第6章：项目拖延→加班→质量下降→更拖延（时间借用）
      - 第6章：节食者今天多吃一口→明天更胖→更难节食（热量借用）
    reasoning: |
      借用行为及其复利效应在金钱、时间、热量等多个独立资源维度中存在，
      且都符合同一模式：管窥心态下低估借用成本→利息累积→加剧稀缺。
  V2_predictive_power:
    passed: true
    novel_question: "一个学生想用'刷夜突击'来应对考试，这是不是坏的借用？如何判断？"
    derived_answer: |
      用借用警觉清单分析：
      1) 这是借用吗？——是，向未来的时间/健康/精力借用（刷夜换来今晚的学习时间，
         但明天效率下降、健康受损）。
      2) 利息是多少？——刷夜一晚，第二天认知能力下降相当于IQ降10分，
         后续几天效率都受影响，可能得不偿失。
      3) 有没有不借用的替代方案？——有：提前规划、分散学习、
         放弃部分内容保重点（而不是全部都学但都学不好）。
      4) 这是第几次借用了？——如果已经连续刷夜好几次，那利息已经在复利累积了，
         必须立刻停止。
      结论：刷夜突击是典型的时间借用，管窥心态下被高估收益、低估成本，
      从全局看往往是净损失。
  V3_exclusivity:
    passed: true
    why_not_common: |
      常识是"借钱不好""拖延不好"——道德化的定性判断，没有可操作的判断标准。
      本书的独特之处：1) 提供了借用的统一机制（管窥→低估成本→过度借用）；
      2) 解释了为什么聪明人也会犯借用错误（不是蠢，是管窥机制的必然结果）；
      3) 最反直觉：你最想借用的时候（最紧迫的时候），往往是最不该借用的时候，
         因为此时判断力被管窥扭曲得最严重。
