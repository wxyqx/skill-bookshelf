- id: c05
  title: 印度街头小贩的稀缺陷阱实验
  type: case
  source_chapter: 第6章 稀缺陷阱
  source_quote: |
    "如果每天都能节省一点钱，50天之后，小贩们就可以无债一身轻。
    没有债务之后，小贩们每天的收入就能翻番……但典型的街头小贩已经借贷达九年半之久。"
  summary: |
    印度金奈街头小贩：每天借1000卢比进货，日利润100卢比，但要付50卢比利息（日息5%）。
    理论上每天省5卢比，50天就能摆脱债务、收入翻番。但实际他们平均借贷9.5年。
    作者做了一个实验：随机选一半小贩，直接帮他们还清所有债务。
    结果：最初几个月他们保持了无债状态，但一年后，几乎所有人又回到了原来的债务水平。
    原因：余闲不足——一次突发事件（家人生病、亲戚婚礼）就足以让他们重新借贷，
    然后再次落入陷阱。
  bound_to:
    - "稀缺陷阱的自我强化"
    - "余闲缺乏导致脆弱性"
    - "光给钱不能解决稀缺问题"
  outcome: |
    一次性资金注入不能让人永久逃离稀缺陷阱，因为余闲不足时，任何突发事件
    都会把人重新拉回陷阱。需要缓冲机制和行为模式的双重改变。
  tags: [case, field-experiment, street-vendors, scarcity-trap]

  summary: |

    - "系统层面的稀缺管理"

    改革大获成功。证明了：在满负荷运转的系统中，预留专门的缓冲资源
    （看似"浪费"的余闲）反而能提高整体效率和产出。

    - "重要事项拉入管子法"

    核心洞见：利用带宽充裕（钱也充裕）的时机做重要决策，而不是等到稀缺时再想办法。

    肥料购买使用率从29%提升至45%。证明了"时机选择"对稀缺管理的重要性——

  type: case
  source_chapter: 第5章 借用与短视
  source_quote: |
    "穷人比上次能借用秒数的时候多赚到了60%的分数……
    穷人常常会采取借用手段，为当下寻求帮助。但最终，他们会反受其害。"
  summary: |
    基于《家庭问答》游戏的实验室实验：玩家在有限时间内答题，"穷人"时间少，"富人"时间多。

    结果：穷人更专注，每秒钟得分更高；但他们也借用得更多，
    而高利息的借用最终让他们总得分更低。当取消借用功能时，
    穷人的分数比有借用时高了60%。这直接证明了：
    借用在管窥心态下看起来很有吸引力，但从全局看是净损失。
  bound_to:
    - "借用的净损失"
    - "管窥导致过度借用"
  outcome: |
    有借用时穷人成绩差60%。实验室中验证了借用对稀缺人群的伤害——
    看似在帮你解决当下之急，实际让整体情况更糟。

  title: 红花日本料理的座位稀缺管理
  type: case
  source_chapter: 第9章 如何解决组织中的时间稀缺
  source_quote: |
    "青木意识到，餐饮行业真正稀缺的是座位资源……
    红花日本料理上演的厨艺表演，实际上是解决稀缺问题的一种非常聪明的办法。"
  summary: |
    青木广彰创办的红花日本料理，用铁板烧+厨艺表演的模式，解决了餐厅最核心的稀缺——
    座位资源。做法：1) 公用大餐桌（8人桌），提高座位利用率（零散客人不用等）；
    2) 厨师现场表演，加快翻桌率（客人必须跟着节奏吃，结束就走）；
    3) 简洁菜单，减少点单时间。结果：每张桌子每晚能招待更多轮客人，
    每1美元收入的盈利比普通餐厅多10美分。
    核心洞见：识别真正的稀缺资源（不是菜品、不是服务，是座位），
    然后围绕它设计整个商业模式。
  bound_to:
    - "识别真正的稀缺资源"
    - "稀缺管理的商业应用"
  outcome: |
    餐厅盈利能力显著提升，成为全球连锁品牌。
    是"稀缺管理创造商业价值"的经典商业案例。
  tags: [case, business, restaurant, scarcity-management]
