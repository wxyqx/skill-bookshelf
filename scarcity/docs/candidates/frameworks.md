- id: f01
  title: 管窥决策框架
  type: framework
  source_chapter: 第1章 专注的得与管窥的失
  source_quote: |
    "专注于某一事物就意味着我们会忽略其他事物。稀缺令人'专注'，也可以说稀缺导致我们有了'管窥'之见——只能一门心思地专注于管理手头的稀缺。"
  summary: |
    当稀缺俘获大脑时，人的视野会变窄，形成"管子"视野——管子内的事物被放大和强化，
    管子外的事物被抑制和忽略。这不是有意识的选择，而是目标抑制机制的自动结果。
    做决策时，如果自己正处于稀缺状态，必须主动检查：管子视野之外有什么被我忽略了？
    这个框架适用于识别所有稀缺状态下的决策盲区。
  tags: [framework, decision, tunneling, scarcity]

- id: f02
  title: 带宽征税模型
  type: framework
  source_chapter: 第2章 带宽负担会降低人的智商
  source_quote: |
    "稀缺会直接减少带宽——不是减少某人与生俱来的带宽容量，而是减少其当下能用得上的容量。"
  summary: |
    把心智想象成一台同时运行多个程序的电脑。稀缺会在后台自动运行一个高占用程序，
    占用大量处理器资源（带宽），导致前台任务可用资源减少。
    带宽包括两类：认知能力（流体智力）和执行控制力（规划、抑制冲动、自我控制）。
    这个模型的核心洞见：同一个人在稀缺状态下，有效智力会下降13-14分IQ。
    应用：评估他人或自己的表现时，要问"此刻带宽负担有多重？"
  tags: [framework, cognitive, bandwidth, mental-model]

- id: f03
  title: 行李箱装箱模型
  type: framework
  source_chapter: 第3章 装箱、余闲和权衡式思维
  source_quote: |
    "小行李箱迫使我们认清了一个事实：装进一样东西的同时，就必须拿出另一样东西。
    大行李箱的主人在思考是否带上跑鞋时，只不过是在想他需不需要这双鞋；
    而小行李箱的主人则是在考虑，若想带上跑鞋，就需要从行李箱中拿出某样物品。"
  summary: |
    把资源（时间、金钱、热量）想象成行李箱。大行李箱（充裕）= 余闲多 = 不需要权衡 =
    可以随便装 = 但也容易浪费。小行李箱（稀缺）= 余闲少 = 每次装入都要权衡 =
    更精打细算 = 但也没有容错空间。这个模型解释了为什么稀缺的人更懂价值（装箱专家），
    但也更难承受失误（没有缓冲）。应用：评估自己处于"大行李箱"还是"小行李箱"状态，
    并据此调整决策方式。
  tags: [framework, tradeoff, slack, mental-model]

- id: f04
  title: 借用复利陷阱模型
  type: framework
  source_chapter: 第5章 借用与短视 / 第6章 稀缺陷阱
  source_quote: |
    "当我们有了管窥之见时，借用就会超越得失均衡的限度。当面临稀缺状况时，
    我们的借用，从长期来看通常是不合理的。稀缺致使我们借用，并且让我们在稀缺的泥潭中越陷越深。"
  summary: |
    管窥心态下，当下之急被放大，未来代价被低估，导致我们向未来"借用"资源
    （借高利贷、拖延工作、跳过重要但不紧急的事）。借用的利息会像复利一样累积：
    今天借的时间，明天要花更多时间还；今天借的钱，未来要还更多。
    这个模型解释了稀缺陷阱的自我强化机制——借用→利息更高→更稀缺→更多借用。
    应用：面对紧迫需求时，先问"这是借用吗？真实利息是多少？"
  tags: [framework, borrowing, trap, compound-interest]

- id: f05
  title: 杂耍状态诊断框架
  type: framework
  source_chapter: 第6章 稀缺陷阱
  source_quote: |
    "杂耍，就是人们将可预期事件当成突如其来的事件进行处理的根源。杂耍时，
    你从'管子'视野中只能看到即将落入手中的球，而会忽视抛在空中尚未落下的其他几个球。"
  summary: |
    稀缺陷阱的典型状态：持续从一个紧迫任务跳到另一个紧迫任务，把可预期的事件
    都当作突发事件处理。判断自己是否在"杂耍"的信号：
    1) 总是在最后一刻才处理事情；
    2) 明明知道某件事要来，却总是等它迫近才行动；
    3) 待办事项像杂乱的补丁图，而非有序的计划；
    4) 感觉永远在"救火"。
    这个框架用于识别自己是否已进入稀缺陷阱的核心状态。
  tags: [framework, diagnosis, juggling, scarcity-trap]

- id: f06
  title: 充裕-稀缺循环模型
  type: framework
  source_chapter: 第6章 稀缺陷阱 / 第10章 如何应对日常生活中的稀缺
  source_quote: |
    "沿着稀缺的线索向上追溯，我们就能看到充裕：萧条，是由我们在繁荣阶段的行为所导致的；
    最后一刻的拼凑，是由我们之前几周的不作为所造成的。"
  summary: |
    稀缺不是凭空出现的，它的种子在资源充裕阶段就种下了。
    循环路径：资源充裕→拖延/浪费→资源逐渐减少→管窥出现→借用→杂耍→稀缺陷阱。
    关键洞见：逃离/预防稀缺的最佳时机，不是稀缺最严重的时候，
    而是资源还充裕的时候——因为稀缺状态下没有带宽去规划和改变。
    应用：在充裕期主动构建缓冲、均摊资源、设置阶段性截止日期。
  tags: [framework, cycle, abundance, prevention]

- id: f07
  title: 驾驶舱设计思维（稀缺环境优化框架）
  type: framework
  source_chapter: 第8章 如何让穷人摆脱贫穷
  source_quote: |
    "失误在所难免，灾难却并非如此。优秀的驾驶舱设计，不仅不应该诱导飞行员犯错，
    而且还要避免将失误酿成灾难。"
  summary: |
    不是让人"更努力""更细心"，而是从环境设计入手，让正确的选择成为最容易的选择。
    核心原则：
    1) 包容失误——设计容错空间，让一次失误不致酿成灾难；
    2) 让重要的事自动进入视野——提醒、默认设置；
    3) 减少带宽消耗——简化决策、降低认知负荷；
    4) 把警醒型行为转为一次性行动。
    这个框架可用于设计产品、政策、个人系统等任何需要应对稀缺的场景。
  tags: [framework, design, environment, nudge]

- id: f08
  title: 余闲缓冲构建框架
  type: framework
  source_chapter: 第9章 如何解决组织中的时间稀缺
  source_quote: |
    "许多系统的正常运转，都以余闲的存在为前提。就算是那些深谋远虑的人，
    也常常会低估余闲的重要性。"
  summary: |
    余闲不是浪费，而是系统正常运转的必需品。构建余闲的思路：
    1) 识别真正的稀缺资源（时间？金钱？注意力？）；
    2) 为该资源预留专门缓冲（如空出一间手术室应对急诊）；
    3) 缓冲必须是"专用"的，否则会被日常需求挤占；
    4) 余闲的量要足以吸收常见的突发事件波动。
    应用：个人日程留空白、财务存应急金、项目留缓冲时间。
  tags: [framework, slack, buffer, system-design]

- id: f09
  title: 带宽时机利用框架
  type: framework
  source_chapter: 第10章 如何应对日常生活中的稀缺
  source_quote: |
    "带宽变化时机的重要性，在于能让人们将计划与更为理想的带宽变化时机联系起来。"
  summary: |
    带宽不是恒定的，它随时间波动：农民收获后带宽多、收获前带宽少；
    上班族月初带宽多、月底少；早上带宽多、深夜带宽少。
    利用带宽波动的策略：
    1) 在带宽充裕时处理高认知需求的任务（规划、学习、重要决策）；
    2) 在带宽稀缺时只处理低带宽需求的事（机械性任务）；
    3) 重要决策要在带宽充足时做，稀缺状态下尽量不做重大决定；
    4) 在带宽充裕时提前为稀缺期做好准备（如收获时买肥料、发薪日储蓄）。
  tags: [framework, timing, bandwidth, planning]

- id: f10
  title: 警醒型→一次性行为转化框架
  type: framework
  source_chapter: 第10章 如何应对日常生活中的稀缺
  source_quote: |
    "只要有可能，就要将警醒型行为转变成一次性行动。"
  summary: |
    行为分两类：警醒型（需要持续意志力，如每天健身、每月储蓄、健康饮食）
    和一次性（做一次就长期受益，如设置自动还款、买健身卡、清理橱柜里的垃圾食品）。
    管窥心态下，警醒型行为最容易被忽略。转化策略：
    1) 识别哪些好行为是警醒型的；
    2) 找到一次性行动的替代方案（自动扣款=自动储蓄，ETC=不用每次准备零钱）；
    3) 反过来，把危险的一次性行为（如借高利贷）转化为需要警醒的（设置冷却期）。
  tags: [framework, behavior-design, willpower, automation]

- id: f11
  title: 重要事项拉入管子法
  type: framework
  source_chapter: 第10章 如何应对日常生活中的稀缺
  source_quote: |
    "对稀缺进行管理，有一种简单而常常为人们所低估的方法，那就是对'管子'视野之内的事物施加影响。"
  summary: |
    管窥心态下，重要但不紧急的事总会落在管子视野之外被忽略。
    解决方法不是"提高专注力"，而是主动把重要的事"拉进"管子里：
    1) 提醒（短信、邮件、助理敲门——把未来的事带到当下）；
    2) 让它出现在眼前（把储蓄卡放在收银台旁、橱柜里只放健康食品）；
    3) 设置截止日期和节点（把遥远的大目标拆成频繁的小截止日期）；
    4) 冲动设计（利用冲动心理，把好行为也变成"冲动"）。
  tags: [framework, attention, nudge, important-not-urgent]
