## 直接淘汰的候选

以下候选因不符合"可执行方法论"标准或过于泛化而被淘汰：

| 候选 Skill | 来源信件 | 淘汰原因 |
|---|---|---|
| ask-dont-know（敢于说不懂） | 第一封 | 过于具体，更适合作为 low-profile-wisdom 的案例而非独立 skill |
| praise-leadership（赞美式领导） | 第一封 | 已融入 employees-first 和 strength-based-management 的具体做法 |
| borrowing-leverage（借贷杠杆） | 第七封 | 时代背景强，现代应用需大量合规补充，不适合独立 skill |
| manage-by-numbers（数字治理） | 第七封 | 过于专业财务，偏离本书核心心智体系 |
| seize-window（抓窗口期） | 第六、八封 | 已融入 planned-luck 和 calculated-risk |
| insult-to-fuel 等情绪类 | 第十二封 | 合并到 impulse-control |

## 淘汰标准

1. **跨域验证**: 是否能在不同行业、不同人生阶段通用？
2. **预测力验证**: 是否能帮助用户在真实决策中做出更好判断？
3. **独特性验证**: 是否与已有 skill 明显区分，而非同义反复？
4. **可执行性**: 是否能拆分为明确的行动步骤？
5. **去时代局限**: 是否过度依赖 19 世纪特定商业环境？
