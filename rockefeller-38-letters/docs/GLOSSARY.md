# 《洛克菲勒留给儿子的38封信》—— 共享术语词典

> 本词典汇总全书 skills 中反复出现的关键术语，统一作者用法与常见含义的差异。

| 术语 | 作者用法 | 常见含义差异 |
|---|---|---|
| 装傻 | 低调行事、谦恭为人，将聪明包装在傻气下面；是真聪明而非真傻。 | 日常常指故意表现得愚蠢或逃避责任。 |
| 吃苦 | 主动经历艰辛、不幸、失败、挫折，以磨砺毅力与实行能力。 | 日常多指被动忍受贫困或劳累。 |
| 知识 | 必须付诸实践才有价值，否则等于没有知识。 | 常被视为书本学问或学历资本。 |
| 实行能力 | 身体力行、活学活用、解决问题的能力，来自吃苦与实践。 | 常被简单理解为执行力，忽略其来源是磨难。 |
| 态度 | 思想与精神因素的结合，决定抉择、行动与结果。 | 日常多指一时的情绪或礼貌。 |
| 运气 | 由自信、勇敢、态度与谋略创造出来的东西，并非天赐。 | 常被视为随机、不可控的外部机遇。 |
| 策划运气 | 通过明确目标、清点资源、制定谋略来主动创造机遇。 | 日常认为运气不可策划，只能等待。 |
| 借贷 | 为前途创造好运的投资工具，前提是善用与诚信。 | 常被看作债务压力或走投无路的选择。 |
| 精神破产 | 宣布自己无法再起、丧失乐观坚毅的心，意味着输掉一切。 | 日常无此固定用法，易误解为精神疾病。 |
| 利益 | 人性的投影仪，能显露一个人真实的人性面目。 | 常被视为中性或负面的金钱收益。 |
| 谋利游戏 | 以利益为核心的人际互动场域，没有永恒的朋友，只有永恒的利益。 | 日常较少使用，易被理解为尔虞我诈的极端描述。 |
| 协和 | 目标与资源相互调节后达到的一致状态，是策划人生的基础。 | 日常多指音乐和谐或关系融洽。 |
| 忍耐 | 基于目标利益的冷静策略，非软弱。 | 常被误解为忍气吞声、无原则退让。 |
| 信念 | 坚信自己能成功的恒定态度，可激发能力与方法。 | 常被等同于希望或宗教信仰。 |
| 目的 | 行动的原动力与方向，领导者向团队坦诚共享的动机与预期结果。 | 常仅指目标或意图，较少强调其驱动与公开沟通功能。 |
| 价值 | 交易中对方获得的好处与效用，而非价格高低。 | 日常中常与价格混淆。 |
| 拐杖 | 外在条件、关系、资源等辅助手段。 | 日常生活中指行动不便者的辅助工具。 |
| 双腿 | 自身实力与核心竞争力。 | 身体部位。 |
| 渔夫 | 善于创造多种可能性、结网捕鱼的策略型思考者。 | 职业身份。 |
| 垂钓者 | 固守单一路径、被动等待结果的计划执行者。 | 休闲活动者。 |
| 借口 | 思想上腐蚀成功机遇的毒疮，是怠惰的软枕头，使人大脑僵化、动力消失。 | 日常多指搪塞他人的理由，作者强调其对自我成功的慢性毒害。 |
| 运气 | 由详细计划、充分准备和积极思想创造出来的结果，非天赐。 | 通常指随机、不可控的外部机遇。 |
| 才智 | 潜在能力，必须通过建设性运用与正确思考方式才能产生价值。 | 常被视为决定成败的先天禀赋。 |
| 伟大 | 对同胞与祖国作出实际贡献，用卑微工具创造伟大成就。 | 常与职位、财富、名声挂钩。 |
| 酷爱金钱 | 崇拜金钱、为金钱不择手段的心态，才是万恶之源。 | 常被简化为"金钱是万恶之源"。 |
| 勤奋 | 为自己劳作，锻造品质、能力与自信的过程。 | 常被视为为他人或公司付出。 |
| 贵族 | 血脉中流淌勤劳、毅力与顽强意志的精神，非永恒身份。 | 通常指出身显赫的阶层。 |
| 责任 | 财富拥有者对国家、同胞与人类的公共义务。 | 常指岗位职责或法律责任。 |
| 尾声/开端 | 每次成功的结束都是下一次梦想征程的开始。 | 通常被看作终点或起点，作者强调其连续性。 |
| 优势 | 竞争中了解自身与对手的资源、优劣势、习惯与性格后形成的主动权。 | 常简单等同于资源多或能力强。 |
| 毅力 | 无可替代的成功的核心品质，胜过才能与教育。 | 常被当作意志力或坚持的同义词。 |
| 责难 | 摧毁领导风范的最强劲敌人，让领导者陷入沼泽。 | 常被视为追责或批评。 |
| 自责 | 最阴险狡猾的责难陷阱，使人陷入仇恨与抱怨。 | 常被视为自我反省或负责任的表现。 |
| 免费午餐 | 不劳而获的诱惑，会剥夺人的尊严与自主能力。 | 常指真正的免费福利或优惠。 |
| 施舍 | 否定他人尊严、剥夺其掌控命运权力的不道德行为。 | 常被视为善举或慈善。 |
| 忠于自己 | 做自己喜欢且擅长的事，发挥自身潜能。 | 常被误解为任性或自我中心。 |
| 贪心 | 对成功、财富、卓越的强烈渴望，是激发潜能的内在动力。 | 常带贬义，指贪婪、损人利己。 |
| 珍惜时间 | 计划每一天甚至每一刻的行动，让时间产生成果。 | 常被理解为不要浪费、提高效率，缺少目标导向。 |
| 精神食粮 | 经典书籍、积极思想、良好词汇，用于每日滋养心灵。 | 常泛化为任何娱乐或信息消费。 |
| 雄心/野心 | 高远目标与持续追求卓越的动力。 | 现代语境有时带"不择手段"的负面联想。 |
| 金钱价值 | 钱应通过明智投资持续生钱，而非消费或封存。 | 常被等同于储蓄数额或购买力。 |
| 员工首位 | 将雇员放在决策首位，以尊重、感激和优厚待遇激发潜能。 | 常被误解为慈善或无原则迁就。 |
| 冒险 | 在周密计划与价值判断基础上的大胆行动。 | 常被等同于赌博或盲目冒进。 |
| 竞争 | 在规则范围内尽全力取胜，先发制人。 | 常被理解为恶意打压或不择手段。 |
| 资本 | 创业者自身的能力、信念、常识与潜力。 | 常被狭义理解为资金。 |
| 为自己工作 | 把每一份工作视为实现自我目标的手段与奠基。 | 常被简单理解为辞职创业。 |
