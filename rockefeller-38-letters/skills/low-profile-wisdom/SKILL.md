# 韬光养晦

## R — 原文 (Reading)

> 装傻并不是真傻，它的含义是：低调行事、谦恭为人，换言之，就是要韬光养晦，将你的聪明包装在你的傻气下面。
>
> — 约翰·D·洛克菲勒，第一封 大智若愚，韬光养晦

---

## I — 方法论骨架 (Interpretation)

洛克菲勒把"装傻"重新定义为一种情境策略：在需要借力、谈判、争取时间或避免树敌时，主动收敛锋芒，以谦恭姿态获取信息、信任与更有利的条件。它不是真傻，也不是懦弱，而是把聪明包装在傻气下面的主动选择。其核心是判断何时该示弱、何时该藏锋，以及何时该在合适的时机展现实力。

这个方法论的关键是"姿态管理"：真正强大的人不必处处证明自己强大；在弱势时低头学习，在强势时宽宏待人，才能赢得长久的合作空间。

## A1 — 书中的应用 (Past Application)

### 案例 1: 银行家主动借五万美元
- **问题**: 洛克菲勒正苦于筹集1.5万美元，银行家却主动提出借给他五万美元。
- **方法论的使用**: 面对意外之喜，他没有表现出焦急或兴奋，而是平静地请求"请给我24小时的考虑时间"。
- **结论**: 主动争取思考时间，才能避免在情绪高点做出不利决策。
- **结果**: 最终以极有利于自己的条件获得借款。

### 案例 2: 10万美元买地三年变2500万美元
- **问题**: 洛克菲勒看好一块郊外偏僻地皮，但主人不信其购买意图。
- **方法论的使用**: 他直接拿10万美元现金购买，面对"傻子"的嘲笑不动声色；一年后市政府宣布建环城公路仍不出售，继续等待。
- **结论**: 在别人看来的"傻气"下面，藏着对长期价值的判断与定力。
- **结果**: 三年后以2500万美元售出，地皮升值150倍。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新入职或晋升，需要融入团队而不引发老员工的敌意。
2. 向专家、上级或长辈请教敏感问题，需要争取思考和学习的时间。
3. 商业谈判中对方急躁逼单，你需要争取更有利的条件。
4. 身居高位需要笼络人心，避免压人一截的将军式指挥。
5. 面对低估你的对手，需要隐藏真实意图以待时机。

### 语言信号 (用户的话里出现这些就应激活)

- "如何低调做人"
- "太高调被排挤"
- "怎么让别人愿意帮我"
- "谈判时如何争取时间"
- "领导如何赢得人心"
- "韬光养晦"

### 与相邻 skill 的区分

- 与 `deliberate-hardship` 的区别: `deliberate-hardship` 聚焦主动选择艰难历练以磨砺能力；`low-profile-wisdom` 聚焦情境中收敛锋芒、以谦恭获取优势。
- 与 `ask-dont-know` 的区别: `ask-dont-know` 聚焦坦诚说"不懂"以获取知识；`low-profile-wisdom` 聚焦整体的低调谦恭策略姿态。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **判断是否需要收敛锋芒**
   - 完成标准: 明确用户当前是处于强势还是弱势位置，是否需要争取时间、信息或信任。
   - 判停条件: 若用户处于必须展示专业能力的场景，建议切换至展示能力模式。

2. **选择具体低调姿态**
   - 完成标准: 从"少说多听""请教为先""延后表态""宽宏待人"中选出适合当前情境的一种或多种。
   - 判停条件: 若低调会被误解为无能或逃避，需加入适度的实力展示。

3. **争取时间、信息或信任**
   - 完成标准: 通过请求思考时间、提出好问题、表达感谢等方式，获得对自己有利的空间。
   - 判停条件: 若对方识破策略或利用低调施压，需调整姿态。

4. **在适当时机展现实力**
   - 完成标准: 当条件成熟、信任建立或决策关键时刻，用事实证明真正的能力。
   - 判停条件: 若始终不展现实力，会错失机会或被当作真傻。

5. **评估结果并调整姿态**
   - 完成标准: 回顾低调策略是否达成目标，是否需要转向更强硬的立场。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户需要展示专业能力以获取信任或赢得竞争的场合。
- 用户借"低调"长期逃避责任、伪装无能或推卸决策。
- 紧急危机中需要立即建立权威、果断指挥的场景。

### 作者在书中警告的失败模式

- **自以为聪明而不懂装懂**: 耻于请教的人才是真正的傻瓜，先入为主会关闭学习通道。
- **压人一截的将军式指挥**: 轻视与鄙薄会激发部下的厌恶，最终丧失领导能力。

### 作者的盲点 / 时代局限

- 洛克菲勒的韬光养晦建立在他已有强大实力和资源的基础上，现代普通人在弱势时过度低调可能被忽视或边缘化，需要把握展示与隐藏的平衡。
- 在强调个人品牌与专业背书的现代职场，完全低调可能不利于职业发展。

### 容易混淆的邻近方法论

- 与"真傻/懦弱"的区别: 韬光养晦是主动策略，内心清醒、目标明确；真傻是能力不足，懦弱是不敢主张。
- 与"过度谦虚"的区别: 韬光养晦有明确的时机和目的，不是无原则的自我贬低。
