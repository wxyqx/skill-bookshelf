# 策划运气

## R — 原文 (Reading)

> 我不凭借天赐的运气过活，但我凭借策划运气而发达……好的谋略策划可以掌控机遇的到来，而且更为重要的是，人为策略往往都能够成功地影响运气。
>
> — 约翰·D·洛克菲勒，第十封 运筹帷幄，策划运气

---

## I — 方法论骨架 (Interpretation)

洛克菲勒把"运气"重新定义为"目标、资源、谋略与行动"的协和产物。不是等待天上掉馅饼，而是先明确自己要什么，再清点手里有什么（地位、金钱、权力、人际关系、自身能力），然后根据两者相互调节，制定分阶段计划，主动引导机遇到来。

这个方法论的核心是"协和"：目标不能脱离资源空喊，资源也不能没有目标地闲置。当目标与资源达成一致，谋略就变成连接两者的桥梁。

## A1 — 书中的应用 (Past Application)

### 案例 1: 变竞争为合作的石油业并购
- **问题**: 炼油商各自为战导致生产过剩、油价暴跌、普遍亏损。
- **方法论的使用**: 洛克菲勒没有继续打价格战，而是制定分阶段计划：先筹资成立标准石油，再收购科利佛兰最强大的克拉克-佩恩公司，形成示范效应，最后向全国扩张。
- **结论**: 把对手变成合作者，才能重塑行业秩序。
- **结果**: 三年内成为全美洲炼油业最终领导者。

### 案例 2: 被浸染丝绸做成迷彩服
- **问题**: 贫穷时期洛克菲勒在酒吧听说日本人因丝绸被海水浸染而发愁，想扔掉又怕被罚。
- **方法论的使用**: 他发现这是"无成本资源 + 市场空白"的组合，主动提出帮忙处理，再做成迷彩服、领带、礼帽出售。
- **结论**: 在别人眼里的麻烦，可能是你眼里的资源。
- **结果**: 赚得十万美元，由小商贩变成小有资本的商人。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 创业起步，不知道从何入手，资源有限但目标远大。
2. 人生或企业进入转型期，需要重新对焦方向。
3. 行业混乱，想从被动竞争转向主动布局。
4. 总觉得自己"运气不好"，想把不可控感转化为可控行动。
5. 有机会出现，但不知道如何最大化把握概率。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么策划运气"
- "如何主动创造机会"
- "人生规划怎么做"
- "目标资源不匹配"
- "如何把竞争变成合作"
- "时运不济怎么办"

### 与相邻 skill 的区分

- 与 `action-first` 的区别: `action-first` 强调在计划足够好后立即行动，解决拖延；`planned-luck` 强调先让目标与资源协和，再设计机会。
- 与 `calculated-risk` 的区别: `calculated-risk` 聚焦在不确定性下的下注决策；`planned-luck` 聚焦在机会出现前的系统性布局。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **明确核心目标**
   - 完成标准: 用一句话说清楚用户真正想要的结果，且可衡量、有时限。
   - 判停条件: 若用户目标模糊，先帮其澄清，否则无法进入下一步。

2. **清点现有资源**
   - 完成标准: 列出用户可支配的资源清单，包括金钱、人脉、技能、时间、信息、位置优势等。
   - 判停条件: 若资源严重不足，进入"缩小目标或补充资源"分支。

3. **识别资源与目标的差距**
   - 完成标准: 明确"缺什么"和"可以用什么替代"。
   - 判停条件: 若差距过大且无法弥合，建议调整目标或分阶段实现。

4. **设计分阶段谋略**
   - 完成标准: 输出 3-5 个可执行的关键动作，每个动作对应一个小里程碑。
   - 判停条件: 若用户只想空想，强调必须选择最小下一步行动。

5. **选择最小下一步行动**
   - 完成标准: 明确 24-72 小时内可以完成的具体动作。
   - 判停条件: 若用户无法承诺行动，回到步骤 1 重新校准目标。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只是想算命、占卜或等待"天赐良机"。
- 用户寻求的是违反法律、反垄断或道德底线的"捷径"。
- 用户完全没有行动意愿，只想做人生规划的白日梦。

### 作者在书中警告的失败模式

- **随波逐流怨天尤人**: 将机遇视为天赐、顾影自怜，不主动策划命运，最终被主动者吞并或淘汰。
- **等待完美时机**: 非要等到天时地利人和才行动，结果机会被他人抢走。

### 作者的盲点 / 时代局限

- 洛克菲勒的"策划运气"大量依赖资本、人脉与行业控制力，现代普通个体可调配的资源远少于他，需要把方法论降级为可负担的版本。
- 书中对垄断整合的描述在现代合规环境下需要重新审视，不能简单复制。

### 容易混淆的邻近方法论

- 与"吸引力法则"的区别: 策划运气强调目标、资源、谋略与行动的系统工程，而非单纯"心想事成"。
- 与"机会主义"的区别: 策划运气有长期目标与道德边界，不是见风使舵。
