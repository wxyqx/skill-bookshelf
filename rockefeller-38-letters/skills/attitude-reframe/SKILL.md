# 态度重塑

## R — 原文 (Reading)

> 可以工作是每个人的一项特权，它所给人们带来的快乐是远远超过换取维持生命的面包的。工作其实是奠定商业基础的起步，是富贵昌盛的源头，更是磨炼天才的伟大教师。
>
> — 约翰·D·洛克菲勒，第四封 天堂地狱，态度之差

---

## I — 方法论骨架 (Interpretation)

洛克菲勒把工作态度比作天堂与地狱的分界线：视工作为乐趣与荣耀，人生就是天堂；视工作为义务与惩罚，人生就是地狱。他认为，工作的最高报酬不只是薪资，而在于它成就了什么、塑造了什么样的人。"态度重塑"就是帮助用户把对工作"不得不做"的消极框架，转化为"选择去做"的积极框架，从而改变工作体验与人生感受。

这个方法论的核心不是否认工作的辛苦，而是重新赋予工作意义：看见工作中的成长、贡献与长期回报，让态度成为推动行动的内在燃料。

## A1 — 书中的应用 (Past Application)

### 案例 1: 簿记员工作中的喜悦与加薪
- **问题**: 洛克菲勒的第一份工作是天不亮起床、办公室昏暗的簿记员，条件艰苦。
- **方法论的使用**: 他没有感到乏味，反而热爱办公室里的一切繁文缛节，全心投入工作。
- **结论**: 热爱工作才能享受工作的恩惠与欢乐，态度决定工作回报。
- **结果**: 老板不断加薪，为日后创业打下良好基础。

### 案例 2: 三个石匠的故事
- **问题**: 三人做同样的雕刻工作，被问"你在做什么"。
- **方法论的使用**: 一人视工作为惩罚，一人视工作为义务养家糊口，第三人视工作为雕刻完美艺术品。
- **结论**: 同样的工作，态度不同，工作的意义与人生感受截然不同。
- **结果**: 态度重塑了他们对工作的体验，也决定了他们的成长空间。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 职业倦怠，对工作失去热情。
2. 失业后重返职场，需要重建工作的意义感。
3. 团队执行力差，士气低落，需要重新激发投入度。
4. 初入职场，不适应工作节奏，容易抱怨。
5. 对工作报酬或内容不满，陷入消极情绪。

### 语言信号 (用户的话里出现这些就应激活)

- "工作好累"
- "不想上班"
- "工作没有意义"
- "如何爱上工作"
- "职业倦怠怎么办"
- "态度决定一切"

### 与相邻 skill 的区分

- 与 `action-first` 的区别: `action-first` 聚焦停止拖延、立即行动；`attitude-reframe` 聚焦调整对工作本身的认知与情绪。
- 与 `deliberate-hardship` 的区别: `deliberate-hardship` 聚焦主动选择艰难任务磨砺自己；`attitude-reframe` 聚焦重构现有工作的意义与体验。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **识别当前态度模式**
   - 完成标准: 判断用户把工作视为"惩罚""义务"还是"乐趣/荣耀"。
   - 判停条件: 若工作环境存在严重不公或违法侵害，建议先解决实际问题而非单纯调整心态。

2. **找到可重新定义的具体元素**
   - 完成标准: 从当前工作中找出至少一个可以被重新解读的具体任务、关系或成长点。
   - 判停条件: 若完全找不到任何积极元素，需考虑是否是岗位或环境本身不匹配。

3. **将"不得不做"转为"选择去做"**
   - 完成标准: 帮助用户看到留在当前工作中的主动选择理由，而非被动承受。
   - 判停条件: 若用户确实没有任何选择余地，需先讨论如何扩大选择空间。

4. **关注成长与长期回报**
   - 完成标准: 引导用户看到工作带来的能力提升、人脉积累、职业资本等长期价值。
   - 判停条件: 若长期回报明显不存在，需帮助用户评估是否应换工作。

5. **建立每日态度检查机制**
   - 完成标准: 设计一个简单的日常练习，如每天记录工作中一个积极发现或一点成长。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 工作环境存在严重不公、职场霸凌或违法侵害，需要维权或离职。
- 用户面临的是实际薪酬、负荷或职业路径问题，需要具体行动而非心态调整。
- 用户只是想用"积极心态"自我催眠，逃避解决真实问题。

### 作者在书中警告的失败模式

- **把工作当惩罚或义务**: 视工作为苦役会让人筋疲力尽、效率低下，无法体会工作带来的成长与快乐。
- **洛克菲勒53岁的健康崩溃**: 无止境地追求财富目标、过度忧虑紧张，最终损害健康，说明态度调整不能替代休息与平衡。

### 作者的盲点 / 时代局限

- 洛克菲勒强调态度决定一切，容易忽视劳动条件、组织公平与结构性因素对 worker 幸福感的影响。
- 现代职场中，"热爱工作"不能成为要求员工无条件加班或接受低薪的借口。

### 容易混淆的邻近方法论

- 与"心灵鸡汤"的区别: 态度重塑不是否认困难，而是主动选择看待工作的视角，并配合实际行动。
- 与"躺平/辞职"的区别: 态度重塑是在现有岗位上寻找意义；躺平或辞职是另一种选择，各有适用场景。
