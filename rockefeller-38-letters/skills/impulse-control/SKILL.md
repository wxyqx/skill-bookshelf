# 控制冲动决策

## R — 原文 (Reading)

> 无论何时，冲动都是我们最大的敌人。在做每一个决定的时候都不被自己的情感所左右，要就事论事，完全根据自己的需要来做出明智的决定。
>
> — 约翰·D·洛克菲勒，第十七封 冲动毁己，忍耐则刚

---

## I — 方法论骨架 (Interpretation)

洛克菲勒把"冲动"视为决策的最大敌人。情绪高涨时做出的决定，往往不是服务于长远目标，而是服务于一时痛快。控制冲动不是软弱，而是一种基于目标利益的冷静策略——先识别情绪触发信号，按下暂停键，把决定重新放回"我需要什么"的轨道上。

这个方法论的核心是"暂停—回看目标—选择回应"。它不要求人没有情绪，而是要求人在情绪最强烈时不做重大决定；用理性判断替代条件反射，让行动服务于真正的利益。

## A1 — 书中的应用 (Past Application)

### 案例 1: 洛克菲勒忍耐克拉克与加德纳
- **问题**: 合伙人克拉克将公司改名为克拉克-加德纳公司，抹除洛克菲勒姓氏，且多次当众贬抑洛克菲勒。
- **方法论的使用**: 洛克菲勒克制怒火，装作若无其事，埋头工作，三年内壮大实力后将加德纳"请"出公司，随后也将克拉克排除出局。
- **结论**: 在实力不足时冲动反击，只会提前暴露意图、破坏事业根基；忍耐是为了等待最佳时机。
- **结果**: 保全了自身利益与事业根基，个人力量随公司壮大，最终登上财富巅峰。

### 案例 2: 安德鲁斯因冲动错失巨富
- **问题**: 安德鲁斯因年终分红方案与洛克菲勒冲突，威胁退出公司。
- **方法论的使用**: 洛克菲勒以百万美元买下其股份；安德鲁斯兴奋认为占了便宜，但当得知洛克菲勒转手赚三十万美元后，恼怒拒绝按原价回购股份。
- **结论**: 一时怨气驱动的决定，可能把已到手的财富拱手让人。
- **结果**: 安德鲁斯错失成为豪富的良机，被一时冲动断送财富。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 被挑衅或激怒，即将说出或做出可能后悔的话或事。
2. 愤怒或兴奋中要做重大商业或个人决定。
3. 谈判中对手试图激怒你，让你失去冷静。
4. 事后常后悔"当时不该那么说/做"。
5. 合作关系紧张，想立刻反击或决裂，但长远利益可能需要忍耐。

### 与相邻 skill 的区分

- 与 `patience-as-strategy` 的区别: `patience-as-strategy` 聚焦在目标利益需要时选择忍耐并等待时机；`impulse-control` 聚焦在情绪强烈时避免做出冲动决定。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **识别情绪触发信号**
   - 完成标准: 帮助用户说出当前情绪（愤怒、羞辱、兴奋、恐惧）以及触发它的具体事件或话语。
   - 判停条件: 若用户只是发泄情绪，先给予共情，再引导其进入下一步。

2. **按下暂停键，设置决策缓冲期**
   - 完成标准: 为当前决定设定一个最小延迟时间（如24小时、睡一觉、走一圈），并明确"在缓冲期内不发送关键信息、不签文件、不做公开表态"。
   - 判停条件: 若涉及紧急人身安全，跳过缓冲期，立即采取保护措施。

3. **回到目标利益计算**
   - 完成标准: 让用户写下"我真正想要的结果是什么""冲动回应会带来什么后果""冷静回应会带来什么后果"。
   - 判停条件: 若用户无法说出长远目标，先帮助澄清目标，否则无法评估选项。

4. **选择服务于目标的回应**
   - 完成标准: 输出 2-3 个冷静后的可选回应，并标注每个回应对目标的利弊。
   - 判停条件: 若所有选项都明显损害目标，建议进一步延迟或寻求第三方意见。

5. **复盘冲动模式**
   - 完成标准: 帮助用户识别自己的常见触发器（特定人、特定话语、特定场景），并建立下一次的预防机制。
   - 判停条件: 若用户不愿回顾，提供简单的自我监控清单即可。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要快速反应的紧急安全场景（如火灾、暴力威胁、医疗急救）。
- 用户只是需要正常情绪宣泄，而非做决策。
- 用户以"控制冲动"为名长期压抑正当愤怒或权益诉求。
- 问题本质是能力或信息不足，而非情绪冲动。

### 作者在书中警告的失败模式

- **冲动决策、被情绪左右**: 一时冲动会破坏合作关系、错失良机，甚至把已到手的财富拱手让人。
- **被侮辱激怒而失态反击**: 情绪失控会让对手抓住弱点，破坏谈判与合作关系。
- **把忍耐等同于软弱**: 忍耐是基于目标利益的策略，不是无原则退让；该反击时仍要反击。

### 作者的盲点 / 时代局限

- 洛克菲勒的案例多发生在商业权力斗争中，现代职场与家庭关系中的情绪管理需要更多共情与沟通技巧，而非单纯的延迟决策。
- 书中对"冲动"的警告可能过于强调理性，忽视了某些情境下情绪本身携带的重要信息。

### 容易混淆的邻近方法论

- 与"情绪管理/情商"的区别: 控制冲动决策是情绪管理的一个子集，聚焦在决策前的暂停与目标校准。
- 与"非暴力沟通"的区别: 非暴力沟通强调表达感受与需求；控制冲动决策强调不在情绪峰值做决定。
