# 当下行动

## R — 原文 (Reading)

> 计划影响结果，但行动决定结果。一个稍微有些瑕疵的构思得以成功实践，要强过千个空想而未付诸实践的完美想法。
>
> — 约翰·D·洛克菲勒，第五封 当机立断，当下行动

---

## I — 方法论骨架 (Interpretation)

洛克菲勒认为，周密计划固然重要，但如果没有行动，计划就毫无价值。他反对"等到万事俱备才行动"的完美主义拖延，主张在计划"足够好"时果断出击，用实践来迭代和完善想法。"当下行动"不是鲁莽冲动，而是把宏大目标拆解为可执行的小步骤，从最小行动开始推进。

这个方法论的核心是"启动优先": 一个稍有瑕疵的构思付诸实践，胜过千个空想而未实践的完美想法。行动本身就是最好的计划和反馈来源。

## A1 — 书中的应用 (Past Application)

### 案例 1: 擦鞋童谈股票引发抛售
- **问题**: 1929年股市崩溃前夕，擦鞋童与洛克菲勒大谈股票行情。
- **方法论的使用**: 洛克菲勒意识到市场过热，没有继续观望或等待更明确的信号，而是立即将手中股票兑现。
- **结论**: 在判断已经足够清晰时，果断行动胜过反复犹豫。
- **结果**: 成为华尔街崩溃中唯一幸免保全财富的人之一。

### 案例 2: 一口一口吃大象
- **问题**: 宏大目标让人不知从何入手，容易陷入拖延。
- **方法论的使用**: 洛克菲勒用"要想吞掉大象似的庞然大物，我们需要一口一口地吃"来比喻目标拆解。
- **结论**: 把大目标拆解为可执行的小步骤，从当下最小行动做起。
- **结果**: 降低行动门槛，让遥不可及的目标变成可管理的日常任务。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 产品发布一再推迟，总觉得还不够完美。
2. 创业想法长期停留在脑海，从未真正启动。
3. 项目准备过度，分析瘫痪，迟迟不落地。
4. 习惯性等待万事俱备，结果机会被他人抢走。
5. 团队执行力差，会议多、决策少、行动更少。

### 语言信号 (用户的话里出现这些就应激活)

- "还没准备好"
- "等条件成熟了再说"
- "想法很多但没行动"
- "完美主义拖延"
- "如何开始第一步"
- "当下行动"

### 与相邻 skill 的区分

- 与 `planned-luck` 的区别: `planned-luck` 聚焦目标与资源协和、主动策划机会；`action-first` 聚焦计划足够好后立即启动、避免拖延。
- 与 `elephant-bites` 的区别: `elephant-bites` 聚焦把宏大目标拆解为小步骤；`action-first` 聚焦克服启动拖延、立即开始最小行动。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **判断当前状态是准备还是拖延**
   - 完成标准: 区分用户是真的还需要关键信息，还是用"准备"作为拖延的借口。
   - 判停条件: 若目标本身模糊或缺乏基本风险评估，先进入澄清与风险评估分支。

2. **明确最小可行行动**
   - 完成标准: 找出24-72小时内可以完成的、风险可控的最小行动。
   - 判停条件: 若用户无法找到任何可执行的最小行动，回到目标澄清步骤。

3. **设定立即启动的时间节点**
   - 完成标准: 为用户确定一个具体的启动时间，最好是不超过未来72小时。
   - 判停条件: 若用户以各种理由推迟启动时间，追问真实障碍。

4. **执行并收集反馈**
   - 完成标准: 完成最小行动后，记录结果、反馈与下一步调整方向。
   - 判停条件: 若行动后没有产生任何可学习的信息，检查行动是否足够具体。

5. **根据反馈迭代，而非等待完美**
   - 完成标准: 基于反馈快速调整下一步行动，形成"行动—反馈—迭代"循环。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 医疗、航空、金融等高风险合规场景，必须追求极致安全与合规。
- 用户目标本身模糊，尚未定义清楚要解决什么问题。
- 完全没有基本风险评估的盲目行动，可能带来不可逆损失。

### 作者在书中警告的失败模式

- **只说不做的借口派**: 嘴巴比头脑和双手灵活，终身找借口搪塞，最终一事无成。
- **等待完美时机的迟缓派**: 非要等到天时地利人和、百利而无一害才行动，结果机会被他人抢走。

### 作者的盲点 / 时代局限

- 洛克菲勒所处的19世纪商业环境变化相对较慢，"当下行动"的成功依赖对市场的敏锐判断；现代快速变化的环境中，行动需要配合 MVP、用户反馈和快速迭代思维。
- 书中较少讨论"何时不该行动"，现代应用需要更强调风险评估与止损边界。

### 容易混淆的邻近方法论

- 与"鲁莽冲动"的区别: 当下行动是有计划、有最小可行步骤的果断执行；鲁莽冲动是无视风险的盲目冒进。
- 与"分析瘫痪"的区别: 当下行动正是分析瘫痪的解药，但前提是有基本判断而非完全盲目。
