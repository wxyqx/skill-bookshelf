# 长处用人法

## R — 原文 (Reading)

> 一个领导者的职责不在于发现部属的缺点，关键的是发掘并利用部属的优点和特殊才能。……我从不以自己的好恶来当做评选人才的基准，我用人从来不看在他的头顶上有着怎样的耀眼光圈，我更看重的是他在工作中所表现出来的才能。
>
> — 约翰·D·洛克菲勒，第三十封 各为所用，各尽其才

---

## I — 方法论骨架 (Interpretation)

洛克菲勒认为领导者的核心职责不是当"挑错者"，而是当"优点挖掘者"。每个人都有缺陷，但人无完人；把焦点从缺点移到优点，从"他不能做什么"移到"他最适合做什么"，才能把普通团队变成高产团队。

这个方法的关键是：用人不以个人好恶为标准，而以工作才能和效率为标准；岗位配置要让员工做自己喜欢且擅长的事，因为激情会把优点转化为持续产出。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 洛克菲勒重用嗜酒却才华横溢的阿奇博尔德
- **问题**: 阿奇博尔德嗜酒如命，与洛克菲勒严格的禁酒主义形成强烈反差，按个人好恶本应被排斥。
- **方法论的使用**: 洛克菲勒不看生活习惯，而看重阿奇博尔德非凡的领导才能、机敏乐观、过人口才与好斗精神，不断提拔重用。
- **结论**: 才能是岗位配置的唯一标准，个人习惯不在工作评价范围内。
- **结果**: 阿奇博尔德成长为当之无愧的天才领导者，最终接替洛克菲勒的职务。

### 案例 2: 洛克菲勒不以头顶光环选人
- **问题**: 组织选才时容易被学历、头衔、背景等"耀眼光圈"迷惑。
- **方法论的使用**: 洛克菲勒强调用人看的是工作中表现出的才能，而非外在光环。
- **结论**: 真正的才干在行动中体现，不在简历上。
- **结果**: 标准石油聚集了一批实战中证明自己的人，形成强大执行力。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队成员能力不足感明显，但领导者总觉得"没有可用之人"。
2. 绩效面谈只谈短板，员工越谈越丧、越丧越差。
3. 招聘或晋升时，领导者因候选人生活习惯、背景与自己不同而犹豫。
4. 员工长期缺乏动力，工作只是完成任务。
5. 组建新团队或调整岗位时，不知道如何根据长处配置角色。

### 语言信号 (用户的话里出现这些就应激活)

- "这个人满身缺点"
- "团队人岗不匹配"
- "怎么激发员工潜能"
- "用人所长"
- "他工作没激情"
- "人才盘点怎么做"

### 与相邻 skill 的区分

- 与 `bias-free-hiring` 的区别: `bias-free-hiring` 聚焦在招聘晋升中去除个人偏见；`strength-based-management` 覆盖岗位配置、绩效沟通与日常管理中的长处导向。
- 与 `passion-job-fit` 的区别: `passion-job-fit` 更偏向个人职业选择；`strength-based-management` 是领导者用来配置他人的方法。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **诊断当前用人模式**
   - 完成标准: 帮助用户识别自己平时是"挑缺点"还是"找优点"，列出最近三次绩效沟通或人员评估的偏向。
   - 判停条件: 若用户否认存在用人问题，先用阿奇博尔德案例建立共识。

2. **盘点团队长处清单**
   - 完成标准: 引导用户为每个关键成员列出3-5项可转化为工作产出的优点或特殊才能，而非通用优点。
   - 判停条件: 若用户只能列出缺点，使用"忽视缺点、专注优点"的重新框定话术。

3. **匹配"喜欢+擅长+组织需要"三要素**
   - 完成标准: 对每个岗位或项目，明确需要什么成果，再匹配谁最可能喜欢并擅长交付该成果。
   - 判停条件: 若三者无法对齐，进入"调整岗位"或"缩小任务范围"分支。

4. **设计长处激活方案**
   - 完成标准: 输出3-5个具体动作，包括任务分配、授权范围、反馈方式、激励信号。
   - 判停条件: 若方案仍让员工做不喜欢的事，回到步骤3重新匹配。

5. **建立"优点回顾"机制**
   - 完成标准: 设定周期性的一对一或团队会议，专门回顾每个人的长处贡献与成长。
   - 判停条件: 若用户只想一次性调整，说明长处管理需要持续强化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 员工存在严重职业道德问题（如欺诈、贪污、性骚扰、恶意破坏）。
- 员工能力完全不胜任且经过培训、调岗后仍无法达标。
- 组织已经濒临崩溃，需要立即止损而非长处开发。

### 作者在书中警告的失败模式

- **以个人好恶用人**: 领导者只看自己喜欢什么、讨厌什么，错失真正有才能的人。
- **盯着部属缺点**: 聚焦缺点会让员工失去动力，就像期待坏掉的闹钟准时报时一样荒唐。
- **忽视岗位匹配**: 把员工放在不喜欢、不擅长的岗位上，消耗激情与产出。

### 作者的盲点 / 时代局限

- 洛克菲勒时代的岗位边界相对清晰，现代知识工作中"喜欢+擅长+需要"的动态匹配更复杂，需要频繁调整。
- 书中对阿奇博尔德的"嗜酒"采取完全忽视态度，现代企业需要考虑行为是否影响团队安全、合规与文化，不能简单复制。

### 容易混淆的邻近方法论

- 与"优势理论（StrengthsFinder）"的区别: 洛克菲勒的方法更朴素，强调"工作中表现出的才能"和"喜欢做的事"，而非标准化测评结果。
- 与"短板理论"的区别: 长处用人法不是完全不管短板，而是不让短板成为岗位配置的主要决定因素。
