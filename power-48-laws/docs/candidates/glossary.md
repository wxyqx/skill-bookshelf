## g01 权力

```yaml
id: g01
term: 权力
type: core-concept
source_chapter: 前言/译序
author_definition: |
  译序中明确指出："所指的'权力'是一个'泛权力'的概念，并不专指政治权谋，更多的是'控制力'和'操纵力'的代名词。"前言中称"不能拥有权力驾驭他人、掌控事物，对我们来说通常是难以忍受的"，"没有人希望权力减弱，人人都渴望更大的权力。"
key_distinction: |
  常识中"权力"多指政治权力或职位权威。本书的"权力"是泛化的——任何人际关系中的控制力、影响力和操纵力都是权力。它超越道德范畴，不以善恶判断，只以结果论输赢。权力是一场竞赛，不是道德选择。
why_it_matters: |
  下游skill需要理解本书讨论的不是政治权谋而是通用的人际操控方法论。所有法则都建立在"权力=控制力"这一泛化定义之上，理解此定义才能正确迁移法则到非政治场景。
tags: [power, control, core-concept]
```

## g02 迂回

```yaml
id: g02
term: 迂回
type: core-concept
source_chapter: 前言
author_definition: |
  "你必须学会永远要走迂回的路线去获取权力，要掩盖你的精明或狡诈。就像打台球一样，在回弹数次之后才击中目标。"书中称之为"迂回前进艺术"和"迂回隐蔽的艺术"。
key_distinction: |
  常识中"迂回"多为消极的绕远路。本书中迂回是积极、核心的权力获取方式——不是因为没有直线道路而绕行，而是直线道路本身就是陷阱。迂回=以最不显眼的方式实施+优雅风度+掩盖攻击意图，是全书的方法论基石。
why_it_matters: |
  迂回是整本书的元方法论。几乎所有48条法则都是迂回策略的具体应用。不理解迂回概念就无法理解为何本书强调"隐藏""烟幕""沉默""间接"等策略。
tags: [indirection, strategy, core-concept]
```

## g04 名誉/声誉

```yaml
id: g04
term: 名誉/声誉
type: core-concept
source_chapter: 法则5
author_definition: |
  "名誉是权力的基石。仅仅凭借名誉，你就能威慑别人，赢得胜利。名誉一旦受损，你就会陷入无从抵抗、四面楚歌的境地。"声誉拥有"魔法般的力量"——"只要这根魔棒一挥，你的力量就会加倍增大"。
key_distinction: |
  常识中"声誉"是道德品质的社会评价。本书中声誉是一种权力工具和战略资源——它控制世界对你的评断，给予你控制评断的权力，并可以在敌人声誉受损后"冷眼袖手旁观，让公众舆论置其于死地"。声誉是可攻可防的战场，不是静态的道德标签。
why_it_matters: |
  法则5的核心概念。下游skill需要理解声誉在本书中是动态的攻防工具而非静态评价——它需要主动经营、维护、攻击和防御。
tags: [reputation, power-tool, perception]
```

## g05 欺诈

```yaml
id: g05
term: 欺诈
type: core-concept
source_chapter: 前言
author_definition: |
  "欺诈是文明社会高度发达的一种艺术，也是权力角逐场上最强有力的武器。"前言将欺诈与欺骗视为"武器库中最锐利的武器"，是人类区别于动物的能力——"人类之所以与动物有区别，就在于人类有说谎和欺骗的能力"。
key_distinction: |
  常识中"欺诈"是负面道德概念，等同于犯罪或不道德行为。本书将欺诈重新定义为中性的、高度发达的文明艺术和权力核心武器。欺骗和伪装"不应简单地看成是丑恶的和不道德的"——人与人之间的交际互动在多方面都需要欺骗。这是超越道德范畴的工具。
why_it_matters: |
  欺诈是全书的底层世界观之一。如果不理解作者对"欺诈"的中性化定义，整本书的法则都会被误读为邪恶指南而非权力方法论。
tags: [deception, art, weapon, amoral]
```

```yaml
tags: [patience, defense, timing]
```

## g07 朝臣

```yaml
id: g07
term: 朝臣
type: concept
source_chapter: 前言
author_definition: |
  前言以古代宫廷朝臣为模型描述权力博弈："朝臣们处于一种进退两难的境地——既要充分表现出优雅和高贵，又必须以最高妙的手段挫败那些实力强劲的对手。"成功的朝臣"学会了每一个步骤都要巧妙迂回"，"手上戴着天鹅绒的手套，脸上挂着最甜美的微笑"。
key_distinction: |
  常识中"朝臣"是历史名词，指古代宫廷中的官员。本书将"朝臣"泛化为现代权力博弈中的原型角色——"今天我们所面临的权力争斗与古代朝臣的矛盾处境极其相似"。整个世界被比喻为"一个勾心斗角的巨大宫廷"，每个人都是现代朝臣。
why_it_matters: |
  "朝臣"是全书的核心隐喻。所有法则都以朝臣模型为底座——既要文明优雅又要深谋远虑。理解这一隐喻才能理解为何法则反复强调"迂回""隐蔽""优雅"等看似矛盾的策略。
tags: [courtier, metaphor, archetype]
```

## g12 逆转

```yaml
id: g12
term: 逆转
type: structural-term
source_chapter: 各法则
author_definition: |
  每条法则末尾的"逆转"部分讨论法则的例外条件和反转可能——在什么情况下法则不适用或需要反向操作。例如法则5的逆转："这条法则根本就没有逆转的可能。声誉是至关重要的，这条法则是没有例外的。"
key_distinction: |
  常识中"逆转"指反转或改变方向。本书中"逆转"是结构性术语——它是每条法则的必要组成部分，用于界定法则的边界条件和适用例外。有些法则有逆转（如法则1：上司衰落时可盖过风头），有些没有（如法则5：声誉永远重要）。
why_it_matters: |
  理解"逆转"结构有助于下游skill判断每条法则的适用边界——法则不是绝对教条而是有条件的策略，逆转部分定义了条件变更时的应对方式。
tags: [structure, exception, boundary-condition]
```

## g18 声望

```yaml
id: g18

type: concept
```
