## f03 情绪控制框架

```yaml
id: f03
title: 情绪控制框架
type: framework
source_chapter: 前言
source_quote: |

  3. 通用对策：跳出眼前情境，冷静客观思考过去和未来。
  核心原则：情绪反应=失控=失去权力。
tags: [emotion-control, self-regulation, decision]
```

## f04 代价评估法

```yaml
id: f04
title: 代价评估法
type: decision-framework
source_chapter: 前言
source_quote: |
  "你必须学会根据可能付出代价的多少来判断事情。正如尼采所说的：'一件事情的价值，有时并不在于我们从中得到了什么，而在于为此付出什么——即我们所付出的代价'。"
summary: |
  评估任何行动/合作/帮助时，不以可能获得的收益为标准，而以可能付出的代价为标准。关键考量维度：
  - 时间成本（人生苦短，机会稀少）
  - 精神宁静成本（是否打破内心平静）
  - 关系风险（是否牵扯进不该介入的事）
  核心问题永远是："代价是多少？"而非"我能得到什么？"如果代价太昂贵，即使目标有价值也要放弃。
tags: [decision, cost-benefit, opportunity-cost]
```

## f05 结果导向判断（超越道德判断）

```yaml
id: f05
title: 结果导向判断
type: reasoning-method
source_chapter: 前言
source_quote: |
  "在本质上，权力是与道德无关的，是超越道德范畴的……一切都以行动的结果而不是对手的道德意图来决定输赢。你应该以自己的所见所感来衡量对手的策略与力量，至于他的个人意图只会混淆概念、模糊主题，起到欺骗的作用。"
summary: |
  判断他人行动时，永远以结果而非意图为标准。
  - 不以道德判断对手意图：即使朋友心怀善意但结果造成损害，也应在内心大笑其"好意"借口。
  - 道德判断往往是聚积力量的借口。
  - 训练眼睛紧盯行动结果和外部形势变化，不分散注意力。
  - 把权力视为竞赛：感谢对手的礼貌和教养，而不是他们美好的意图。
tags: [judgment, result-oriented, amoral-thinking]
```

## f10 烟幕策略

```yaml
id: f10

  5. 张扬引人注目：江湖医生用娱乐表演掩盖推销意图（有时间限制）
  核心原则：把他人注意力转移到真正意图的相反方向。
```

## f12 声誉攻防法

```yaml
  1. 撒播怀疑的种子（巴纳姆第一招）
  2. 拥有笃实名望后用温文尔雅的嘲讽削弱对手
```

## f15 诚实作为策略

```yaml
id: f15
title: 诚实作为策略

  - 最高明的骗子在某个方面表现出来的诚实是为了掩盖其他方面的不诚实
  - 对权力者而言：训练隐藏真实意图，而非真诚开放
tags: [honesty-as-strategy, deception, persuasion]
```

## f20 研究他人框架
