# 代价评估法

## R — 原文 (Reading)

> 你必须学会根据可能付出代价的多少来判断事情。正如尼采所说的：'一件事情的价值，有时并不在于我们从中得到了什么，而在于为此付出什么——即我们所付出的代价'。
>
> — 罗伯特·格林, 前言

---

## I — 方法论骨架 (Interpretation)

评估任何行动/合作/帮助时，不以可能获得的收益为标准，而以可能付出的代价为标准。关键考量维度：时间成本（人生苦短机会稀少）、精神宁静成本（是否打破内心平静）、关系风险（是否牵扯进不该介入的事）。核心问题永远是"代价是多少？"而非"我能得到什么？"。如果代价太昂贵，即使目标有价值也要放弃。特别注意"隐藏代价"：忘恩负义的代价、暴露意图的代价、打破宁静的代价——这些往往不在表面收益计算中。

## A1 — 书中的应用 (Past Application)

### 案例 1: 迈克尔三世的代价误判
- **问题**: 迈克尔三世任用朋友巴西琉斯，只看到了好处（信任、感恩），没看到代价
- **方法论的使用**: 若用代价评估法——代价包括：朋友会因感恩压力产生怨恨、嫉妒、最终反噬。"忘恩负义"是可预期的人性代价而非道德缺陷
- **结论**: 迈克尔低估了"忘恩负义"这一隐藏的人性代价
- **结果**: 巴西琉斯因怨恨反叛，迈克尔被其杀害

### 案例 2: 侯爵的冲动代价
- **问题**: 侯爵只看到了说出"爱"字的收益（表达真实感情），没看到代价
- **方法论的使用**: 若用代价评估法——代价包括：意图暴露、神秘魅力崩塌、计划功亏一篑。一句话的代价是整个计划
- **结论**: 冲动表态的隐藏代价远超表面收益
- **结果**: 因一句话暴露意图，整个计划功亏一篑

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户面对一个"零投资只需投入时间"的机会，需要评估——"零投资"不代表"零代价"
2. 用户纠结于是否接受某人的帮助/邀请/合作——需要评估隐藏代价
3. 用户在做决策时总是以"能得到什么"为主，想改为以"代价"为主——需要切换决策框架

### 语言信号 (用户的话里出现这些就应激活)

- "这个机会代价大不大"
- "该不该接受这个邀请"
- "值不值得做"
- "cost assessment"
- "代价评估"
- "机会成本"

### 与相邻 skill 的区分

- 与 `result-judgment` 的区别: 代价评估是判断自己行动（看自己付出的代价），结果导向是判断他人行动（看对方造成的结果）。代价评估关注"我要付出什么"，结果导向关注"对方造成了什么"
- 与 `patience-shield` 的区别: 代价评估是决策框架（该不该做），耐心是时机判断（什么时候做）。代价评估关注"做不做的代价"，耐心关注"做的时机"

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出可能的收益**
   - 先问用户: 你想从这件事中得到什么？
   - 完成标准: 收益清单明确

2. **列出可能的代价——三个维度**
   - 时间成本: 人生苦短，这段时间能做什么？机会成本是多少？
   - 精神宁静成本: 这件事是否打破你的内心平静？
   - 关系风险: 这件事是否牵扯进不该介入的事？
   - 完成标准: 三个维度的代价都被评估

3. **问核心问题: "代价是多少？"**
   - 如果代价太昂贵，即使目标有价值也放弃——不以收益诱人程度决定，以代价可承受程度决定
   - 完成标准: 决策基于"代价是否可承受"而非"收益是否诱人"

4. **特别注意"隐藏代价"**
   - 忘恩负义的代价（帮了别人反而被怨恨）、暴露意图的代价、打破宁静的代价
   - 完成标准: 隐藏代价被纳入评估，不只看表面代价

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 紧急情况下必须快速行动——来不及评估，需要直觉决策
- 纯粹的创造性活动——过度评估代价会扼杀创造力，创造需要冒险
- 投资理财的项目回报分析——那是投资分析领域，不是权力框架的代价评估

### 作者在书中警告的失败模式

- 缺乏耐心的虚弱（ce13）：急于求成在时机不成熟时出手，因为只看到收益没看到代价——代价评估的缺失导致冲动行动

### 作者的盲点 / 时代局限

- 过于保守——只看代价可能导致错失真正值得冒险的机会。精神宁静作为成本维度难以量化，容易被滥用为"不想做"的借口

### 容易混淆的邻近方法论

- 与 `result-judgment` 的混淆: 代价评估看"自己付出的"（决策前），结果导向看"对方造成的"（行动后）——时间维度不同
