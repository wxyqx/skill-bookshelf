# 结果导向判断

## R — 原文 (Reading)

> 在本质上，权力是与道德无关的，是超越道德范畴的……一切都以行动的结果而不是对手的道德意图来决定输赢。
>
> — 罗伯特·格林, 前言

---

## I — 方法论骨架 (Interpretation)

判断他人行动时永远以结果而非意图为标准。不以道德判断对手意图：即使朋友心怀善意但结果造成损害，也应在内心大笑其"好意"借口。道德判断往往是聚积力量的借口——用"他是好意"来自我安慰，实际上是在放弃对自身利益的保护。训练眼睛紧盯行动结果和外部形势变化。把权力视为竞赛：感谢对手的礼貌和教养，而不是他们美好的意图。这不是冷酷，而是清醒——意图不可验证，结果可验证。

## A1 — 书中的应用 (Past Application)

### 案例 1: 迈克尔三世被朋友杀害
- **问题**: 迈克尔三世信任朋友巴西琉斯，认为他心怀感恩
- **方法论的使用**: 迈克尔因友谊蒙蔽，用"善意意图"来判断对方，没有看行动结果
- **结论**: 巴西琉斯心怀感恩（善意意图），但行动结果是弑君篡位（毁灭性结果）
- **结果**: 迈克尔被杀害——用意图而非结果来判断，付出了生命代价

### 案例 2: 俾斯麦反战演说
- **问题**: 俾斯麦发表了看似反战的演说，外界难以判断其真实立场
- **方法论的使用**: 以结果而非言辞来判断——最终俾斯麦获得权力并发动战争
- **结论**: 意图（表面上反战）和结果（获得权力最终发动战争）完全不同
- **结果**: 俾斯麦成功统一德国——以结果判断而非被言辞迷惑

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户被同事"好心"办了坏事，纠结该不该追究——用结果还是意图来判断
2. 用户面对对手的"善意"表态，需要判断是否可信——看结果而非言辞
3. 用户在复盘一段失败关系/合作时，纠结于对方"是不是故意的"——以结果定应对策略

### 语言信号 (用户的话里出现这些就应激活)

- "他是好意但是……" / "该看意图还是结果"
- "朋友好心办坏事" / "result-oriented" / "结果导向" / "以结果论"

### 与相邻 skill 的区分

- 与 `emotion-mastery` 的区别: 结果导向是判断方法论（怎么看——如何评价他人行动），情绪控制是自我管理（怎么做——如何管理自己反应）
- 与 `cost-assessment` 的区别: 结果导向是判断他人（看对方行动的结果），代价评估是判断自己（看自己行动的代价）

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出对方的行动结果（不是意图）**
   - 完成标准: 清晰列出实际发生了什么、造成了什么具体损害/收益，不涉及"他为什么这么做"

2. **剥离道德标签**
   - 完成标准: 不用善恶判断，用"这个结果对我有利/有害"来判断，将"他是好意/恶意"暂时搁置

3. **检查自己是否因"好意"标签而忽视了损害**
   - 完成标准: 如果发现自己因对方"是好意"而放任了损害，调整应对策略——以损害程度而非善意程度决定应对
   - 判停条件: 若涉及法律判断（需考虑犯罪意图），则跳到步骤4并提示用户寻求法律意见

4. **以结果决定下一步行动**
   - 完成标准: 能以结果而非意图来制定应对策略——损害大则防范，损害小则观察

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 法律判断场景（必须考虑意图——故意伤害和过失伤害性质不同）
- 亲密关系中的情感修复（需要理解对方意图以修复信任，纯结果导向会破坏关系）

### 作者在书中警告的失败模式

- 道德判断陷阱：因对方"是好意"而忽视损害，或因"是恶意"而高估威胁——导致概念混淆和自欺，用道德标签替代了利益判断

### 作者的盲点 / 时代局限

- 道德虚无主义风险：将道德判断本身定义为"陷阱"可能被用来为不道德行为辩护
- 假设所有人都在玩权力游戏——忽略了存在真正无私的行为

### 容易混淆的邻近方法论

- 与 cost-assessment 的混淆：结果导向看"对方行动的结果"（对方做了什么影响了我），代价评估看"自己行动的代价"（我做了什么要付出什么）
