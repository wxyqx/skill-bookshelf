# 不盖过上司光芒

## R — 原文 (Reading)

> 永远让你的上司感到比你优越。在取悦他们或给他们留下深刻印象的同时，不要过分显露你的才华，否则会适得其反——引发他的恐惧和不安。
>
> — 罗伯特·格林, 法则1

---

## I — 方法论骨架 (Interpretation)

面对权位高于自己的人时的决策框架。核心前提：上司都有不安全感——不安全感程度决定你的隐藏程度。四种伪装方法：故作天真请教（让上司感到聪明）、故意犯无关痛痒的错误（给上司纠正你的机会）、把创意归到上司头上（让上司当发明者）、扮演小丑让上司当主角。逆转条件：如果上司是正在坠落的星星，可以加速其衰败；如果地位稳固，则耐心等待。这不是虚伪，而是在权力不对等关系中的自我保护——你的光芒是上司眼中的威胁。

## A1 — 书中的应用 (Past Application)

### 案例 1: 富凯的豪华宴会（反面）
- **问题**: 1661年，富凯为讨好路易十四举办空前奢华的宴会
- **方法论的使用**: 富凯没有意识到自己的炫耀会让国王感到被盖过光芒
- **结论**: 每幕壮观场景都让国王感到自己被超越，虚荣心和不安全感被激发
- **结果**: 第二天富凯被逮捕，在单人牢房度过最后20年

### 案例 2: 伽利略献给美第奇（正面）
- **问题**: 伽利略需要稳定的资助人，之前分散献给各资助人效果不佳
- **方法论的使用**: 他不再分散，而是集中呈献给美第奇家族，把木星卫星发现包装成宇宙向家族致敬
- **结论**: 把创意和发现归到资助人头上，让资助人感到荣耀
- **结果**: 获得美第奇家族全额薪俸，成为终身宫廷数学家

### 案例 3: 千利休因傲慢雕像被处死（反面）
- **问题**: 千利休受丰臣秀吉宠信后，忘记恩赐来自统治者
- **方法论的使用**: 他没有使用任何隐藏策略，反而让人刻了一尊穿贵族木屐、姿态傲慢的雕像放在皇宫最重要的神殿
- **结论**: 恩宠冲昏头脑，忘记地位是上司赐予的
- **结果**: 被丰臣秀吉赐死

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户新晋升或刚完成重大项目，公司全员称赞，直属上司态度微妙变化
2. 用户发现自己的直属上司最近对自己态度变化（冷淡、挑剔、回避）
3. 用户比上司能力强/学历高/人脉广，不知道如何处理这种能力优势带来的关系压力

### 语言信号 (用户的话里出现这些就应激活)

- "老板好像不太喜欢我" / "上司对我的态度变了"
- "比上司强怎么办" / "盖过老板风头" / "manage up" / "向上管理"

### 与相邻 skill 的区分

- 与 `silence-power` 的区别: 不盖过上司是上下级权力管理（对上），沉默是通用表达策略（对所有）。不盖过上司关注"如何隐藏才华"，silence-power 关注"如何少说话"
- 与 `conceal-intent` 的区别: 不盖过上司是具体场景应用（对上级），隐藏意图是通用信息策略（对所有）。不盖过上司是隐藏意图在上下级关系中的具体化

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **评估上司的不安全感程度**
   - 完成标准: 判断上司地位是否稳固、是否正在衰落、是否极度虚荣——三种情况对应不同策略

2. **选择隐藏策略**
   - 故作天真请教上司意见（让上司感到聪明）
   - 故意犯小错让上司指导（给上司纠正你的满足感）
   - 把创意归到上司头上（让上司当发明者）
   - 表现弱点赢得同情
   - 完成标准: 选择了与上司性格和不安全感程度匹配的策略

3. **逆转判断**
   - 如果上司地位稳固→耐心等待，持续隐藏
   - 如果上司正在衰落→可适度加速（但风险大，需谨慎）
   - 完成标准: 明确当前是隐藏期还是逆转期，并据此行动

4. **验证效果**
   - 完成标准: 上司在他人眼里更加耀眼夺目，你的存在不构成威胁

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 上司有能力且客观公正时——不需要伪装，正常展现实力即可获得认可
- 你本身就是最高决策者时——没有上司，不需要隐藏

### 作者在书中警告的失败模式

- 盖过上司光芒的灾难（富凯）：炫耀才华刺激上司虚荣心和不安全感，导致从恩宠到牢狱
- 天生魅力也是罪（曼弗雷迪王子）：不用做任何努力就盖过了博尔吉亚，被当作威胁消除
- 恩宠冲昏头脑（千利休）：忘记地位是上司赐予的，傲慢招致毁灭

### 作者的盲点 / 时代局限

- 假设所有上司都有不安全感且会因此迫害下属——忽略了安全型领导者的存在
- 宫廷政治语境与现代职场差异：现代组织有制度保护，不完全适用

### 容易混淆的邻近方法论

- 与 conceal-intent 的混淆：不盖过上司是"隐藏才华"（让对方不感到威胁），隐藏意图是"隐藏目的"（让对方不知道你要做什么）
