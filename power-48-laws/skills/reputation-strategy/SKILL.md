# 声誉攻防法

## R — 原文 (Reading)

> "名誉是权力的基石。仅仅凭借名誉，你就能威慑别人，赢得胜利。名誉一旦受损，你就会陷入无从抵抗、四面楚歌的境地。"
>
> — 罗伯特·格林, 法则5

---

## I — 方法论骨架 (Interpretation)

声誉管理的攻防双轨体系。进攻（建立）：选一种特质集中建立、慢慢打基础、让声誉先于你到达——这就是"隆美尔效应"，对手在你的名声面前就先怯了三分。防御：不拼命自我防卫（越辩越显心虚），而是预测攻击方向提前布防。攻击敌人：撒播怀疑种子、用嘲讽削弱、绝不回击过头（回击过头反而暴露报复心）。声誉受损时的修复：结交形象好的人来"漂白"自身。核心洞察：声誉是你不在场时别人对你的评价——它独立于你行动，在你的行动到达之前已先于你工作。

## A1 — 书中的应用 (Past Application)

### 案例 1: 诸葛亮空城计

- **问题**: 诸葛亮城中空虚，面对司马懿15万大军，无力抵抗
- **方法论的使用**: 声誉先于他到达——司马懿因恐惧诸葛亮"智谋无双"的声望，不敢进城。诸葛亮无需动用一兵一卒，仅靠声望就完成了威慑
- **结论**: 声誉本身就是武器，"隆美尔效应"让对手在行动前就退却
- **结果**: 司马懿撤军，诸葛亮以零成本赢得胜利

### 案例 2: 巴纳姆 vs 皮尔声誉战

- **问题**: 巴纳姆想获取皮尔的博物馆，但自己无声望，对方有声望
- **方法论的使用**: 无声望时不直接攻击，而是撒播怀疑种子——质疑皮尔的稳定性；当皮尔反击时，巴纳姆组织仿冒表演嘲弄对手；终获博物馆。攻击策略：用嘲讽而非正面冲突削弱对手
- **结论**: 不回击过头——嘲讽是持续削弱而非一次性毁灭，保持节奏让对手自己失态
- **结果**: 皮尔的声望被侵蚀，巴纳姆获得博物馆

### 案例 3: 弥子瑕声誉逆转

- **问题**: 弥子瑕同一行为（偷驾君主马车/给君主吃剩桃），受宠时被视为美德，失宠后被视为罪过
- **方法论的使用**: 声誉决定了行为的解读——同样的行为，声誉好时是忠心，声誉差时是傲慢。声誉是行为的滤镜
- **结论**: 声誉不是行为的附属品，而是行为意义的决定因素
- **结果**: 从受宠到被惩罚，命运完全取决于声誉的转变，而非行为本身

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户新加入团队/公司，需要建立声誉——需要选一种特质集中展示，让声誉先于自己工作
2. 用户的声誉受到攻击，需要防御——不拼命自辩，而是预测攻击方向并稳定根基
3. 用户面对有声誉的对手，需要削弱对方——撒播怀疑种子，用嘲讽而非正面冲突

### 语言信号 (用户的话里出现这些就应激活)

- "怎么建立口碑"
- "声誉被攻击了"
- "怎么对付有声望的对手"
- "reputation management"
- "名声"
- "口碑"

### 与相邻 skill 的区分

- 与 `conceal-intent` 的区别: 声誉是公开形象管理（管理别人对你的长期评价），隐藏意图是私密信息管理（管理别人此刻知道什么）。声誉=被怎么评价，意图=知道不知道你的计划
- 与 `indirect-approach` 的区别: 迂回是到达目标的路径策略，声誉是到达前的前置资产。迂回关注"怎么走"，声誉关注"走之前你已是什么"

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断当前声誉状态**
   - 完成标准: 明确当前状态是"无声誉/正在建立/已建立/受损"中的哪一种，并据此选择攻防策略

2. **根据状态执行对应策略**
   - 完成标准: 若"无声誉/正在建立"——选一种特质集中展示，慢慢打基础，不急于求成；若"受损/被攻击"——不拼命自辩，预测攻击方向，结交形象好的人漂白；若"攻击有声望的对手"——撒播怀疑种子，用嘲讽削弱，不回击过头
   - 判停条件: 若攻击涉及法律或事实性指控（如欺诈指控），则不走嘲讽路线，应走法律和事实回应

3. **验证"隆美尔效应"是否生效**
   - 完成标准: 声誉在你到达之前已为你工作——对方在接触你之前已因你的名声而调整了对你的态度和行为

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 产品质量和技术能力无法用声誉替代的场景——声誉是放大器不是替代品，产品本身不行则声誉迟早崩塌
- 需要以事实和证据说服的理性决策场景——声誉影响力有限，数据和事实优先

### 作者在书中警告的失败模式

- 回击过头反损自身——爱迪生电死宠物来攻击特斯拉，旁观者注意到的不是特斯拉的问题，而是爱迪生的报复心。过度攻击让攻击者自己的声誉受损

### 作者的盲点 / 时代局限

- 幸存者偏差——只选了成功的声誉案例（诸葛亮、巴纳姆），对同样行为但失败的案例缺乏讨论。不是所有声望建设都能成功
- 社交媒体时代声誉的脆弱性——网络时代声誉可在数小时内崩塌，修复成本远超18世纪，"慢慢打基础"的时间窗口已大幅缩短

### 容易混淆的邻近方法论

- 与 `command-attention`（引人注目）容易混淆——声誉是"人们怎么评价你"（长期社会评价），注目是"人们看不看你"（短期注意力获取）。声誉=被怎么评价，注目=被不被看到
