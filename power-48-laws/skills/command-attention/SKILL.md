# 引人注目策略

## R — 原文 (Reading)

> 人们总是习惯于眼见为实，以外表评判一切，没看见的不算数。因此绝对不要让自己淹没在茫茫人海中，或是被他人遗忘。一定要想方设法突显自我，不惜一切代价让自己惹人注目！
>
> — 罗伯特·格林, 法则6

---

## I — 方法论骨架 (Interpretation)

在以外表评判的世界里，被看见才有权力。创造令人难忘、充满争议的形象将别人的目光吸引到自身——任何一种知名度都会带来权力，受人攻击中伤也要好过无人问津。让自己显得比平庸胆怯的芸芸众生更加高大伟岸、光彩夺目和神秘诱人。招惹丑闻、千方百计突显形象，核心逻辑是"存在感 > 好感"——被记住比被喜欢更重要。一旦成为焦点，必须不断调整保持新鲜感，否则大众会厌倦。

## A1 — 书中的应用 (Past Application)

### 案例 1: 巴纳姆冒充艾弗里牧师引发轰动
- **问题**: 巴纳姆需要让整个镇的人走进他的马戏团，但没有预算做广告
- **方法论的使用**: 1836年马戏团开幕日，有人误认他为臭名昭著的杀人嫌疑犯艾弗里牧师，愤怒群众围堵他——巴纳姆说服群众一起去马戏团证明身份
- **结论**: 任何知名度都带来权力——即使是负面争议也能转化为注意力
- **结果**: 整个镇的人跟着他进了马戏团，开幕日大获成功

### 案例 2: 安迪·沃霍尔以沉默建立神秘
- **问题**: 沃霍尔需要让自己的波普艺术作品获得关注和高价
- **方法论的使用**: 采访中含糊不清、模棱两可，让别人去解释他的作品——越少说作品越值钱
- **结论**: 通过神秘感吸引注意力——被看到但不说透，反而更引人注目
- **结果**: 作品价值飙升，成为波普艺术最知名的代表人物

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户是部门里最资历浅的人，开会总被忽视——需要创造存在感
2. 用户的产品/项目/品牌无人关注——需要通过争议或独特形象吸引注意力
3. 用户害怕争议而选择低调，但发现正在被遗忘——需要意识到被遗忘比被攻击更糟

### 语言信号 (用户的话里出现这些就应激活)

- "开会总被忽视"
- "没人注意到我的工作"
- "害怕争议所以低调"
- "被人遗忘了"
- "command attention"
- "引人注目"
- "存在感"

### 与相邻 skill 的区分

- 与 `reputation-strategy` 的区别: 引人注目是短期注意力获取（被不被看到），声誉是长期评价经营（被怎么评价）。注目=被不被看到，声誉=被怎么评价
- 与 `silence-power` 的区别: 引人注目是"多被看到"，沉默是"少说话"——两者方向相反但可以组合（神秘感既需要被看到又需要少说）

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断当前状态**
   - 判断用户当前处于哪种状态: 被遗忘 / 不够突出 / 有争议但不够 / 已被记住但正在消退
   - 完成标准: 明确用户的注意力现状

2. **选择策略**
   - 根据状态选择: 制造话题（争议性观点/大胆行动） / 创造独特形象（与众不同） / 利用丑闻（即使负面也比无关注好） / 建立神秘感（被看到但不说透）
   - 完成标准: 选定的策略与用户的场景和风险承受力匹配
   - 判停条件: 若负面关注会严重损害核心利益（如法律/合规问题），则跳到步骤 4 提醒风险

3. **执行后管理**
   - 一旦成为焦点，必须不断调整保持新鲜感，否则大众会厌倦——提醒用户注意力需要持续经营
   - 完成标准: 用户有持续维持注意力的计划

4. **验证效果**
   - 检查: 你的名字是否在讨论中被提及，即使伴随争议？
   - 完成标准: 用户的名字/品牌出现在讨论中

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 负面关注会严重损害核心利益的场景（如法律/合规问题、医疗/金融等高信任行业）——在这些领域负面关注可能是毁灭性的
- 已经过度曝光时——继续追求关注会导致审美疲劳和反感
- 纯粹的营销推广需求——那是营销策略领域，不是权力框架的注意力管理

### 作者在书中警告的失败模式

- 被遗忘是最悲惨的命运（ce15）：因害怕争议而选择低调，结果被遗忘，失去所有影响力和机会——比被攻击更糟

### 作者的盲点 / 时代局限

- 注意力经济的极端化——假设任何关注都比无关注好，但负面关注在某些文化/行业中可能是毁灭性的。社交媒体时代"任何关注度都是好热度"的假设已经受到质疑

### 容易混淆的邻近方法论

- 与 `reputation-strategy` 的混淆: 引人注目是"被不被看到"，声誉是"被怎么评价"——前者是注意力获取，后者是评价经营
