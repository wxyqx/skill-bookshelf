# 选择性诚实缴械

## R — 原文 (Reading)

> 事实上，表现诚实确实是一种权力的策略，试图要使别人相信你的高尚、无私和善意的品格。这是一种说服的方式，甚至是一种巧妙的强制的手段。
>
> — 罗伯特·格林, 前言 / 法则12

---

## I — 方法论骨架 (Interpretation)

诚实不是道德选择而是权力工具。完全坦诚会冒犯和伤害人——"诚实是把钝刀子，割得不快血还流得特别多"。选择性诚实是核心：一次真诚的慷慨举动可以解除对方防备。最高明的骗子在某个方面表现诚实是为了掩盖其他方面的不诚实。偶尔表露真实想法以示"坦诚"，诱使对方推心置腹。逻辑链条：诚实 = 让人相信你的高尚品格 = 说服手段 = 巧妙的强制。关键在于"选择性"——选择无关痛痒的内容坦诚，换取在关键议题上的信任和对方的信息暴露。

## A1 — 书中的应用 (Past Application)

### 案例 1: 巴纳姆承认是骗子反获益
- **问题**: 巴纳姆年老后无法再伪装狡猾，欺诈恶名已传开
- **方法论的使用**: 坦然承认自己是骗子，做个"真诚的小人"——当欺诈恶名远扬时，承认本身就是最好的烟幕
- **结论**: 选择性诚实——承认一个已经无法隐藏的缺点，反而赢得信任
- **结果**: 观众反而更喜欢他，因为"坦诚"地承认了自己的狡猾

### 案例 2: 塔里兰式透露
- **问题**: 需要建立信任窗口来推进外交目标，但对方有戒心
- **方法论的使用**: 透露一些显而易见的秘密，表明对别人十分坦诚而信任，诱使对方推心置腹——"偶尔表露真实想法以示坦诚"
- **结论**: 选择性透露小真话来换取对方的大真话
- **结果**: 对方因"坦诚"而放下戒心，暴露更多信息

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户需要向客户/上级承认一个缺陷或劣势，想化劣势为优势——用坦诚缴械
2. 用户在谈判中需要建立信任窗口来推进——用选择性诚实打开缺口
3. 用户想让人敞开心扉但对方有戒心——用坦诚换坦诚

### 语言信号 (用户的话里出现这些就应激活)

- "怎么用坦诚赢得信任"
- "该不该承认这个缺点"
- "选择性诚实"
- "selective honesty"
- "用真话来"
- "坦诚策略"

### 与相邻 skill 的区分

- 与 `conceal-intent` 的区别: 选择性诚实是主动给小真话（给什么），隐藏意图是不暴露真目的（不给什么）。选择性诚实是"用诚实来缴械"，隐藏意图是"用假象来误导"
- 与 `detect-deception` 的区别: 选择性诚实是自己用诚实做武器（自己使用），识别伪装是检测对方的伪装（看穿别人）

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **选择要"坦诚"的内容**
   - 选一个: 无关痛痒的小缺点 / 一个显而易见的秘密 / 一个不影响大局的真实想法
   - 完成标准: 选定的内容不会暴露核心底牌，但足以让对方感到"坦诚"

2. **选择时机**
   - 在需要建立信任窗口的关键时刻使用——不要过早也不要过晚
   - 完成标准: 时机与推进真正目标的需求匹配
   - 判停条件: 若处于法律/合规要求完整披露的场景，则跳到步骤 4 提醒不能使用选择性诚实

3. **观察对方反应**
   - 对方因你的"坦诚"而放下戒心后，注意他暴露的信息和态度变化
   - 完成标准: 记录对方在信任窗口中暴露的新信息

4. **利用信任窗口推进目标**
   - 在信任窗口打开时推进真正的目标——一旦对方重新警惕，窗口关闭
   - 完成标准: 对方因"坦诚"而放下防备，主动暴露更多信息或做出让步

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 核心利益相关的坦诚——不能坦白真正的底牌，选择性诚实的前提是"选择"什么可以坦诚
- 法律/合规要求完整披露的场景——在这些场景中部分坦诚等于欺诈
- 真诚沟通改善关系的场景——那是品格修养，不是权力工具

### 作者在书中警告的失败模式

- 完全诚实的陷阱（ce12）：毫无掩饰的开放让人一览无遗，人们不会敬重一览无遗的人——坦诚冒犯他人招致报复。过度诚实和完全不诚实一样危险

### 作者的盲点 / 时代局限

- 将诚实完全工具化——忽略了真诚的诚实确实存在且能建立真正的信任。将所有诚实都解读为策略，会损害真正基于信任的关系

### 容易混淆的邻近方法论

- 与 `conceal-intent` 的混淆: 选择性诚实是"给小真话"（主动给），隐藏意图是"藏真目的"（主动不给）——方向相反
