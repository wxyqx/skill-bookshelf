# 情绪控制框架

## R — 原文 (Reading)

> "这些技巧中最重要的，也是权力最关键的基石，就是控制自己情绪的能力。对任何情况或局面都产生情绪上的反应是通向权力道路最大的障碍……情绪会遮蔽理性。"
>
> — 罗伯特·格林, 前言

---

## I — 方法论骨架 (Interpretation)

情绪是权力最大的障碍，因为情绪反应等于失控，失控等于失去权力。三大致命情绪各有遮蔽方式：愤怒——破坏性最强，阻碍视野，增强敌人决心，让你做出本不会做的蠢事；爱和感情——使人盲目，看不出对方的算计和危险信号；恐惧——让你在需要冷静时无法思考。核心原则：情绪反应会暴露意图、暴露弱点，因此永远不要让情绪驱动行动。对策不是压抑情绪，而是假装友善而非表现愤怒、绝不让爱与愤怒影响计划、跳出情境以第三方视角冷静思考。关键洞察：情绪是信号但不是方向盘。

## A1 — 书中的应用 (Past Application)

### 案例 1: 科里奥拉努斯多言失国

- **问题**: 罗马战神科里奥拉努斯功勋卓著，竞选执政官时本应稳操胜券
- **方法论的使用**: 他未能控制骄傲这一情绪——在竞选演说中滔滔不绝，傲慢多言，不断暴露自己的不安全感和对平民的蔑视。情绪驱动了表达，表达暴露了弱点
- **结论**: 情绪失控导致他从英雄沦为被审判的囚徒。他的多言不是策略选择，而是情绪失控的外化
- **结果**: 被终生流放，从权力巅峰跌落谷底

### 案例 2: 迈克尔三世被朋友杀害

- **问题**: 拜占庭皇帝迈克尔三世有一个亲密朋友巴西琉斯，实际上此人贪婪且野心勃勃
- **方法论的使用**: 迈克尔因爱和友谊蒙蔽了双眼，完全看不出朋友的危险信号。爱这种情绪让他放松了警惕，丧失了判断力
- **结论**: 爱与信任使他无法理性评估身边人的真实动机，对明显危险视而不见
- **结果**: 最终被这个"朋友"杀害，付出了生命的代价

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在职场遭遇不公或挑衅，愤怒想当场反击——愤怒是此刻最危险的驱动力
2. 用户因对某人的好感而忽视明显的危险信号——爱这种情绪正在遮蔽判断
3. 用户在关键时刻感到无法冷静思考——恐惧或焦虑正在影响决策质量

### 语言信号 (用户的话里出现这些就应激活)

- "气死我了"
- "太愤怒了"
- "冷静不下来"
- "他激怒了我"
- "emotion control"
- "控制情绪"
- "我太喜欢他了所以……"

### 与相邻 skill 的区分

- 与 `silence-power` 的区别: 情绪控制是内在状态管理（不产生情绪反应），沉默是外在表达策略（控制说话的量）。情绪控制关注"内心不被动摇"，沉默关注"嘴上少输出"
- 与 `conceal-intent` 的区别: 情绪控制是自我管理（控制自己的反应），隐藏意图是对外信息管理（控制别人看到什么）。情绪失控会破坏隐藏意图的效果

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别当前情绪类型及其遮蔽效应**
   - 完成标准: 明确说出当前情绪是愤怒/爱/恐惧/骄傲中的哪一种，以及它正在遮蔽什么（判断力/危险信号/视野）

2. **跳出当前情境——用延迟反应切断情绪-行动链**
   - 完成标准: 制定一个"不立刻行动"的策略（如24小时法则、假装友善而非表现愤怒），确保情绪不会直接驱动行动
   - 判停条件: 若用户确认情况需要立即回应（如安全威胁），则跳到步骤3快速评估后行动

3. **评估情绪反应的后果——以第三方视角分析**
   - 完成标准: 回答两个问题——这个情绪反应会暴露什么意图？会增强谁的决心？若回答表明情绪反应对你不利，则用理性对策替代

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要共情和情感连接的亲密关系场景——在婚姻、家庭中完全压抑情绪会破坏关系基础
- 心理健康需要表达和疏导的情境——临床性情绪问题需要专业支持，不是权力框架能处理的

### 作者在书中警告的失败模式

- 情绪反应遮蔽理性 → 无法看清形势 → 无法做准备 → 关键决策错误。愤怒暴露意图让对手防备，爱让你放松警惕看不出心计——两种情绪的致命后果都在书中反复印证

### 作者的盲点 / 时代局限

- 权力等于操控的单一定义忽略了情感信任也是力量来源——有些关系中，真实情感表达反而增强影响力
- 零和博弈假设忽略了合作共赢——在合作场景中，适度的情感投入是建立信任的必要条件

### 容易混淆的邻近方法论

- 与 `strategic-surrender`（示弱）容易混淆——情绪控制是真实的自我管理（内心不被情绪驱动），示弱是策略性表演（故意展示柔弱以降低对方警惕）。一个是控制情绪，一个是利用情绪表象
