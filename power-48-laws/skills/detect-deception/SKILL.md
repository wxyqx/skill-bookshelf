# 天真伪装识别法

## R — 原文 (Reading)

> 那声称或显示自己天真单纯的人最老奸巨滑！
>
> — 罗伯特·格林, 前言

---

## I — 方法论骨架 (Interpretation)

识别"天真/道德/不玩权术"伪装下的权力策略。声称不玩权术的人通常是最精于权术的——他们用高尚道德的表象掩盖权力操作。四种识别信号：反复强调自己"不懂政治"、总是以道德高地发言、公开示弱但实际利益不受损、声称天真但行动结果总是对其有利。真正无意于权位的人不会公开宣称自己的弱势以博得同情——公开宣称本身就是一种主动操作。平等口号可能是按个人意志重新分配奖励的策略，看似无私的表态往往是最高明的伪装。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 巴纳姆承认是骗子反获益
- **问题**: 巴纳姆年老后无法再伪装狡猾，欺诈恶名已传开，继续伪装不可行
- **方法论的使用**: 反其道而行——坦然承认自己是骗子，做个"真诚的小人"，用承认本身就是一种伪装策略
- **结论**: "真诚的小人"本身就是一种伪装策略——当欺诈恶名远扬时，承认本身就是最好的烟幕
- **结果**: 观众反而更喜欢他，因为他"坦诚"地承认了自己的狡猾

### 案例 2: "黄孩"韦尔假装深信诱饵
- **问题**: 韦尔需要让人相信他编造的假故事是真的
- **方法论的使用**: 骗术大师假装深信不疑自己的假故事——表面上的热诚和"坦诚"是最高明的伪装，让人觉得"他这么相信，那一定是真的"
- **结论**: 声称天真/深信不疑本身就是一种权力操作手段
- **结果**: 令人难以怀疑其真实性，骗术成功

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户遇到反复强调自己"不玩政治"的人，不确定是否可信——需要识别天真伪装
2. 用户面对一个总是以道德高地发言的同事/合作方——需要判断这是真道德还是权力策略
3. 用户怀疑某人的"天真"是伪装但不确定——需要系统化的识别信号

### 语言信号 (用户的话里出现这些就应激活)

- "他说自己不懂政治，能信吗"
- "总是站在道德高地说话"
- "这人看起来很天真"
- "detect deception"
- "识别伪装"
- "谁在装"

### 与相邻 skill 的区分

- 与 `people-reading` 的区别: 天真伪装识别是特定检测（识别伪装者），研究他人是通用分析（看透所有人）。识别伪装关注"谁在演"，研究他人关注"谁在想什么"
- 与 `selective-honesty` 的区别: 天真伪装识别是检测对方的伪装（看穿别人），选择性诚实是自己用诚实做武器（自己使用）

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **收集行为信号**
   - 询问/观察对方是否: 反复强调自己不玩政治？总是以道德高地发言？公开示弱但利益不受损？
   - 完成标准: 至少收集到 2 个以上的行为信号

2. **对比言行**
   - 将对方声称的天真与实际行动结果对比——行动结果是否总是对其有利？
   - 完成标准: 明确对方的言行一致程度

3. **检查"平等"策略**
   - 是否要求平等对待但实际在争取分配权？是否用"公平"口号谋取个人优势？
   - 完成标准: 判断对方的"道德"主张是否服务于实际利益

4. **做出判断并制定应对策略**
   - 综合以上信号判断对方是真正天真还是在伪装，并决定应对策略（保持距离/反向利用/直接对质）
   - 完成标准: 用户有明确的判断和可执行的应对方案

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对方确实是真诚和谦虚的人——不是所有谦虚都是伪装，过度怀疑会损害真诚的关系
- 反诈骗/金融诈骗场景——那是法律和反诈教育领域，不是权力框架的伪装识别

### 作者在书中警告的失败模式

- 宣称不玩权术的陷阱（ce11）：相信"不玩政治"的人是单纯的，结果被其权力操作收割——天真本身可能是最高明的伪装

### 作者的盲点 / 时代局限

- 偏执倾向——假设所有声称天真的人都在伪装，忽略了真正谦虚的人存在。将所有道德表态都解读为权力策略，会陷入"看谁都是骗子"的偏执

### 容易混淆的邻近方法论

- 与 `people-reading` 的混淆: 识别伪装是"检测特定策略"（谁在演天真），研究他人是"通用分析"（看透所有人）
