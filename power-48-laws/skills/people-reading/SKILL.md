# 研究他人与弱点识别

## R — 原文 (Reading)

> 永远不要去区分谁是你应该研究的，谁是你可以信赖的。永远不要完全信任任何人，而应该研究每一个人，包括朋友和你所爱的人。
>
> — 罗伯特·格林, 前言 + 法则33

---

## I — 方法论骨架 (Interpretation)

研究和了解他人的方法论。核心原则：不区分"应研究的"和"可信赖的"——研究每一个人，包括朋友和爱人。永远不完全信任任何人。必须成为出色的心理学家，能透过重重迷雾洞悉别人隐藏的动机。每个人都有弱点（贪婪/虚荣/恐惧/不安全感），找到它就是找到了操控的杠杆。这是开启欺骗、防御、社交和影响的无限可能性的最了不起的能力。方法：观察言行不一致之处、识别弱点类型、设计小测试验证、建立心理档案以预测行为。

## A1 — 书中的应用 (Past Application)

### 案例 1: 迈克尔三世不研究朋友
- **问题**: 迈克尔三世信任朋友巴西琉斯，认为他心怀感恩值得托付
- **方法论的使用**: 迈克尔没有使用研究方法——他没有研究巴西琉斯的真实性格（贪婪、野心），因友谊蒙蔽看不到危险
- **结论**: 不区分"可信赖的"和"应研究的"——朋友也需要研究
- **结果**: 迈克尔被巴西琉斯杀害——不研究他人的人付出致命代价

### 案例 2: 塔里兰研究敌人
- **问题**: 塔里兰需要找到推翻拿破仑的同盟者，在众多选择中找到最可靠的人
- **方法论的使用**: 塔里兰深入研究富歇的性格，知道他"对我无所求会努力证明价值"，精准识人后选择结盟
- **结论**: 研究他人的弱点、动机和行为模式，是做出正确联盟决策的前提
- **结果**: 成功与富歇结盟，反对拿破仑阵营逐步扩大

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户即将进入新团队/新环境，需要快速了解权力格局和关键人物
2. 用户面对一个关键人物（客户/合作方/上级），不确定是否可信，需要识别其真实意图
3. 用户在人际交往中总是"看错人"，需要系统性的识人方法来提高准确率

### 语言信号 (用户的话里出现这些就应激活)

- "怎么看出他真实想法" / "该不该信任这个人"
- "怎么快速了解新团队" / "reading people" / "识人" / "看人准不准"

### 与相邻 skill 的区分

- 与 `enemy-to-ally` 的区别: 研究他人是分析框架（怎么看人——看透所有人），化敌为友是行动策略（怎么转化——转化特定对手）。研究他人关注"如何看透"，化敌为友关注"如何利用"
- 与 `conceal-intent` 的区别: 研究他人是看透对方（信息获取——从对方获取信息），隐藏意图是隐藏自己（信息保护——保护自己的信息）

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **收集信息：观察、听其言、观其行**
   - 完成标准: 记录对方说了什么、做了什么，特别注意言行不一致的地方——言行差距是隐藏动机的信号

2. **识别弱点类型**
   - 贪婪（对什么贪？）
   - 虚荣（哪方面虚荣？）
   - 恐惧（怕什么？）
   - 不安全感（什么让他不安？）
   - 完成标准: 至少识别一个明确的弱点类型及其具体表现

3. **验证：设计小测试**
   - 给一个小诱惑看反应，或给一个选择看偏好
   - 完成标准: 通过观察到的反应确认或修正初步判断

4. **建立心理档案**
   - 动机、弱点、可预测的行为模式
   - 完成标准: 能预测对方在特定情境下的行为——"如果发生X，他会做Y"

5. **持续更新**
   - 完成标准: 随着新信息出现持续修正档案，不固化为刻板印象

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 亲密关系中的深度信任建立——不能永远研究而不信任，关系需要一定程度的"不研究"才能深入
- 专业合作场景中的基本尊重——过度分析同事会显得偏执且破坏合作氛围

### 作者在书中警告的失败模式

- 过度分析导致偏执——不是所有人都在玩权力游戏，研究他人不等于怀疑一切
- 因友谊或亲密蒙蔽双眼——迈克尔三世因不研究朋友而被杀，但反向极端是将所有关系都视为权力博弈

### 作者的盲点 / 时代局限

- 假设所有人都有隐藏动机和可利用弱点——忽略了有些人确实表里如一
- 将研究他人等同于寻找操控杠杆——忽略了研究中性和善意的理解可能

### 容易混淆的邻近方法论

- 与 enemy-to-ally 的混淆：研究他人是"看透所有人"（分析方法），化敌为友是"转化特定对手"（行动策略）。先研究再转化，但关注点不同
