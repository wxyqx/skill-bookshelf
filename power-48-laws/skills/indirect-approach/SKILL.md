# 迂回前进艺术

## R — 原文 (Reading)

> "你必须学会永远要走迂回的路线去获取权力，要掩盖你的精明或狡诈。就像打台球一样，在回弹数次之后才击中目标。你的行动必须周密计划，以最不显眼的方式来实施。"
>
> — 罗伯特·格林, 前言

---

## I — 方法论骨架 (Interpretation)

权力获取不靠直线冲刺，而靠迂回包抄。所有行动应经中间步骤、间接路径达成目标，而非直奔目的。核心原则有三：第一，掩盖精明——让对方看不到你的聪明和算计；第二，以最不显眼的方式实施——每一步看起来都与最终目标无关；第三，通过优雅和迂回掩盖真正的攻击意图。这是"铁手伸进天鹅绒手套里"——力量被柔软的外表包裹。直接路线会激发抵抗，间接路线让对方在不知情中配合你。迂回不是拖延，而是让目标在对方看来自然达成、甚至像是他自己的想法。

## A1 — 书中的应用 (Past Application)

### 案例 1: 俾斯麦反战演说 (1850年)

- **问题**: 俾斯麦是狂热主战派，渴望通过战争统一德国，但直接主张开战会被国王视为危险激进分子而拒绝
- **方法论的使用**: 俾斯麦没有直接推进战争目标，而是发表反战演说，走了一条完全迂回的路线——用与真实意图相反的公开立场掩盖最终目的
- **结论**: 国王被其"温和理性"的姿态打动，认为他是可信赖的人，任命他为内阁大臣
- **结果**: 俾斯麦逐步升为首相，最终以自己的节奏和方式完成了德国统一，目标在迂回路径中完美实现

### 案例 2: 马尔伯勒公爵诱使法军自毁要塞 (1711年)

- **问题**: 英军想摧毁法方防线上的要塞，但直接攻击代价巨大且法军会重建
- **方法论的使用**: 马尔伯勒占领要塞后留少量兵力驻守，然后故意撤退让法军"夺回"要塞。法军判断英军意在长期占据要塞，于是自己动手将要塞摧毁以防英军再来
- **结论**: 目标（摧毁要塞）由敌方自己完成，通路畅通，英军零损耗
- **结果**: 法军在不知情中执行了英军的计划，迂回策略完美达成战略目标

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户的提案被否决，但目标不变，想换个方式让同样想法被采纳——直接路线已被堵死，需要间接路径
2. 用户想接近某人（客户/上级/投资人）但直接联系会被拒绝——需要通过中间人或中间步骤建立连接
3. 用户在谈判中需要让对方"自己想到"对自己有利的方案——目标需在对方看来是自然结果而非外部强加

### 语言信号 (用户的话里出现这些就应激活)

- "怎么让他们接受我的想法"
- "直接说没用"
- "有没有迂回的办法"
- "indirect approach"
- "绕一下"

### 与相邻 skill 的区分

- 与 `conceal-intent` 的区别: 迂回是整体战略框架（路径选择——走什么路），conceal-intent 是具体战术（信息隐藏——说什么话做什么表象）。迂回关注"从哪条路到达目标"，隐藏意图关注"对外展示什么信息"
- 与 `silence-power` 的区别: 沉默是迂回在沟通中的具体应用（少说话也是一种间接），迂回是更宏观的方法论（涵盖路径、行动、时间的整体规划）

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确最终目标，但不直接朝目标行动**
   - 完成标准: 能用一句话写出最终目标，且当前不打算直接表达或直奔此目标

2. **设计中间步骤和间接路径——找到2-3个中间节点**
   - 完成标准: 列出至少2个中间节点，每个节点看起来与最终目标无直接关联，但逻辑上通向目标
   - 判停条件: 若目标本身具有紧迫时效（如数小时内必须完成）且无迂回空间，则跳到步骤4直接评估

3. **以最不显眼的方式实施——每一步看起来都与最终目标无关**
   - 完成标准: 每一步的表面理由独立成立，不依赖"最终目标"来解释其合理性

4. **验证迂回效果——对方是否在不知情中配合**
   - 完成标准: 对方在达成你的目标时，认为这是他自己的想法或自然结果，而非你的推动

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 紧急危机需要直接行动时——迂回需要时间成本，时效性高于策略性时应直接行动
- 对方已经知道你的意图时——迂回的前提是信息不对称，意图已暴露则迂回无意义

### 作者在书中警告的失败模式

- 侯爵冲动说出"爱"字，精心构建的神秘瞬间崩塌——迂回策略被一时冲动毁掉，意图暴露后全部努力归零

### 作者的盲点 / 时代局限

- 有时直接透明的沟通可能比迂回更有效——作者未讨论在信任基础已建立的关系中，直接表达反而能增强信任的场景
- 迂回策略的道德成本——持续掩盖真实意图可能导致长期关系中的信任侵蚀，作者未充分讨论

### 容易混淆的邻近方法论

- 与 `conceal-intent` 容易混淆——迂回是路径选择（走哪条路到目标），隐藏意图是信息管理（对外说什么话做什么表象）。两者常配合使用但层次不同
