# 阶段 1.5 — 三重验证结果

## 说明

本文件汇总阶段 1（5 个 extractor）产出的候选单元，并给出三重验证（V1 跨域 / V2 预测力 / V3 独特性）的判定。

## 未通过验证的候选（已移入 rejected/）

1. **f11 竞争性毁灭**：V2 较弱，预测力主要限于长期投资，与 circle-of-competence / margin-of-safety 重叠度高。
2. **f12 市场先生**：V3 不通过，该概念来自格雷厄姆而非芒格独创，更适合作为案例或术语，不独立成 skill。
3. **f13 自我催化**：V1 跨域证据不足，主要作为 lollapalooza-effect 的子概念。
4. **f14 五何原则**：V3 不通过，是管理学通用原则，非芒格独创。
5. **f15 全归因治学方法**：V1 较弱，主要在第九讲出现，应用范围窄。
6. **f16 二级与更高级别效应**：V3 不通过，属于系统思维常识。
7. **f17 正向与逆向结合的运算法则**：与 inversion-thinking 高度重叠。
8. **f18 终身学习机器**：V3 不通过，属于通用成功学概念。
9. **f19 普朗克知识与司机知识**：V3 不通过，故事性强但可 skill 化价值低。
10. **f20 信任之网**：V1 跨域证据不足，主要出现在第十讲。
11. **p08 保持独立与客观**：与 inversion-thinking / circle-of-competence 重叠。
12. **p12-p22 多数原则**：或过于投资专用，或与已有 skill 重叠，未独立成 skill，保留为引用素材。
