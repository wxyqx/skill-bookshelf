# 能力圈

## R — 原文 (Reading)

> “最重要的是，别愚弄你自己，而且要记住，你是最容易被自己愚弄的人。”
> “只在自己明确界定的能力圈内行事。”
>
> — 查理·芒格，第二章《投资原则检查清单》

> “如果你确有能力，你就会非常清楚能力圈的边界在哪里。如果你问起（你是否超出了能力圈），那就意味着你已经在圈子之外了。”
>
> — 查理·芒格，第四章第十一讲《人类误判心理学》

---

## I — 方法论骨架 (Interpretation)

能力圈不是“我会做什么”或“我擅长什么”，而是“我能判断别人是否错了”的领域。它要求你诚实回答：我真的理解这件事的核心变量吗？我能识别这个领域里常见的错误吗？

芒格把“承认无知”视为智慧的开端。能力圈的作用是给自己划定一个行动边界：圈内可以果断行动，圈外要么学习扩展，要么直接说“不懂”并避开。

关键动作：
1. 用具体问题测试自己是否真懂（而不是只会复述名词）。
2. 识别自己“自以为懂”的时刻——这通常是越界的信号。
3. 对圈外机会保持礼貌但坚决的拒绝。

能力圈可以扩大，但扩展需要深度学习、实践反馈和时间，不是看几篇文章就能实现的。

## A1 — 书中的应用 (Past Application)

### 案例 1：伯克希尔远离衍生品
- **问题**：衍生品市场规模巨大，很多机构参与，是否应该进入？
- **方法论的使用**：芒格和巴菲特认为衍生品是“大规模杀伤性金融武器”，其复杂性和系统性风险超出他们的能力圈，于是主动远离。
- **结论**：不懂的东西不碰，即使别人都在赚钱。
- **结果**：2008 年金融危机中，伯克希尔没有因衍生品遭受重大损失。

### 案例 2：索罗斯与德鲁肯米勒的科技股教训
- **问题**：看到别人在科技股上赚大钱，是否应该跟进？
- **方法论的使用**：索罗斯和德鲁肯米勒因妒忌（能力圈外情绪）进入自己不擅长的领域，蒙受惨重损失。
- **结论**：圈外行动常被情绪驱动，而非理性判断。
- **结果**：成为芒格在第三章中用来警告“妒忌”的经典反例。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户想投资、创业、转行或接项目，但不确定自己是否真懂。
2. 用户看到别人在某领域赚钱，产生 FOMO（害怕错过）。
3. 用户被要求评价一个超出专业范围的方案。
4. 用户想拒绝一个机会，但需要更清晰的判断依据。
5. 用户想扩展自己的能力圈，但不知道从何开始。

### 语言信号

- “这个我能做吗？”
- “我不懂这个领域，但机会好像很好……”
- “我要不要跟风？”
- “能力圈 / circle of competence”
- “超出我的能力范围”

### 与相邻 skill 的区分

- 与 `multi-disciplinary-thinking` 的区别：后者回答“用什么框架分析”，前者回答“我是否有资格分析”。
- 与 `margin-of-safety` 的区别：安全边际是“错了也有缓冲”，能力圈是“尽量不进入自己不懂的局”。
- 与 `stop-doing-list` 的区别：Stop Doing List 是主动列出的禁忌清单，能力圈是动态的自我认知边界。

## E — 可执行步骤 (Execution)

1. **用“下一个问题”测试真懂程度**
   - 完成标准：用户能连续回答 3 个深入的“为什么/会怎样”问题，且能识别该领域的常见错误。
   - 示例问题：“如果你错了，最可能因为什么原因？”“这个领域里谁的观点最可能被高估？”

2. **识别越界信号**
   - 完成标准：列出 3 个“我已经在能力圈外”的语言或情境信号。
   - 常见信号：开始用大量新名词、需要依赖别人判断、情绪被收益或恐惧主导。

3. **划定行动规则**
   - 完成标准：明确圈内可做什么、圈外应拒绝或学习。
   - 圈内：可以独立分析并承担后果。
   - 圈外：直接说“我不懂”，或只做学习性投入。

4. **如果需要扩展能力圈**
   - 完成标准：制定 90 天学习计划，包括原始资料、实践测试和反馈来源。
   - 注意：扩展不是“多看资讯”，而是“能判断别人是否错了”。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户已经明确懂这件事，只是需要执行细节。
- 问题是关于他人的能力圈评价，而非自我评估。
- 用户需要情绪安慰，而不是能力判断。

### 作者在书中警告的失败模式

- **假装在能力圈内**：收集一些术语就以为自己懂。
- **越界后加倍下注**：越不懂越爱用大仓位证明自己是“学习能力强的”。
- **把运气当能力**：因为一次成功就认为自己懂了。

### 作者的盲点 / 时代局限

- 芒格的能力圈主要来自法律、投资和商业，对科技、互联网的理解相对保守。
- 他低估了在快速变化领域，能力圈边界需要更频繁地重新评估。

### 容易混淆的邻近方法论

- 与“舒适区”的区别：能力圈是认知边界，舒适区是情绪边界。能力圈内的事可能很不舒服。
