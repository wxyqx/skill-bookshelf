# 人类误判心理学

## R — 原文 (Reading)

> “人类的——经常出错但总体上很有用——心理倾向相当多，而且相当不同。大量的心理倾向的自然结果就是社会心理学的重要原理：认知往往取决于情景，所以不同的情景通常会引起不同的结论，哪怕是同一个人在思考同一个问题的时候也是如此。”
>
> — 查理·芒格，第四章第十一讲《人类误判心理学》

> “人类的大脑即使在有所知觉的时候，也会错误地估量它感知到的东西，因为大脑只能感知到鲜明的对比，而无法像精密的科学仪器那样以科学的单位来估算感知的变化。”
>
> — 查理·芒格，第四章第十一讲《人类误判心理学》

## I — 方法论骨架 (Interpretation)

人类误判心理学是芒格总结的一套约 25 种常见心理倾向清单，用来解释人为什么会系统性地做出错误判断。这些倾向大多在进化中有用，但在现代社会中常常失灵。

它的核心用法不是“背清单”，而是：
1. 在决策前快速扫描：哪些倾向可能影响我？
2. 在决策后复盘：我犯了哪种倾向？
3. 在组织中设计制度：如何防止这些倾向害人？

25 种心理倾向：
1. 奖励和惩罚超级反应倾向
2. 喜欢/热爱倾向
3. 讨厌/憎恨倾向
4. 避免怀疑倾向
5. 避免不一致性倾向
6. 好奇心倾向
7. 康德式公平倾向
8. 艳羡/妒忌倾向
9. 回馈倾向
10. 受简单联想影响的倾向
11. 简单的、避免痛苦的心理否认
12. 自视过高的倾向
13. 过度乐观倾向
14. 被剥夺超级反应倾向
15. 社会认同倾向
16. 对比错误反应倾向
17. 压力影响倾向
18. 错误衡量易得性倾向
19. 不用就忘倾向
20. 化学物质错误影响倾向
21. 衰老——错误影响倾向
22. 权威——错误影响倾向
23. 废话倾向
24. 重视理由倾向
25. lollapalooza 倾向

## A1 — 书中的应用 (Past Application)

### 案例 1：联邦快递的夜班效率
- **问题**：夜班工人不能按时完成工作，怎么办？
- **方法论的使用**：芒格用激励机制偏见解释：按小时付薪激励的是“工作更久”，而公司真正想要的是“快速无差错完成”。改为按班次付薪并允许提前回家后，效率大增。
- **结论**：激励机制会改变行为，也会扭曲判断。
- **结果**：联邦快递解决了长期难题。

### 案例 2：芒格错失贝尔里奇石油
- **问题**：为什么聪明人也会做出错误决定？
- **方法论的使用**：芒格承认自己因“被剥夺超级反应倾向”，在有机会以同样低价再买 1500 股时拒绝了，原因是现金安排和心理上的“已经错过”感。
- **结论**：即使了解心理学，也不能完全免疫。
- **结果**：少赚约 540 万美元，成为他反复讲述的教训。

### 案例 3：哥伦比亚广播公司波斯信使综合征
- **问题**：为什么 CEO 会反复做出错误交易？
- **方法论的使用**：董事长佩利讨厌坏消息，导致下属只报喜不报忧。这是“受简单联想影响的倾向”（坏消息与报信人绑定）。
- **结论**：组织文化会放大个人心理倾向。
- **结果**：哥伦比亚广播公司逐渐衰落。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户做了一个判断，事后发现“明显错了”，想知道为什么。
2. 用户面对销售、谈判、广告、招聘等可能被心理操控的场景。
3. 用户想理解团队或组织为什么会集体犯错。
4. 用户想设计制度来减少自己或他人的错误判断。
5. 用户想了解为什么自己会“明知不该却控制不住”。

### 语言信号

- “我怎么会犯这种错？”
- “为什么我会相信这个？”
- “人类误判心理学 / cognitive bias”
- “是不是被洗脑/被操控了？”
- “我明知不该，但就是想……”

### 与相邻 skill 的区分

- 与 `two-track-analysis` 的区别：双轨分析是使用心理倾向的决策框架，本 skill 是心理倾向清单本身。
- 与 `checklist-method` 的区别：检查清单是通用防错工具，本 skill 专门针对认知偏差。
- 与 `circle-of-competence` 的区别：能力圈是认知边界，本 skill 是认知机制缺陷。

## E — 可执行步骤 (Execution)

1. **识别当前场景类型**
   - 完成标准：判断用户处于“决策前/决策后/被影响/设计制度”四类中的哪一类。

2. **快速扫描关键倾向**
   - 完成标准：根据场景，从 25 种倾向中挑选最相关的 3–5 种。
   - 常见场景映射：
     - 投资决策：激励偏见、过度乐观、自视过高、社会认同、被剥夺反应。
     - 谈判/销售：回馈倾向、社会认同、喜欢/热爱、权威、对比错误。
     - 团队决策：避免不一致性、社会认同、自视过高、激励机制。
     - 招聘/评价：自视过高、喜欢/热爱、受简单联想影响、第一印象偏见。

3. **分析具体影响机制**
   - 完成标准：对每个选中的倾向，回答：
     - 它如何在这个场景中起作用？
     - 它可能让我忽略什么？
     - 谁会利用这个倾向来影响我？

4. **设计防御措施**
   - 完成标准：为每个关键倾向设计 1 条具体对策。
   - 示例：
     - 社会认同 → 问自己：“如果别人都不这么做，我还会做吗？”
     - 过度乐观 → 强制计算最坏情况。
     - 激励偏见 → 检查对方的激励结构，而非只听其说辞。

5. **建立复盘清单**
   - 完成标准：决策后记录实际触发了哪些倾向，更新个人“常见误判档案”。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户有临床心理疾病或需要专业心理咨询。
- 用户只是想情绪发泄，不需要分析。
- 问题是纯逻辑或数学问题，没有心理判断成分。

### 作者在书中警告的失败模式

- **学了清单就以为自己免疫**：芒格自己也常犯错。
- **把倾向当借口**：用“我有偏见”来合理化错误。
- **忽视 lollapalooza 倾向**：多种倾向同时作用时，后果会被放大。
- **只贴标签不分析**：只说“这是社会认同”，没说明具体如何影响当前判断。

### 作者的盲点 / 时代局限

- 芒格的心理学来自上世纪五六十年代教材和自学，部分术语与当代认知心理学不完全一致。
- 他的清单偏西方商业语境，对集体主义文化中的某些心理动力覆盖不足。
- 他没有提供严格的双盲实验证据，更多依赖个人观察和案例。

### 容易混淆的邻近方法论

- 与“行为经济学”的区别：行为经济学是学术研究，芒格的误判心理学是实践清单。
- 与“批判性思维”的区别：批判性思维是一套通用技能，误判心理学是具体偏差清单。
