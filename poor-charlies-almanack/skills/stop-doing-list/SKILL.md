# Stop Doing List

## R — 原文 (Reading)

> “查理一般会先注意应该避免什么，也就是说，先弄清楚应该别做什么事情，然后才会考虑接下来要采取的行动。‘我只想知道我将来会死在什么地方，这样我就可以永远不去那里啦。’这是查理很喜欢的一句妙语。无论是在生活中，还是在生意场上，查理避开了‘棋盘’上那些无益的部分，把更多的时间和精力用在有利可图的区域，从而获得了巨大的收益。”
>
> — 查理·芒格，第二章《芒格进行商业分析和评估的“多元思维模型”》

> “生活和生意上的大多数成功来自你知道应该避免哪些事情：过早死亡、糟糕的婚姻等等。避免染上艾滋病、在路口和火车抢道以及吸毒。”
>
> — 查理·芒格，第三章《怎样变得幸福、富裕，以及其他建议》

---

## I — 方法论骨架 (Interpretation)

Stop Doing List（停止做清单）是“逆向思维”的直接落地工具。它不是目标清单，也不是待办清单，而是明确列出“绝对不做/不再做”的事项。

芒格认为，人生和投资的大多数成功来自避免灾难性错误，而不是追求极致聪明。先清除棋盘上的无益区域，再把时间和精力投入到有利可图的区域。

一个好的 Stop Doing List 有三个特征：
1. **具体**：不是“不要犯错”，而是“不要熬夜到 2 点后工作”“不要投资不懂的加密货币”。
2. **可执行**：能在行动前快速判断“这件事是否在清单上”。
3. **与个人失败史绑定**：基于自己过去付出的代价，而不是泛泛的“好习惯”。

## A1 — 书中的应用 (Past Application)

### 案例 1：芒格的“避免犯傻体系”
- **问题**：如何在投资中超越聪明人？
- **方法论的使用**：芒格通过检查清单和逆向思维，先避免常见错误。
- **结论**：光是“避免犯傻”就能超越许多比你聪明的人。
- **结果**：伯克希尔长期保持较低的重大错误率。

### 案例 2：生活成功的“避免清单”
- **问题**：如何过上幸福的生活？
- **方法论的使用**：芒格列出“避免早逝、糟糕婚姻、毒品、危险行为”。
- **结论**：幸福来自排除坏事，而不只是追求好事。
- **结果**：这成为他回答“如何生活成功”的核心答案。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户做完逆向思维，得到了一堆“失败路径”，需要落地为具体规则。
2. 用户反复犯同一类错误，想建立禁止机制。
3. 用户想减少干扰，把精力集中在高价值领域。
4. 用户在做年度计划时，希望明确“不做什么”。
5. 用户想设计组织或团队的行为红线。

### 语言信号

- “我总是在同一个地方跌倒。”
- “不做什么比做什么更重要。”
- “stop doing list / 停止做清单”
- “我要排除什么？”
- “哪些事是红线？”

### 与相邻 skill 的区分

- 与 `inversion-thinking` 的区别：逆向思维是思考方向，Stop Doing List 是逆向思维的产物。
- 与 `checklist-method` 的区别：检查清单是决策前审视，Stop Doing List 是行为红线。
- 与 `circle-of-competence` 的区别：能力圈是认知边界，Stop Doing List 是行动禁令。

## E — 可执行步骤 (Execution)

1. **收集失败路径**
   - 完成标准：从逆向思维、复盘、或个人历史中提取 5–10 条最常见的失败路径。
   - 方法：
     - 问自己：“我过去一年最昂贵的错误是什么？”
     - 问：“如果我想毁掉这个目标，我会做什么？”

2. **转化为具体禁止项**
   - 完成标准：把每条失败路径改写成一条可判断的“不做”规则。
   - 示例：
     - “不要因为害怕错过而投资不懂的项目。”
     - “不要在晚上 11 点后回复工作邮件。”
     - “不要在未读招股说明书前下单。”

3. **设定触发条件**
   - 完成标准：为每条禁止项设定“一旦出现这个信号，就启动禁令”的触发条件。
   - 示例：
     - 信号：朋友推荐一个“稳赚”项目 → 禁令：先查是否在能力圈内。

4. **建立监督机制**
   - 完成标准：确定谁或什么机制能提醒用户触发禁令。
   - 示例：投资备忘录、问责伙伴、自动化规则。

5. **定期回顾更新**
   - 完成标准：每季度复盘一次，删除失效项，新增新发现的禁止项。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户正在探索新方向，需要试错空间。
- 用户把 Stop Doing List 当作逃避责任的工具。
- 禁止项过于宽泛，变成口号而非规则。

### 作者在书中警告的失败模式

- **清单太短**：只列大道理，不具体。
- **清单太长**：几十条禁令让人记不住、执行不了。
- **不更新**：过去的失败路径不一定适用于未来。
- **明知故犯**：没有监督机制，清单沦为摆设。

### 作者的盲点 / 时代局限

- 芒格的 Stop Doing List 来自投资和人生经验，对创新型工作的“可尝试边界”讨论不足。
- 有时过度强调避免错误，可能抑制有益的冒险。

### 容易混淆的邻近方法论

- 与“禁忌清单”的区别：Stop Doing List 是主动设计，不是被动禁忌。
- 与“风险管理”的区别：风险管理是概率思维，Stop Doing List 是行为禁令。
