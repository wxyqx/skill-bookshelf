# 机会成本

## R — 原文 (Reading)

> “配置——正确地配置资本是投资者最重要的工作。记住，最好的用途总是由第二好的用途衡量出来的（机会成本）。好主意特别少——当时机对你有利时，狠狠地下赌注吧（配置资本）。别‘爱上’投资项目——要依情况而定，照机会而行。”
>
> — 查理·芒格，第二章《投资原则检查清单》

---

## I — 方法论骨架 (Interpretation)

机会成本是经济学的基础概念，也是芒格资源配置的核心视角：任何资源用于一件事，就放弃了用于其他事的收益。真正的“成本”不是花了多少钱，而是“第二好的用途”是什么。

在投资中，机会成本意味着：
- 资金投给 A，就不能投给 B。
- 如果 B 的预期收益更高，那么 A 的实际成本就是 B 的收益。
- 因此，平庸的机会也要被拒绝，因为等待更好的机会本身有价值。

机会成本思维让“什么都不做”成为一个有意义的决策。芒格称之为“正确地配置资本是投资者最重要的工作”。

## A1 — 书中的应用 (Past Application)

### 案例 1：芒格的“耐心等待”
- **问题**：如何处理现金？
- **方法论的使用**：芒格认为现金的机会成本不是通胀损失，而是“保留抓住伟大机会的能力”。
- **结论**：持有现金的代价，低于盲目投资的代价。
- **结果**：伯克希尔在机会来临时有充足弹药。

### 案例 2：集中投资伟大公司
- **问题**：为什么要集中投资而不是分散？
- **方法论的使用**：因为好主意很少，当遇到伟大公司时，应该下重注。
- **结论**：机会成本的逻辑支持集中投资。
- **结果**：伯克希尔长期持有可口可乐、美国运通等伟大公司。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户在多个项目/机会中选择，不知道哪个更值得投入。
2. 用户考虑是否要接受一个“还不错”的机会。
3. 用户想评估“什么都不做”是否合理。
4. 用户在做时间管理和优先级排序。
5. 用户讨论投资、职业、学习路径的选择。

### 语言信号

- “我该选 A 还是 B？”
- “这个机会不错，但……”
- “机会成本 / opportunity cost”
- “不做这个，我能做什么？”
- “第二好的选择是什么？”

### 与相邻 skill 的区分

- 与 `patience-and-action` 的区别：耐心是行动节奏，机会成本是资源比较。
- 与 `margin-of-safety` 的区别：安全边际是容错，机会成本是选择。
- 与 `checklist-method` 的区别：检查清单是防错流程，机会成本是评估标准。

## E — 可执行步骤 (Execution)

1. **明确资源约束**
   - 完成标准：确定用户要配置的资源类型：时间、金钱、注意力、精力、关系资本。

2. **列出所有可行选项**
   - 完成标准：包括“什么都不做”和“继续等待”也是选项之一。

3. **评估每个选项的预期收益**
   - 完成标准：用同一维度比较（如年化收益、长期价值、学习收益）。
   - 注意：不要只看名义收益，要看风险调整后的收益。

4. **计算机会成本**
   - 完成标准：对最佳选项，明确写出“我放弃了什么”。
   - 公式：选择 A 的机会成本 = 所有放弃选项中收益最高的那个。

5. **做出去留决策**
   - 完成标准：
     - 如果 A 明显优于第二好选项：选择 A。
     - 如果 A 只是略好，且风险更高：等待或选择更安全的第二好选项。
     - 如果没有选项明显优于现金/等待：什么都不做。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 资源几乎无限，不需要做选择。
- 用户只是需要执行，不需要比较。
- 用户把机会成本当作无限拖延的借口。

### 作者在书中警告的失败模式

- **忽视机会成本**：以为不花钱就没有成本。
- **高估可见选项**：忽略“等待更好机会”这个隐性选项。
- **用机会成本逃避决策**：永远等待“更好的机会”，永远不行动。
- **把机会成本当唯一标准**：不考虑风险、能力和安全边际。

### 作者的盲点 / 时代局限

- 芒格的机会成本思维偏投资，对人生的机会成本（如陪伴家人、健康）的量化讨论较少。
- 在高度不确定的新兴领域，第二好选项的收益难以估计。

### 容易混淆的邻近方法论

- 与“沉没成本”的区别：沉没成本是已经发生的不可回收成本，机会成本是放弃的潜在收益。
- 与“比较优势”的区别：比较优势是不同主体之间的分工，机会成本是同一主体不同选择之间的取舍。
