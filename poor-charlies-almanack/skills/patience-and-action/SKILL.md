# 耐心与果断

## R — 原文 (Reading)

> “赚大钱的诀窍不在于买进卖出……而在于等待。”
>
> — 杰西·利弗莫尔，被芒格引用，第二章《芒格进行商业分析和评估的“多元思维模型”》

> “耐心——克制人类天生爱行动的偏好。‘复利是世界第八大奇迹’（爱因斯坦），不到必要的时候，别去打断它。避免多余的交易税和摩擦成本，永远别为了行动而行动。幸运来临时要保持头脑清醒。”
>
> — 查理·芒格，第二章《投资原则检查清单》

> “决心——当合适的时机出现时，要坚决地采取行动。机会来临的次数不多，所以当它来临时，抓住它。”
>
> — 查理·芒格，第二章《投资原则检查清单》

---

## I — 方法论骨架 (Interpretation)

耐心与果断是一枚硬币的两面：绝大多数时间克制行动偏好、安静等待；只有遇到高置信度、高赔率的机会时，才果断重仓出击。

芒格把投资比作泰德·威廉姆斯的棒球：把“击球区”划成格子，只打落在最佳格子里的球。对较差的机会保持不动，哪怕全场都在挥棒。

关键动作：
1. **定义你的最佳击球区**：明确什么情况才值得你行动。
2. **区分“行动”与“进展”**：等待和学习本身就是进展。
3. **用机会成本评估每一次行动**：频繁的小行动会消耗你抓住大机会的弹药。
4. **机会来临时毫不犹豫**：一旦出现符合标准的机会，就要敢于下重注。

## A1 — 书中的应用 (Past Application)

### 案例 1：泰德·威廉姆斯的 77 格击球区
- **问题**：如何在棒球中持续高绩效？
- **方法论的使用**：泰德·威廉姆斯只在自己最有把握的格子挥棒，其他球一律放过。
- **结论**：不挥棒也是一种高度纪律性的行动。
- **结果**：成为历史上最伟大的击球手之一。

### 案例 2：伯克希尔的“坐等投资法”
- **问题**：如何处理大量现金？
- **方法论的使用**：芒格和巴菲特宁可持有现金和国债多年等待，也不为了行动而行动。
- **结论**：耐心保护复利不被打断。
- **结果**：减少交易费用、减少错误、享受复利。

### 案例 3：考勤卡思想实验
- **问题**：如何改善一生中的投资决策？
- **方法论的使用**：巴菲特给学生一张只有 20 格的考勤卡，每格代表一生的重大投资机会。
- **结论**：限制机会数量会迫使人更慎重。
- **结果**：这是一种心理工具，帮助克服行动偏好。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户看到别人都在行动，自己却很犹豫。
2. 用户担心错过某个机会，想“先投了再说”。
3. 用户手中持有现金或资源，不知道是该等待还是出击。
4. 用户做了一个决定后反复后悔，想降低决策频率。
5. 用户想在高机会来临时更果断。

### 语言信号

- “我是不是太保守了？”
- “别人都动了，我要不要也动？”
- “机会难得，错过就没了。”
- “耐心 / patience / 等待”
- “频繁交易 / 行动偏好”

### 与相邻 skill 的区分

- 与 `opportunity-cost` 的区别：机会成本是“放弃的收益”，耐心与果断是“何时行动”的节奏。
- 与 `margin-of-safety` 的区别：安全边际是“错了也有缓冲”，耐心是“等到对的时候”。
- 与 `checklist-method` 的区别：清单帮助判断机会质量，耐心帮助克制冲动。

## E — 可执行步骤 (Execution)

1. **定义最佳击球区**
   - 完成标准：列出 3–5 条“只有在满足这些条件时才行动”的标准。
   - 示例：高置信度、高赔率、在能力圈内、有安全边际、机会成本低。

2. **评估当前机会**
   - 完成标准：用 1–5 分给当前机会在以下维度打分：
     - 置信度
     - 赔率
     - 能力圈内程度
     - 安全边际
     - 不可逆程度
   - 判停条件：如果总分低于阈值，明确建议“等待”。

3. **识别行动偏好信号**
   - 完成标准：列出 3 个自己“为了行动而行动”的典型信号。
   - 常见信号：害怕错过、厌倦无聊、需要向他人证明自己很忙。

4. **等待期间的学习清单**
   - 完成标准：如果建议等待，给出用户在此期间应做的 2–3 项准备工作。
   - 示例：阅读相关书籍、跟踪关键指标、扩展能力圈。

5. **机会来临时的果断机制**
   - 完成标准：如果机会满足所有标准，给出“现在就行动”的明确建议，并提醒用户避免过度分析。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 紧急避险或安全问题。
- 已经有明确截止日的执行事项。
- 用户把“等待”当作拖延的借口。

### 作者在书中警告的失败模式

- **为了行动而行动**：频繁交易、频繁换工作、频繁做决策，消耗复利。
- **机会来了却犹豫**：准备不足导致不敢下注。
- **把耐心等待当懒惰**：等待是主动选择，不是被动逃避。
- **过早重仓**：把普通机会当成最佳击球区。

### 作者的盲点 / 时代局限

- 芒格的案例来自投资，机会窗口可以等待数年。在互联网、科技创业等快速变化领域，某些窗口一旦关闭不可复现。
- 他较少讨论“等待”在个人关系或健康中的应用。

### 容易混淆的邻近方法论

- 与“拖延症”的区别：拖延是逃避，耐心是主动选择。
- 与“优柔寡断”的区别：优柔寡断是不敢决定，耐心是清楚何时该决定。
