# 双轨分析

## R — 原文 (Reading)

> “从个人的角度来讲，我已经养成了使用双轨分析的习惯。首先，理性地看，哪些因素真正控制了涉及的利益；其次，当大脑处于潜意识状态时，有哪些潜意识因素会使大脑自动以各种方式形成虽然有用但往往失灵的结论？前一种做法是理性分析法——就是你在打桥牌时所用的方法，认准真正的利益，找对真正的机会，等等。后一种做法是评估那些造成潜意识结论——大多数是错误的——的心理因素。”
>
> — 查理·芒格，第二章《芒格进行商业分析和评估的“多元思维模型”》

---

## I — 方法论骨架 (Interpretation)

双轨分析是芒格做复杂决策时的固定习惯：同时运行两条轨道。

**轨道一：理性轨道**。识别真正控制利益的因素、真正的机会、真实的约束条件。这就像打桥牌时认准牌面和概率。

**轨道二：心理轨道**。识别潜意识因素（激励、社会认同、损失厌恶、自视过高等）如何自动形成“虽然有用但往往失灵”的结论。

多数人只跑轨道一，结果反复被自己的大脑欺骗。也有人只跑轨道二，陷入过度怀疑。两条轨道结合，才能既看清现实，又看清“我会怎么误判现实”。

## A1 — 书中的应用 (Past Application)

### 案例 1：评估投资机会
- **问题**：为什么一个看起来很有吸引力的投资机会可能实际很危险？
- **方法论的使用**：轨道一分析商业模式、竞争优势、估值；轨道二检查自己是否被“怕错过”“贪婪”“社会认同”影响。
- **结论**：只有当轨道一和轨道二都通过，才值得行动。
- **结果**：帮助芒格避开许多“理性上说得通、心理上被操控”的陷阱。

### 案例 2：理解泰德·威廉姆斯击球区
- **问题**：为什么等待最佳机会如此困难？
- **方法论的使用**：轨道一说明“等待高概率球”是最优策略；轨道二解释人类“行动偏好”会让我们想挥棒。
- **结论**：理性策略与人性冲动冲突，需要纪律。
- **结果**：把耐心从抽象品质变成可执行规则。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户对一个决策感到矛盾，理性和直觉在打架。
2. 用户想知道“我是不是被情绪/偏见影响了”。
3. 用户分析谈判、竞争、投资或人事决策。
4. 用户想更客观地评估一个自己很喜欢或很讨厌的方案。
5. 用户在复盘时想区分“判断错了”和“执行错了”。

### 语言信号

- “我知道应该做 A，但就是想选 B。”
- “理性告诉我……但我控制不住……”
- “双轨分析 / two-track analysis”
- “我是不是被情绪影响了？”
- “真正控制利益的因素是什么？”

### 与相邻 skill 的区分

- 与 `psychology-of-misjudgment` 的区别：后者是心理倾向清单，前者是使用清单的决策框架。
- 与 `checklist-method` 的区别：检查清单是流程工具，双轨分析是内容框架。
- 与 `multi-disciplinary-thinking` 的区别：后者提供学科模型，双轨分析提供理性+心理的双重视角。

## E — 可执行步骤 (Execution)

1. **明确决策问题**
   - 完成标准：用一句话写出要决策的问题或要分析的现象。

2. **轨道一：理性分析**
   - 完成标准：回答以下问题：
     - 真正控制利益的因素是什么？
     - 各方的真实激励是什么？
     - 有哪些硬数据/事实/基础概率？
     - 如果不考虑情绪，最优选择是什么？

3. **轨道二：心理分析**
   - 完成标准：识别可能影响判断的心理倾向，从芒格清单中勾选相关的：
     - 激励偏见
     - 喜欢/热爱或讨厌/憎恨
     - 社会认同
     - 被剥夺超级反应
     - 自视过高
     - 对比错误
     - 可得性偏见
     - 避免不一致性
   - 对每个勾选的项目，回答：“它可能让我怎么看这个问题？”

4. **交叉验证**
   - 完成标准：
     - 如果轨道一和轨道二结论一致：可以行动。
     - 如果轨道一支持但轨道二强烈反对：暂停，设计隔离机制。
     - 如果轨道二支持但轨道一不支持：警惕心理操控。

5. **形成行动建议**
   - 完成标准：根据双轨结果，给出具体下一步，包括需要补充的信息或需要等待的条件。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户只是想发泄情绪，不需要分析。
- 问题已经完全明确，没有心理判断成分。
- 用户处于急性压力状态，需要先稳定情绪。

### 作者在书中警告的失败模式

- **只跑轨道一**：理性分析完美，却被潜意识偏见带偏。
- **只跑轨道二**：怀疑一切，无法行动。
- **把心理轨道当借口**：用“我有偏见”来合理化错误决策。
- **轨道二流于表面**：只列心理名词，没具体分析它们如何影响当前判断。

### 作者的盲点 / 时代局限

- 芒格的心理轨道主要来自认知偏差，对情感、依恋、创伤等深层心理因素覆盖有限。
- 他的框架偏男性化、理性化，对关系决策的指导力较弱。

### 容易混淆的邻近方法论

- 与“理性决策模型”的区别：双轨分析明确承认理性会受心理扭曲。
- 与“正念/觉察”的区别：正念是情绪调节，双轨分析是决策工具。
