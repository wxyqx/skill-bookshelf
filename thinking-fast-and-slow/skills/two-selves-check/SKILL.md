# 双自我决策核查（时长分量 + 预期后悔矫正）

## R — 原文 (Reading)

> "必须同时考虑记忆自我和体验自我，因为它们的利益并不总是一致的。"
>
> — 丹尼尔·卡尼曼，第35章

---

## I — 方法论骨架 (Interpretation)

你有两个利益不一致的"自我"：**体验自我**回答"现在舒服吗"，按时间总量感受生活；**记忆自我**回答"总体怎么样"，按峰终+时长忽视评分——而且它垄断决策权。于是我们为"值得讲述的故事"付费，而过程中的大多数时刻无人代言。

核查程序：
1. **分别提问**：体验自我——"这个选择的过程中，大多数时刻我会舒服吗？"（按一天/一年的时间分配估算）；记忆自我——"它会留下怎样的峰值与结尾？值得讲述吗？"
2. **认账**：两者都合法——消费与仪式常常是为记忆自我买单（合法），恢复精力的休闲是为体验自我（也合法）。错的是**不知道在为谁花钱**，或让记忆自我永远独裁。
3. **时长分量重算**：评价一段经历时强迫按时间长度加权所有时刻，对冲"多加 5 年还算幸福的日子，总体评价反而更低"式的时长忽视。"我会永远记住"是可能出错的预测。
4. **预期后悔矫正**：有人（包括未来的自己）用"你会后悔"劝阻时——识别这是记忆自我按峰终+后见之明做出的裁决；预期后悔通常被夸大（心理免疫系统比想象中强），别为怕后悔放弃值得的行动。重大长期决策的正确姿势是"要么非常慎重（记录理由），要么完全随意"，最糟的是想了三分钟就决定。

## A1 — 书中的应用 (Past Application)

### 案例 1: 冷手实验与打针谜题
- **问题**: 人们选择重复哪种痛苦？
- **方法论的使用**: 80% 的受试者自愿重复"多 30 秒不必要疼痛"的 90 秒版本——因为它的记忆更好；打针谜题显示人们为"从 20 次减到 18 次"付的钱少于"从 6 次减到 4 次"，违反总量逻辑。
- **结论**: 决策效用可以和体验效用背道而驰，且体验效用是判错标准。
- **结果**: 作者据此把"两个自我"列为全书三大区分之一。

### 案例 2: 珍的人生（詹姆斯·迪恩效应）
- **问题**: 给珍的人生"多加 5 年还算幸福的日子"，总体评价会更高吗？
- **方法论的使用**: 实验结果反而更低——记忆自我按故事规则评分："多出来的平凡岁月"稀释了叙事；连父母为子女做的人生评价也如此。
- **结论**: "少即是多"对人生叙事同样成立——这正是需要时长分量账本对冲的地方。
- **结果**: 作者承认时长分量的幸福观"令人信服，但我们不能将其看作完整的幸福理论"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 大额消费/仪式投入（婚礼、摄影、纪念品）在"实用派"与"值得纪念派"之间摇摆。
2. 职业选择：头衔光鲜 vs 日子好过。
3. 被"你会后悔的""趁年轻要拼"类叙事推着走。
4. 复盘婚姻/工作阶段，感觉"明明不坏却说不出好在哪"。

### 语言信号 (用户的话里出现这些就应激活)

- "值得吗""以后回忆起来……""会不会后悔""面子还是里子"
- "为记忆买单""这段经历怎么算"
- 英文：will I regret it / for the memory / experiencing vs remembering self / is it worth it

### 与相邻 skill 的区分

- 与 `dual-ledger` 的区别：双账本是**测量框架**（体验幸福尺 vs 生活评价尺，用于排序方案/政策）；本 skill 是**个人决策核查**，且含后悔矫正。评估公共政策/医疗方案用 dual-ledger，做自己的选择用本 skill。
- 与 `peak-end-design` 的区别：那是给别人设计体验；本 skill 是给自己做选择。

## E — 可执行步骤 (Execution)

1. **双自我提问**：写下两个答案——体验自我（大多数时刻舒服吗，按时间分配估）与记忆自我（峰值/结尾/值得讲述吗）。
   - 完成标准：两个独立答案，未互相覆盖
   - 判停条件：两个自我指向一致 → 直接选择
2. **认领目标**：明确"这次我在为谁买单"，并检查是否一贯偏向记忆自我。
   - 完成标准：目标自我已声明
3. **时长分量重算**：对"总体怎么样"的直觉答案做时间加权重算，检查峰终是否垄断了评分。
   - 判停条件：重算后两答案收敛 → 按收敛结果选择
4. **预期后悔矫正**：若决策理由是"怕后悔"，用"心理免疫系统比想象强"重估；重大决策执行"慎重或随意"两极，禁止三分钟拍板。
   - 完成标准：后悔预估已与"真实后悔的研究结论"对照过

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 两个自我指向一致的低风险选择（程序是浪费）。
- 用户已被明确告知并接受"就是为记忆买单"——认账比程序重要。

### 作者在书中警告的失败模式

- 记忆自我垄断决策导致"为坏体验买单"：人们自愿重复记忆更好、体验更差的选项（ce60）。
- "别做那件事，你会后悔的"是利用预期后悔制造焦虑的标准话术（ce54）——对行动的后悔被高估、对不行动的后悔被低估。
- 把"两个自我/两个系统"当真实心理机制用：它们是有用的虚构，不是神经事实。

### 作者的盲点 / 时代局限

- 何为"正确"地对待自己的过去（时长分量 or 叙事分量）是哲学争议，作者自认"必须接受复杂性，兼收并蓄"——本 skill 交付的是"两本账都看"，不是"体验自我永远对"。
- 相关实验多为假设性情境或女性小样本（作者自注），外推需打折。

### 容易混淆的邻近方法论

- "活在当下"式鸡汤：本 skill 不否定记忆价值，它反对的是**无意识地**让记忆自我独裁。
