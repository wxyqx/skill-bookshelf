# 四步回归纠偏程序

## R — 原文 (Reading)

> "（1）估计GPA的平均值。（2）根据你对证据的印象，确定与其相匹配的GPA。（3）估计你的证据和GPA之间的相关性。（4）如果相关系数为0.30，从平均值向匹配的GPA移动二者之间30%的距离。"
>
> — 丹尼尔·卡尼曼，第18章（作者以"朱莉4岁能阅读，GPA是多少"现场演示）

---

## I — 方法论骨架 (Interpretation)

直觉预测的毛病是**零回归**：系统1用"印象的强度"直接充当"预测的强度"（强度匹配），所以证据越惊艳预测越极端，而全然不管证据有多可靠——辅导员只要听 5 个形容词，给出的预测百分位就和印象百分位一模一样。

四步程序把"印象"变成"预测"：
1. **基线**：对这个案例一无所知时你会猜什么？（类别平均值或基础比率）
2. **直觉值**：按印象匹配出的极端估计——写下来，不修饰。
3. **相关性**：你的证据与结果之间到底有多大关联（0～1）？它等于"证据里有多少与结局共有的成分"。
4. **收缩输出**：预测 = 基线 + r ×（直觉值 − 基线）。

两个补充规则：**信息越少，回归越大**（惊艳但信息薄的候选，运气占比更高，折扣更狠）；**纠偏昂贵**，只在错误代价高的预测上值得做。代价要知道：无偏预测永远不会命中极端结果——如果你是风投或保守银行，误差不对称，允许策略性极端，但要自知那是下注不是信念。

## A1 — 书中的应用 (Past Application)

### 案例 1: 朱莉的 GPA
- **问题**: "朱莉4岁就能流利阅读，她大学四年级的GPA是多少？"
- **方法论的使用**: 系统1想直接匹配出 3.7～3.8；作者现场演示四步：GPA 均值（约3.1）→ 强度匹配值 → 估相关系数 0.30 → 向均值移动 30% 距离。
- **结论**: "4岁阅读"惊燕的是朗读能力，与大学 GPA 的共享成分有限，预测必须大幅回缩。
- **结果**: 配套的辅导员实验证明，不做此程序的人预测值=印象值，零回归。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 给人/产品/项目打预测分：招人评绩效、估创业成功率、估学生表现。
2. 直觉印象极端（"天才！""必扑！"）而证据其实很薄。
3. 比较两个候选：一个惊艳但履历薄，一个扎实但面试平。
4. 复盘自己过去的预测，发现系统性过乐观/过悲观。

### 语言信号 (用户的话里出现这些就应激活)

- "你觉得他能做到多少""预估能卖/能考/能涨到……"
- "这人是不是天才""我觉得至少……"
- 英文：forecast / estimate / regression to the mean / tone down my prediction

### 与相邻 skill 的区分

- 与 `base-rate-first` 的区别：数量型预测用本程序；分类概率判断用贝叶斯。
- 与 `outside-view` 的区别：外部视角负责产出第 1 步的基线（参考类别统计），本程序负责把直觉收缩到基线上——上下游关系，重大预测两个都做。

## E — 可执行步骤 (Execution)

1. **定基线**：找该类别的平均值/基础比率（查得到统计最好，查不到用 `outside-view` 的参考类别法）。
   - 完成标准：基线是一个具体数字
2. **记直觉值**：写下强度匹配给出的极端估计，不自我修正。
   - 完成标准：直觉值已落纸面
3. **估相关性**：证据与结果的相关程度（0～1）。无数据时按"证据能区分好坏结局的程度"保守估。
   - 完成标准：r 有数值且说明理由
   - 判停条件：证据与结果真高度相关（r≈1）→ 程序退化为直觉，直接采用直觉值
4. **计算输出**：预测 = 基线 + r ×（直觉 − 基线）。
   - 完成标准：给出最终数字
5. **方向校验**：检查是否对"惊艳者"回缩不足（金 vs 简：信息越薄折扣越大）。
   - 判停条件：低风险预测 → 跳过全部程序；误差不对称场景（风投/银行）→ 允许策略性偏离但注明"这是下注"

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 分类/概率问题（"他会不会离职"）——用 `base-rate-first`。
- 纯随机单次事件（下一期彩票）——无稳定基线。

### 作者在书中警告的失败模式

- 强度匹配：预测百分位=印象百分位，对优者过乐观、对弱者过悲观（ce18）。
- 惊艳候选陷阱：最惊艳的往往是信息最薄、运气占比最高的（ce30）。

### 作者的盲点 / 时代局限

- 程序要求用户自估相关系数，普通人既无数据也无校准经验——这是全书纠偏程序里最弱的一环（作者也承认纠偏昂贵、且无偏预测会剥夺胜任感）。自估 r 时宁可偏小。

### 容易混淆的邻近方法论

- 普通统计回归：本程序是**没有数据时**的口算替代品，不是拟合模型；有数据时直接做回归。
