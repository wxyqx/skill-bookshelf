# 聚焦错觉纠偏：你会花多少时间想到它

## R — 原文 (Reading)

> "当你想到某件事时，生活中的其他事就都没它那么重要了。"
>
> — 丹尼尔·卡尼曼，第38章

---

## I — 方法论骨架 (Interpretation)

评估"某物对幸福的影响"时，你**正在想着它**——于是它暂时成为生活的全部权重。这就是聚焦错觉：对长期幸福的预测被"评估那一刻的注意力"污染。加州阳光在想象中价值连城，住进去后心情还是由通勤和 deadline 决定；新车只在洗车和想到它时带来快乐。

纠偏两问：
1. **注意力问**：这个改变之后，我实际会在什么时候想到它？一天占多少分钟？
2. **基线问**：一天中大多数时间，我的心情由什么决定？（日常活动结构：睡眠、通勤、社交、工作压力）

若"很少想到它"，它对长期体验幸福的影响就被高估了——把"想到它时的心情"换算成"时长分量下的心情"。反向应用同样重要：**低估那些持续占据注意力的事**（社交质量、通勤、噪音）的价值，它们才是心情的日常来源。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 加州幸福感研究（源于作者的家庭争论）
- **问题**: 加州人真的更幸福吗？
- **方法论的使用**: 作者与妻子争论"要不要搬去普林斯顿"催生了正式研究：加州与中西部学生的生活满意度几乎无差异，但两地学生都相信加州人更幸福、且高估气候权重——双方都被聚焦错觉骗了。
- **结论**: "想到气候时它最重要"，而生活由其余 23 小时构成。
- **结果**: "分析数据时，我知道我赢得了家庭辩论"——他妻子只让步到"只有北加州居民更幸福"。

### 案例 2: 复印机上的一角钱
- **问题**: 生活满意度问卷测的是什么？
- **方法论的使用**: 一半受试者恰好在复印机上捡到一角钱，整体满意度大幅升高——"对生活的满意"很大程度上是"此刻心情"的替代答案。
- **结论**: 生活评价判断是被当下显著性污染的启发式输出。
- **结果**: 与截瘫患者研究互证：旁人估计截瘫患者一年后 68% 时间情绪负面，实际认识的观察者给出 41%——人能观察到适应却不会预测适应。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 重大生活改变决策：搬家、换城市、买房、买车、跳槽、结婚。
2. 预期"得到/失去某物后的长期心情"（情感预测）。
3. 评估别人的选择："他买了那么贵的房子图什么"。
4. 反向：判断哪些"不起眼但每天占据注意力"的因素值得投资。

### 语言信号 (用户的话里出现这些就应激活)

- "搬过去应该会开心很多""有了XX生活就不一样了""要是……就幸福了"
- "想想都兴奋""一想到要……"
- 英文：will this make me happier / focusing illusion / affective forecasting / miswanting

### 与相邻 skill 的区分

- 与 `two-selves-check` 的区别：two-selves 拆"为谁买单"（体验 vs 记忆）；本 skill 修"对长期心情的预测"——它往往在 two-selves 的体验自我提问环节被调用（"大多数时刻舒服吗"正是要防聚焦错觉）。
- 与 `dual-ledger` 的区别：双账本用于方案排序；本 skill 是单点预测的纠偏。

## E — 可执行步骤 (Execution)

1. **写出预测**："XX 会让我的长期幸福提高/降低多少？"（给一个粗略幅度）
   - 完成标准：预测落纸
   - 判停条件：改变对象将持续占据注意力（慢性疼痛、日复一日的通勤）→ 错觉风险低，正常评估
2. **注意力两问**：改变后我多久想到它一次、每次几分钟？一天的心情主要由什么决定？
   - 完成标准：两问有具体答案
3. **换算**：把"想到它时的心情"折算成"时长分量下的心情"（影响=强度×注意力占比）。
   - 完成标准：影响幅度被显著修正或确认
4. **反向检查**：清单里有没有被低估的"常驻注意力"因素（社交、睡眠、噪音）？把它列入交易条件。

---

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 对象确实常驻注意力（慢性病、噪音、通勤时间）——聚焦错觉对此类预测失真小。
- 用户做的是短期决策（下周的事），长期幸福感预测无意义。

### 作者在书中警告的失败模式

- 误求（miswanting）：为"想到它时的感觉"买单，得到后发现适应来得比想象快（ce62）。
- 人们能观察别人的适应却不会预测自己的适应（截瘫研究的 68% vs 41%）。
- 生活满意度问卷答案本身是"此刻心情"的替代——用一次性问卷做重大决策依据是双重点击（c69）。

### 作者的盲点 / 时代局限

- 7.5 万美元收入饱和线出现在同一章，但已被作者 2023 年与 Killingsworth 的对抗性合作修正——凡涉及"金钱买不到幸福"的引用必须降级。
- 第38章有实验仅用女性样本、假设情境（作者自注），外推需打折。

### 容易混淆的邻近方法论

- "幸福取决于心态"式鸡汤：本 skill 不否认改变的价值，它纠正的是**预测权重**——常驻注意力的改变（通勤、社交圈）依然值得认真投入。
