# WYSIATI 怀疑信号：越顺越要停

## R — 原文 (Reading)

> "一个好故事最重要的是信息一致，而不是信息完整。你经常会发现，知之甚少更容易让你将所知的一切融入逻辑连贯的模式。"
>
> — 丹尼尔·卡尼曼，第7章

---

## I — 方法论骨架 (Interpretation)

WYSIATI（所见即一切）是系统1的运作方式：只用眼前已有的信息编故事，从不为"我不知道的东西"留位置。推论很残酷：**信息越少，故事越容易编圆，人就越自信**——因为检验不了它。所以主观自信度不携带任何证据信息，它只测量你的故事有多流畅。

把它反过来用作怀疑信号，重大判断前过三问：
1. 我基于哪些信息？（列出来，数一数）
2. 结论要成立，还需要哪些我**没掌握**的信息？（这是 WYSIATI 的盲区——系统1从不问的问题）
3. 我的信心来自证据质量，还是故事流畅度？

然后强制写出"若为假，最可能是因为什么"——至少一条具体的、可检验的反向情景。写得出来，说明判断还活着；写不出来，说明你在用连贯性代替证据。

## A1 — 书中的应用 (Past Application)

### 案例 1: 泰特洛克的 284 位专家
- **问题**: 政治经济专家的长期预测到底准不准？
- **方法论的使用**: 泰特洛克收集 284 位专家近 8 万条预测：准确性接近随机掷骰，且**最著名的专家最过度自信**——他们把单一叙事推向极致（"刺猬"），故事最圆，错得最狠。
- **结论**: 专家的自信是叙事连贯性的产物，不是证据的产物。
- **结果**: 与第20章"有效性错觉"同源：以色列无领导小组的评估者明知整体预测仅略好于瞎猜，仍对每个个案信心十足。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户宣布一个高置信度的结论，但说不出证据链。
2. 被一份逻辑严密、细节丰富的叙事说服（商业故事、成功学、复盘报告、阴谋论）。
3. 评估他人（专家、分析师、下属）的判断，对方"讲得特别通"。
4. 自己准备对外输出判断（报告、建议、预测）前的自检。

### 语言信号 (用户的话里出现这些就应激活)

- "我特别确定""这事肯定是""逻辑闭环了""怎么说得这么圆"
- "他讲得头头是道""这个故事很完整"
- 英文：I'm sure / coherent story / too good to be true / confidence check

### 与相邻 skill 的区分

- 与 `substitution-check` 的区别：替代检查的是**问题面**（我在回答哪个问题）；WYSIATI 检查的是**信息面**（我的故事用了多少信息、缺了什么）。一个判断两者都该过。
- 与 `high-stakes-slow-thinking` 的区别：总闸决定何时启动慢思考；本 skill 是慢下来的第二道工序（substitution 之后）。

## E — 可执行步骤 (Execution)

1. **陈述判断与信心值**：一句话写出结论 + 一个粗略置信度（%）。
   - 完成标准：结论与置信度落纸
   - 判停条件：低风险判断 → 程序结束，放行
2. **三问**：列出依据信息清单；写出"还缺哪些信息"；判定信心来源（证据/流畅）。
   - 完成标准：三问各有答案，信息缺口至少 1 条
3. **反向证据**：写出"若为假，最可能是因为……"至少 1 条具体情景。
   - 完成标准：反向情景可检验（能设想什么证据能区分真假）
   - 判停条件：写不出任何反向情景 → 警报：这是纯连贯性判断，降置信度或补充信息
4. **输出**：修正后的置信度 + 信息缺口清单。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 低风险日常判断（检查成本大于收益）。
- 数学/逻辑证明类结论——连贯性与正确性在那里是同一件事。

### 作者在书中警告的失败模式

- 知之甚少者最自信：故事最容易编圆（ce12）。
- 冗余陷阱：多渠道信息**互相印证**（高相关）时信心最足，恰是增量信息最少之时（ce34）——印证≠独立。
- 专家的信心不作数：技能错觉在职业文化中被强化（ce35）。

### 作者的盲点 / 时代局限

- 本书几乎不给连贯性直觉"何时有效"的正面账（吉仁泽一派的批评）；在强规律环境里，流畅感可以是真技能的信号——先用 `expert-intuition-precheck` 判环境，再用本 skill。

### 容易混淆的邻近方法论

- "保持怀疑态度"：本 skill 是三问+反向证据的具体工序，不是笼统态度；产出物是信息缺口清单和修正后的置信度。
