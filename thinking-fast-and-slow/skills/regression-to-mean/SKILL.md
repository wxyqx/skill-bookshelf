# 回归均值与奖惩错觉

## R — 原文 (Reading)

> "他观察到的是所谓的'回归均值'，是表现质量随机波动的结果。……教官是用因果关系来解释随机过程中不可避免的波动。"
>
> — 丹尼尔·卡尼曼（评以色列飞行教官"惩罚有效、表扬有害"的结论），第17章

---

## I — 方法论骨架 (Interpretation)

两次测量不完全相关时，极端表现之后必然向平均回落——这是数学，不是心理学。但系统1不接受"没有原因的变化"，于是必然的回落被编成因果故事：教官得出"表扬有害、惩罚有效"；杂志封面成了诅咒；偏方成了灵药。

三件工具：
1. **对照组基线**：评估任何干预前先问"不干预会怎样"。极端群体（最差的、最抑郁的、最低分的）随时间自然改善，"治疗前后有进步"证明不了疗效——效果必须**超出回归所能解释的部分**。
2. **成功分解公式**：成功 = 天赋 + 好运；巨大的成功 = 稍多一点天赋 + 大量好运。用途：别从极端成功里提炼秘诀；对成功者下一步的最佳预测是"仍高于平均，但低于峰值"。
3. **奖惩错觉校正**：表扬后的退步不是奖励的错，批评后的进步不是惩罚的功。评估管理手段要跨多个周期、多名对象，单次前后对比一律存疑。

## A1 — 书中的应用 (Past Application)

### 案例 1: 飞行教官的当场反驳（作者亲历）
- **问题**: 作者给飞行教官讲回归均值，一位资深教官反驳：他表扬过的学员都退步、吼骂过的都进步了。
- **方法论的使用**: 作者当场用掷硬币打靶演示：这轮打得最准的人（无论是否被表扬）下一轮大概率回落——教官观察到的正是回归。
- **结论**: 教官"说得对，但同时也大错特错"：他的观察无误，因果推论颠倒。
- **结果**: 附录A补记：这解释了为什么人们普遍高估惩罚、低估奖励——随机波动总在"惩罚"后改善。

### 案例 2: 《体育画报》诅咒与抑郁儿童头条
- **问题**: 为什么登上封面的运动员下赛季总表现不佳？为什么"治疗"过的抑郁儿童会好转？
- **方法论的使用**: 登封者必是上季极端好成绩（回归当选）；作者虚构"能量饮料治愈抑郁儿童"头条演示：极端低分的群体自然回升，没有对照组的疗效宣称默认无效。
- **结论**: 极端之后的回落会自动"奖赏"任何恰好发生过的干预。
- **结果**: 巴泽曼的连锁店案例演示正确用法：给差店的预测应包含更大的回归提升。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估培训、治疗、管理改革、产品改动"有没有效"（前后对比数据）。
2. 管理场景：批评/表扬之后下属表现变化，要不要调整奖惩策略。
3. 听到"诅咒""高开低走""昙花一现"类叙事。
4. 预测冠军、爆款、明星员工下一期表现。

### 语言信号 (用户的话里出现这些就应激活)

- "培训后变好了""管得严了就上来了""他飘了所以掉下去了"
- "诅咒""退步了""上季度太高了"
- 英文：regression to the mean / did it work / before vs after / sophomore slump

### 与相邻 skill 的区分

- 与 `small-sample-rules` 的区别：横截面差异归运气（小数定律）；时间轴回落归回归。两者常被同一个因果冲动污染。
- 与 `four-step-prediction` 的区别：四步程序把回归**内建于预测**（对极端者预测回落幅度）；本 skill 管归因与评估场景。给差店预测更大提升正是四步程序的输出。

## E — 可执行步骤 (Execution)

1. **识别两次测量**：确认存在"极端表现 + 随后变化"的结构。
   - 完成标准：前后两次测量与干预时点写明
   - 判停条件：表现无极端化 → 回归预期弱，按常规分析
2. **对照组提问**：不干预会怎样？找到未受干预的同类作为基线。
   - 完成标准：有对照（或至少承认缺失）
   - 判停条件：无对照组且决策重大 → 结论降级为"存疑"
3. **回归幅度估计**：按相关性估计回落/回升幅度（相关越弱回落越大）。
   - 完成标准：预期回归量已从"干预效果"中扣除
4. **归因裁决**：只有超出回归解释的部分才归功/归罪于干预。
5. **预测应用**：对极端成功者的下一步预测 = "高于平均，但低于峰值"，运气占比越大折扣越大。

---

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 干预方向与回归预测**相反**（该跌时反而涨）——此时干预效应的可信度上升。
- 两次测量完全相关（同一测量无波动的重复）——无回归空间。

### 作者在书中警告的失败模式

- 奖惩错觉是**制度化**的：随机波动总在惩罚后改善，组织会系统性地高估严苛、低估鼓励（ce29）。
- "有解释，但没有原因"——凡是给回归配了动听因果的故事（诅咒、体质、风水）都要过对照组（ce29）。
- 连发现者高尔顿都为这个"数学必然"惊讶了数年——它是真的反直觉，不要指望一次讲解就根除。

### 作者的盲点 / 时代局限

- 出租车司机研究等个别案例被后续研究质疑（作者在注释中承认）；书中未给出"多弱的相关算弱"的操作阈值，需使用者按领域数据自定。

### 容易混淆的邻近方法论

- 均值回归（金融术语）：金融价格的"均值回归"是有经济机制的假设，与本 skill 讲的**测量学必然**不是一回事，别混用。
