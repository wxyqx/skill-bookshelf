# 雷区识别与选择性慢思考

## R — 原文 (Reading)

> "原则上，防范源自系统1的错误很简单：识别自己处于认知雷区的迹象，放慢速度，请求系统2的增援。……遗憾的是，在最需要开启理性程序的时候，人们却最不可能这么做。"
>
> — 丹尼尔·卡尼曼，第1章（"妥协原则"），结论章重申为"雷区识别三步法"

---

## I — 方法论骨架 (Interpretation)

直觉大多数时候是对的，时刻警惕既不可行也不划算。这个方法论不要求你变成怀疑论者，而是做一个"在正确的地方多疑"的人：把有限的慢思考预算花在刀刃上。

1. 平时放行直觉——低风险、可逆、熟悉的场景里，跟着感觉走是理性的。
2. 建立一张"雷区情境清单"：出现以下任一迹象，强制切换慢思考——
   - 金额大或不可逆（错一次伤筋动骨）
   - 影响他人（招聘、定价、评价、承诺）
   - 陌生领域（你没在这里挨过反馈）
   - 场域里有锚、有框架、有生动故事（数字刚被报出、剧本讲得很顺）
   - 自己状态差（疲惫、亢奋、连续自控后）
3. 切换动作：放慢 → 把目标问题写下来 → 调集增援（复核、计算、清单、换人审）。
4. 关键认知：这套程序"在最需要时最难启动"（压力越大越想快），所以必须外置成清单或交给旁观者，不能指望临场自觉。

## A1 — 书中的应用 (Past Application)

### 案例 1: "把他赶出办公室"
- **问题**: 作者读研时上心理治疗课，面对"之前所有医生都误解我"的患者会油然产生收治冲动。
- **方法论的使用**: 老师传授的不是自我警惕，而是一条情境规则：听到这句话就触发"赶出办公室"——把识别情境与启用规则绑成条件反射。
- **结论**: 认知错觉无法根除，防错单位是"情境→规则"，不是意志力。
- **结果**: 作者多年后读到精神病态研究的临床规则时，印证了这条训诫的价值。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面临辞职、签约、投资、换城市等重大选择，直觉已有倾向但心里没底。
2. 被催促快速拍板（"今天必须定"），感觉哪里不对劲。
3. 想给自己或团队搭一张"什么决策必须慢下来"的清单。
4. 复盘重大失误，发现"当时就是太顺了没多想"。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要……""该不该……" + 高赌注对象（辞职/签合同/投钱/搬家）
- "帮我看看这个决定""我是不是想当然了"
- "重大决定""不可逆""签了就不能反悔"
- 英文：high stakes / big decision / should I trust my gut / irreversible choice

### 与相邻 skill 的区分

- 与 `substitution-check` 的区别：本 skill 决定"何时进入慢思考"；substitution-check 是进入后检查"我在回答哪个问题"的具体工序。本 skill 的增援步骤会调用后者。
- 与 `fourfold-risk-locator` 的区别：后者只管金钱风险的象限定位；本 skill 是全场景总闸。

## E — 可执行步骤 (Execution)

1. **雷区打分**：对照清单逐项判定——金额大？不可逆？影响他人？陌生领域？有锚/框架/顺滑故事？状态差？
   - 完成标准：得到明确的"高赌注/低赌注"判定
   - 判停条件：全部为否 → 放行直觉，本程序结束
2. **放慢 + 钉住问题**：把目标问题原文写下来，声明"此处印象不可信，只认事实与计算"。
   - 完成标准：有一句话版本的问题原文
3. **调集增援**：按雷区类型调用对应工具——有数字→`anti-anchoring`；是概率判断→`base-rate-first`；是数量预测→`four-step-prediction`；措辞可疑→`frame-check`；感觉过于顺滑→`substitution-check`，故事过于圆融→`wysiati-check`。
   - 完成标准：至少完成一项具体检查并留下记录
   - 判停条件：时间不允许完整程序时，只做"写下问题原文+复述已知事实"的最小动作
4. **留证据**：记录决策理由与当时的判断，供日后复盘使用。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 低风险日常选择——过度审查的代价是决策瘫痪（作者明言"不必时刻警惕"）。
- 真正的紧急事态——此时只执行最小动作（第2步），不要硬上全流程。

### 作者在书中警告的失败模式

- 认知错觉的顽固性：知道偏差存在并不会免疫，"多加小心"防不了错，只有预先规则能防（ce03）。
- "最需要时最难启动"：压力与高赌注恰好抑制慢思考——所以清单必须事前立好、外置执行。

### 作者的盲点 / 时代局限

- 作者承认自己研究了 lifetime 也未变好（"系统1不愿意受教育"），个人自纠近乎无解——本 skill 因此强调外置与组织化，但仍要诚实：它的效果上限有限。
- "疲惫/饥饿损害决策"部分的机制（自我损耗）在复制危机中受挫，状态自检降级为参考项。

### 容易混淆的邻近方法论

- 通用"三思而后行"：区别在于本方法**明确放行大多数直觉**并给出可判定的触发清单，而不是笼统地要求谨慎。
