# 罕见事件与概率表述去偏

## R — 原文 (Reading)

> "我们不应只关注某个设想，否则会高估它的概率。让我们想想其他可能，让概率加起来等于100%。"
>
> — 丹尼尔·卡尼曼，第30章

---

## I — 方法论骨架 (Interpretation)

大脑对小概率没有稳定表征，两头出错：**按描述决策**时过度看重（生动画面、被聚焦的分子）；**按经验决策**时彻底忽视（从未亲历就当不存在）。描述-经验鸿沟意味着：无论你"感觉概率多大"，都可能不对。

三个去偏动作：
1. **加总校验**：只盯着一个设想时，它的概率会被撑大（NBA 球迷对 8 支球队的夺冠概率之和达 240%）。强制列出替代事件并分配概率，让总和回到 100%——荒谬感是最好的校准器。
2. **表述换算（双向）**："每 10000 人中 1286 人死亡"换算成 24.14%（拆掉情绪放大器）；反之"0.001%"换算成"每 10 万人中 1 人"（激活真实的分母感）。看到哪种格式就换到另一种。
3. **分母检查**：生动的画面是分子（"这个孩子病死了"），情绪反应却只该由分数决定——先找到分母。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: NBA 概率之和 240%
- **问题**: 球迷对单队夺冠概率的判断是否互相一致？
- **方法论的使用**: 聚焦单队时替代事件模糊，8 支球队的概率判断加总达 240%；球迷平均每 160 美元回报押 287 美元。但当被问"冠军来自东区还是西区"（替代事件明确）时，荒谬消失。
- **结论**: 让替代事件显形，概率自动归位。
- **结果**: "概率加总=100%"成为标准去偏程序。

### 案例 2: 描述-经验鸿沟
- **问题**: 按描述选和按经验选，哪个更可信？
- **方法论的使用**: 两个按钮实验：按描述时罕见事件被过度看重；按自己采样的经验时又被普遍忽视——从未亲历的灾难从清单里消失。
- **结论**: 大脑对极小概率没有稳定表征，必须外接程序。
- **结果**: 作者自评这是前景理论的适用边界（"理论致盲"的自我修正）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估灾难/事故/极端行情的风险与应对。
2. 读到"每 X 人中 1 人"式风险通报、保险推销、安全宣传。
3. 做风险清单时发现自己"从没经历过所以没列"。
4. 为多个可能情景分配概率（预案、对冲、B 计划）。

### 语言信号 (用户的话里出现这些就应激活)

- "万一呢""概率极低但后果严重""新闻说每X人里1人"
- "从来没出过这种事""要不要为小概率投入"
- 英文：rare event / tail risk / 1 in X / should I worry

### 与相邻 skill 的区分

- 与 `base-rate-first` 的区别：贝叶斯是常规概率判断程序；本 skill 专门处理小概率的特殊失灵与表述操纵。阳性检测类问题（有诊断力结构）走 base-rate-first。
- 与 `availability-check` 的区别：那管例子的来源；本 skill 管拿到概率表述后的换算与加总。舆论风暴场景两者连用。

## E — 可执行步骤 (Execution)

1. **写明事件与表述**：原样记下风险及其表述格式（频率式/百分比式）。
   - 完成标准：表述格式已标注
   - 判停条件：概率不低（>10%）→ 交 base-rate-first 常规处理
2. **换算**：频率式换算成百分比（或反之），重新感受一次。
   - 完成标准：两种格式各有一个读数
3. **加总校验**：列出所有替代事件，给每个分配概率，验证总和=100%。
   - 完成标准：概率表加总为 100%
   - 判停条件：总和明显超 100% → 按比例压缩后重估
4. **分母检查**：问"分子之外，分母是多少？"把情绪反应重新锚定在分数上。
5. **经验模式警报**：若"从未亲历"是放松警惕的理由，检查描述模式下的数据是否仍支持该风险。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 期望值足以裁决的重复性小赌注（交 `wide-frame-trader` 的长期统计）。
- 用户在做纯数学/统计计算而非风险判断。

### 作者在书中警告的失败模式

- "每 10 万人中 1 人残疾"比"0.001%"吓人得多——频率格式系统性放大决策权重（ce25）。
- 1/10 罐 vs 8/100 罐：三成以上的人选错——分母忽视连简单算术都拦不住（c53）。
- 风险沟通是一场措辞之战：谁选择格式，谁就在行使权力——读者方需要免疫程序（ce25）。

### 作者的盲点 / 时代局限

- 频率表示法作为**正面工具**（降低合取谬误）与作为**操纵格式**（放大恐惧）在书里同时出现——方向取决于谁在用；本 skill 已把双向换算并列为程序，使用时注意你的角色（自估者/被说服者）。

### 容易混淆的邻近方法论

- 期望值计算：本 skill 不替代期望值，它校正的是**进入计算之前的概率表征**。
