# 小数定律：小样本打折与运气优先归因

## R — 原文 (Reading)

> "我的建议是，指挥部应该承认不同的结果是运气使然，停止对飞行员的调查。我推断，运气是最可能的答案，盲目寻找不确定的原因无济于事。"
>
> — 丹尼尔·卡尼曼（1973 年对以色列空军指挥部的建议），第10章

---

## I — 方法论骨架 (Interpretation)

系统1相信"小样本也能代表总体"（小数定律），于是小样本的极端结果总被编成因果故事。两条硬规则矫正它：

1. **小样本更容易产生两端极端结果**：最好的学校规模最小、最差的学校规模也最小；肾癌发病率最高与最低的郡都是人口稀少的农村郡——看到极端值先问"样本多大"，答案往往让因果故事塌掉。
2. **运气优先归因**：两组结果悬殊、但事先没有任何能预测该差异的根据时，第一假设是运气。先算"多大的样本量下这个差异才算异常"，算不出来就停止追查——为随机波动编造的因果解释必然是错的。

配套：**赌徒谬误免疫**——独立随机事件没有记忆，连开红之后黑门的概率不变；偏离只被更大的样本"稀释"，不会被"纠正"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 赎罪日战争的飞行中队（作者亲历）
- **问题**: 1973 年战争初期，同一基地两个中队损失悬殊（一队损 4 架、一队零损失），调查组要找出"不幸中队"的过失。
- **方法论的使用**: 作者指出事前无证据表明两队作战能力有差异，极端差异在如此小的样本里最可能就是运气，建议停止调查。
- **结论**: 为随机差异追责只会生产冤案与虚假教训。
- **结果**: 作者自述这是他对那场战争"只做出过一次重大贡献"，且让受挫的飞行员免于背负愧疚。

### 案例 2: 肾癌郡与盖茨基金会
- **问题**: 为什么某些郡肾癌发病率最低？
- **方法论的使用**: 答案是"多为人口稀少的农村郡"——同一研究里发病率**最高**的郡也是这类小样本郡。魏纳与泽维林据"最好的学校规模最小"指出盖茨基金会 17 亿美元小学校投资建在小数定律错觉上。
- **结论**: 对小样本极端结果的一切因果解释都站不住脚。
- **结果**: 机构级决策同样为此买单——这条规则不是学术洁癖。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用几次尝试/几单/几个客户评估一个方法、产品、员工。
2. 两个团队/门店/地区表现悬殊，要归因或奖惩。
3. 看到"某公司成功率惊人""某人连胜"想提炼秘诀。
4. 设计实验或 A/B 测试，要定样本量。

### 语言信号 (用户的话里出现这些就应激活)

- "最近几单都不行""这家店特别火""他就试了三次"
- "他们队好像特别强""这是不是运气"
- 英文：small sample / is it luck / too few cases to conclude / hot streak

### 与相邻 skill 的区分

- 与 `regression-to-mean` 的区别：小数定律管**横截面**的极端值（这批比那批好）；回归管**时间轴**的回落（这次比上次好）。极端成绩"之后的下滑"是回归，"两组之间的悬殊"是小样本。
- 与 `bias-proof-review` 的区别：那是事后复盘的程序；本 skill 是归因时的统计纪律，可在复盘内被调用。

## E — 可执行步骤 (Execution)

1. **报样本量**：结论建立在几次观察上？写下 n。
   - 完成标准：n 落纸
   - 判停条件：n 足够大且差异远超随机波动 → 按正常分析处理
2. **两端检查**：极端方向的反方向有没有同样极端的案例？（最差群组是否与最好群组同源？）
   - 完成标准：明确"两端极端/单侧极端"
3. **异常阈值**：在 n 这么小的样本里，这个差异多容易由运气产生？
   - 判停条件：运气即可解释 → 归因停止，输出"样本不足，无法归因"
4. **反向应用**：听别人讲成功/失败的原因时，先算运气能解释多少，再听他的秘诀。
5. **赌徒谬误自查**：连败后想"该赢了"、连胜后想"该栽了"→ 独立事件无记忆，偏离只被稀释不被纠正。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 有大样本统计支撑的差异——"都是运气"会成为拒绝证据的借口。
- 存在先验差异证据（如能力测评、历史基线）且差异方向一致——此时运气假设权重下降。

### 作者在书中警告的失败模式

- 热手错觉：数千次投篮分析证明 NBA 无热手，从业者至今抗拒（ce21；注意 2018 年后该结论本身受选择偏差分析挑战，引用需谨慎）。
- 伦敦轰炸点分布被当间谍阴谋：随机性看起来就像聚集（c17）。
- 连统计教材作者也犯样本量错误（50% 风险无法证实正确假设）——专家不豁免（c18）。

### 作者的盲点 / 时代局限

- "热手不存在"的原结论已被 Miller & Sanjurjo（2018）用选择偏差分析挑战，小样本规则本身依然成立，但举例需更新。
- 书中承认统计原理"无法从经验自学生得"，但给出的训练方案（尼斯贝特范式）效果有限且作者自己评价悲观——别指望读完就会。

### 容易混淆的邻近方法论

- "样本要大"的常识：本 skill 给出的是**可操作规则**（先报 n、两端检查、异常阈值），不是一句口号。
