# 情景细节审查：越丰富越可信、也越不可能

## R — 原文 (Reading)

> "这对预测者及其委托人来说是一个陷阱：在情景中添加细节会增强说服力，但它发生的可能性更小。"
>
> — 丹尼尔·卡尼曼，第15章

---

## I — 方法论骨架 (Interpretation)

系统1给"信念分"的标准是连贯性，不是概率。于是出现一个反直觉的陷阱：**每加一个细节，联合概率只会更低（多个条件要同时成立），但说服力只会更强**。咨询方案、创业故事、项目路线图、甚至阴谋论——细节的代价被藏在说服力之下。

审查程序：
1. **数假设**：这个情景依赖几个相互独立的假设？逐个写出来。
2. **分别赋概率并连乘**：0.9×0.8×0.7 = 0.5——三个"都挺靠谱"的假设，合起来只有一半。
3. **按结构读偏差方向**：链状结构（多环节串联才能成，如项目成功）→ 直觉**高估**；漏斗结构（任一环节失灵即全局失败，如系统安全）→ 直觉**低估**。两类都要显式组合概率，不许锚定单环节。
4. **分开计分**：给"可信度"（打动我的程度）与"概率"（联合概率）各记一个分——决策只用后者。

## A1 — 书中的应用 (Past Application)

### 案例 1: 琳达问题（细节的杀伤力）
- **问题**: 琳达是哲学系学生、关注社会正义——她更可能是"银行出纳员"还是"女权主义银行出纳员"？
- **方法论的使用**: 89% 的本科生、85% 的斯坦福决策科学博士生判更具体的"女权出纳员"更可能——"女权主义者"这个细节增加了连贯性，也在数学上必然降低了概率。
- **结论**: 连贯性（可信度）与概率是两个变量。
- **结果**: 附录A同构证据：带"地震引发洪水"细节的加州情景被判概率更高。

### 案例 2: 弹珠下注的结构效应
- **问题**: 押"48% 概率的复合事件"还是"50% 的简单事件"？
- **方法论的使用**: 多数人押 0.48 的合取事件、又弃 0.52 的析取事件——合取高估、析取低估，方向完全可从任务结构读出。
- **结论**: 计划成功（链状）被高估、系统失效（漏斗）被低估，是同一个机制的两次表现。
- **结果**: 附录A据此给出"从事件结构推断偏差方向"的诊断规则。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估商业计划、项目路线图、投资故事、尽调报告。
2. 听完一个"每一步都说得通"的方案，想做可行性判断。
3. 审查自己的计划：为什么越写越有信心？（细节累积效应）
4. 被要求评估多方给出的"情景推演"。

### 语言信号 (用户的话里出现这些就应激活)

- "听起来很可行""说得特别具体""每一步都对得上"
- "这个情景/剧本靠谱吗""细节好多反而更信了"
- 英文：plausible scenario / detailed plan / conjunction fallacy / is it probable or just vivid

### 与相邻 skill 的区分

- 与 `base-rate-first` 的区别：贝叶斯管"个体属于某类"的概率判断；本 skill 管"复合情景"的联合概率拆解。方案评估常两者连用。
- 与 `outside-view` 的区别：外部视角用同类案例的**统计分布**给基线；本 skill 是在拿到基线后拆解情景内部结构。先外部视角定盘子，再细节审查拆解。

## E — 可执行步骤 (Execution)

1. **列出独立假设**：情景成立的必要条件逐条写出（不重叠）。
   - 完成标准：假设清单无遗漏关键依赖
   - 判停条件：情景是单步简单事件 → 不适用连乘
2. **分别赋概率**：每个假设给一个概率（有数据用数据，无数据给区间）。
   - 完成标准：每个假设有数值
3. **连乘组合**：链状结构直接相乘；漏斗结构计算"任一失灵"的概率（1−Π(1−p)）。
   - 完成标准：联合概率算出并与直觉值对比
4. **双分计分**：可信度分（说服力）与概率分（连乘结果）分开陈述，决策只用后者。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 假设间高度相关的事件（相关时连乘会**低估**概率——需先做相关性处理）。
- 单步、无结构的简单预测（仪式化连乘没有信息量）。

### 作者在书中警告的失败模式

- 知道合取谬误仍会中招：连古尔德都写文章解释自己为什么"明知故犯"（ce26）。
- 分析师用丰富细节卖方案，委托人把可信度当概率买单（ce27）。
- 计划成功率没有随环节数衰减 = 警报（ce26 的 warning_sign）。

### 作者的盲点 / 时代局限

- 琳达问题是书里自认的"有争议案例"：批评者（赫特维格、吉仁泽）证明部分误差来自"概率"一词的语用歧义，作者与赫特维格为此做了对抗性合作——引用时注明这是逻辑与语用之争而非铁案。

### 容易混淆的邻近方法论

- 敏感性分析：工程里的连乘是建模技术；本 skill 是**对着"叙事说服力"做反差检验**的判断程序，产出的是"可信度≠概率"的双分记录。
