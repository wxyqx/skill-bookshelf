# 专家直觉可信度预检

## R — 原文 (Reading)

> "答案来自技能习得的两个基本条件：· 足够规律的、可预测的环境 · 通过长期实践学习这些规律的机会。同时满足这两个条件，直觉就很可能是技能的体现。"
>
> — 丹尼尔·卡尼曼（与克莱因共同署名的结论），第22章

---

## I — 方法论骨架 (Interpretation)

直觉不是魔法，是识别——"某种情境下的线索触发了记忆库里的答案"（西蒙）。因此它只在两种条件同时满足时才可靠：
1. **环境有规律**：象棋、消防、麻醉、农夫看天气——线索与结局之间有稳定因果；股市长期走势、政治经济预测、创新项目成败——没有。
2. **有带反馈的练习**：足够多的尝试机会，且每次尝试后能快速、清晰地知道对错。

环境恶劣时更糟：专业人士能从经验里学到**错误的**教训（反馈被自己的行为污染）。以及一条一票否决的禁令：**不要相信任何人（包括你自己）对自己直觉的信心**——自信只是故事连贯性的感觉，与证据质量无关；最自信的人往往知之最少，因为故事最容易编圆。

补充信号：想确认"技能还是运气"，查其成绩排名的**跨期稳定性**——运气主导的游戏排名年年洗牌（25 位华尔街顾问 8 年间 28 个跨年相关系数均值 0.01）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 对抗性合作（程序本身的诞生）
- **问题**: 作者相信直觉常是偏差，克莱因为消防指挥官的直觉辩护——两人立场对立。
- **方法论的使用**: 作者发明"对抗性合作"：让分歧双方合著论文。两人共同研究后达成一致答案：直觉=识别，两条件决定可信度。
- **结论**: 这套预检是争论双方都签名的成果，不是一家之言。
- **结果**: 作者称此为"最令我满意也最有成效的对抗性合作"。

### 案例 2: 库罗斯雕像与伤寒医生
- **问题**: 盖蒂博物馆的库罗斯雕像，顶级专家一致说"是赝品"却给不出一致理由；另一位医生凭触诊"精准"预测病人死亡。
- **方法论的使用**: 前者是"直觉排斥"——强预感、无理由，两条件未经验证；后者在恶劣环境里把反馈污染成了错误技能（病人是他自己传播感染的）。
- **结论**: 信心与理由的缺失都不能自动裁决，只有两条件能。
- **结果**: 两人同意以库罗斯案例为起点做系统的线索研究。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 决定是否采纳资深人士的判断（医疗意见、投资建议、技术选型、导师忠告）。
2. 评估自己的直觉："我在这行这么多年，感觉不对劲/感觉稳了。"
3. 面对非常自信的销售、创始人、分析师。
4. 招聘时判断候选人的"行业嗅觉"是否可信。

### 语言信号 (用户的话里出现这些就应激活)

- "他说得很肯定""专家说""老司机/老师傅说"
- "他干了二十年了""凭经验""直觉告诉我"
- 英文：expert opinion / trust the expert / gut of a veteran / confidence

### 与相邻 skill 的区分

- 与 `formula-over-intuition` 的区别：对偶——precheck 通过时才轮到信直觉，不通过时交公式（formula-over-intuition）或基率（base-rate-first）。
- 与 `bias-proof-review` 的区别：那是事后评价专家的往绩；本 skill 是事前可信度预检。

## E — 可执行步骤 (Execution)

1. **识别直觉声称**：明确"谁、在什么任务上、给出了什么直觉判断"。
   - 完成标准：任务边界写清楚（外科医生的直觉不自动覆盖选股）
2. **查环境规律**：该任务领域线索与结局之间有稳定规律吗？
   - 完成标准：明确归入"有规律/无规律"并举例佐证
3. **查练习与反馈**：他有多少次练习？反馈快速且清晰吗？还是延迟、混杂、被自己的行为污染？
   - 完成标准：两项条件各有判定
4. **裁决**：两条件同时满足 → 直觉可信，采信；任一不满足 → 直觉只是启发式，转 `formula-over-intuition` 或 `base-rate-first`。
   - 判停条件：能查到跨期排名记录 → 排名稳定才上调可信度
5. **记录禁令**：写明"其自信程度未作为证据使用"。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 对方给的是数据、公式或可独立核验的依据——直接核验，不必预检直觉。
- 涉及动机与诚信问题（他可能有意误导）——本 skill 只管认知可信度。

### 作者在书中警告的失败模式

- "无论谁（包括你自己）告诉你应该相信其判断，都不要相信"——自信不构成证据（ce38）。
- 恶劣环境学错教训：反馈被污染时，经验只会加固错误（伤寒医生）。
- 技能外推：强项任务的自信被默认延伸到弱项任务（ce38）。

### 作者的盲点 / 时代局限

- "多长算长期、多清晰算清晰反馈"没有操作阈值，只能当方向性判据。
- 泰特洛克后续的"超级预测者"研究表明：经过训练与团队协作的普通人能显著超越专家——在预测任务上应叠加该修正。

### 容易混淆的邻近方法论

- 诉诸权威：本 skill 不是"查头衔"，而是查环境与反馈结构——头衔二十年与两条件无关。
