# 零基重估：反事实提问 + 心理账户审计

## R — 原文 (Reading)

> "为了贯彻这种理性行为，系统2必须意识到反事实的可能性：'如果票是从朋友那儿免费得来的，我还会冒着暴风雪开车去看比赛吗？'"
>
> — 丹尼尔·卡尼曼，第32章

---

## I — 方法论骨架 (Interpretation)

心理账户要求每个账户"结清"：盈利账户想落袋，亏损账户拒绝以亏损销户。于是出现两套系统性的钱错位：
- **沉没成本绑架**：继续投入的真实动机只是维持"这是一笔成本"的记账，回避把它重记为纯损失（网球肘患者忍痛打球，只为不让会费变成"纯粹损失"）。
- **处置效应**：卖盈利股、抱亏损股——为"以收益结清账户"支付真实税负与负 alpha。
- **禀赋效应**：拥有即溢价，"舍不得"被误读成"更适合"——马克杯卖价约为买价两倍。

矫正器是一个标准化问句——**零基重估**："假如我从未投入（票是白送的、项目是别人留下的、股票是今天才看到的），我现在会为它投入这么多吗？"持股版："如果今天用现金按市价买，我还会买这只吗？"——不会买的就是该卖的，**决策与买入价无关**。组织版：让没有心理账户包袱的人（新评审、外部顾问）来评。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 暴风雪球票
- **问题**: 同样一场暴风雪中的球赛，免费得到票的人和花钱买票的人谁更可能驱车前往？
- **方法论的使用**: 买票者更可能冒险上路——他的心理账户里有"以负余额销户"之痛；免费票没有这个账户。
- **结论**: 行为差异与比赛价值无关，只与记账方式有关。
- **结果**: 作者给出矫正问句："如果票是从朋友那儿免费得来的，我还会去吗？"

### 案例 2: 蒂芙尼与蓝莓瓷砖
- **问题**: 投资者需要现金时卖哪只股票？
- **方法论的使用**: 多数人卖盈利的蓝莓瓷砖、抱住亏损的蒂芙尼——拒绝以亏损销户；金融研究量化了代价：卖蒂芙尼保蓝莓的税后回报一年高 3.4%。
- **结论**: 处置效应是心理账户打败金融常识的实证。
- **结果**: 作者的规则版处方：每年固定时间检查并变现亏损头寸。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 项目烧了几个月/几百万，讨论"现在放弃可惜"。
2. 持仓浮亏，"等回本再卖"。
3. 清理订阅、会员、囤积物品时"舍不得"。
4. 接手别人留下的半成品，想客观评估去留。

### 语言信号 (用户的话里出现这些就应激活)

- "都投这么多了""等回本""舍不得""放弃太可惜"
- "已经花了……不能白花"
- 英文：sunk cost / would I buy it today / stop-loss / why can't I let go

### 与相邻 skill 的区分

- 与 `frame-check` 的区别：frame-check 换问题的说法；本 skill 换自己的账本（把历史投入归零）。两者常连用（改述+归零）。
- 与 `wide-frame-trader` 的区别：宽框架解决"单次损失太痛"；零基重估解决"历史投入绑架现在"。卖出决策（处置效应）主用本 skill。

## E — 可执行步骤 (Execution)

1. **识别账户污染信号**：出现"已经投了这么多 / 等回本 / 舍不得 / 白花了"任一措辞即触发。
   - 完成标准：指认出污染措辞
   - 判停条件：无此类措辞 → 不适用
2. **选问句做零基重估**：贴合适用对象——项目版（"如果项目是别人留下的"）、持仓版（"今天按市价还买吗"）、物品版（"没拥有它我还会花这个价换进来吗"）。
   - 完成标准：给出"会/不会"+理由，理由中不得引用历史投入
3. **以零基答案为准执行**：不会买 → 卖出/止损/放弃；会买 → 继续并把账重记为"当下重新选择"。
   - 完成标准：行动与零基答案一致
4. **组织版**：把评估交给没有该心理账户的人（新评审/外部者），原负责人回避独立判断环节。
5. **规则化**：对重复出现的同类决策（持仓检查），设固定检查点（如每年 12 月变现亏损头寸）。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 历史投入有真实复用价值（已建的代码库、渠道、技能）——先盘点残值，再做零基判断；残值是未来收益，不是沉没成本。
- 退出触发法律/声誉合约后果——先处理合约结构，估值问题不会因此消失。

### 作者在书中警告的失败模式

- 继续投入的唯一理由是"不想浪费"，真实动机是回避记账重分类（ce40）。
- 禀赋效应把"舍不得"伪装成"更适合"；反对改变的唯一论据是"现在这样挺好"（ce51）。
- 处置效应的真实代价被量化：一年 3.4% 的税后差（ce53）。

### 作者的盲点 / 时代局限

- 禀赋效应的强度在资深交易者与低收入人群中显著削弱，且有实验伪象之争（普洛特&蔡勒）——效应方向可靠，幅度带不确定性。

### 容易混淆的邻近方法论

- "断舍离"类生活建议：本 skill 提供的是反事实问句+账户审计的可执行程序，且明确边界（残值、合约）。
