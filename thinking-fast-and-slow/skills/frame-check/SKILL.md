# 框架检验：换一种说法再答一遍

## R — 原文 (Reading)

> "'如果丢了等额的现金，你会买票吗？如果会，那就重新买票吧。'较宽的框架和包容性较强的账户通常会让人做出更理性的决策。"
>
> — 丹尼尔·卡尼曼，第34章

---

## I — 方法论骨架 (Interpretation)

等效的措辞会移动参考点，把同一笔钱在"收益"与"损失"之间搬运，而系统1对措辞的情绪反应直接改写偏好——作者称框架效应"更像是知觉错觉，而不是计算错误"：**知道也无法免疫**，只能靠程序检验。

程序：对重要决定，把它改述成至少两种等价说法（损失↔成本、失去30↔保留20、死亡率↔存活率、附加费↔折扣、"买它"↔"假如没拥有它，值多少钱"），分别作答。答案一致→决定稳健；答案翻转→决定由措辞驱动，此时选择**更宽、更包容**的框架版本重新作答（例如把沉没成本放进一般账户、把"人手"改述为"人力资源成本"）。

配套动作：
- **参考点定位**：任何"赚了还是亏了"先问"相对什么而言"（现状、期望、应得权利）。
- **防操纵自查**：对方只给你一种措辞时（律师、营销、风险通报），自动换算成对立措辞再看一遍。

## A1 — 书中的应用 (Past Application)

### 案例 1: 亚洲疾病问题
- **问题**: 600 人受疫病威胁，两个方案数字完全等价，只换措辞（"200 人获救" vs "400 人死亡"）。
- **方法论的使用**: "获救"框架下 72% 选程序化方案，"死亡"框架下只有 22%——同一批受试者几分钟内自相矛盾；公共健康专家同样中招，被追问时"无言以对"。
- **结论**: 偏好是被措辞当场建构的，不是等待被揭示的。
- **结果**: 附录B把"多框架检验"列为头号可执行纠偏策略。

### 案例 2: 存活率 vs 死亡率
- **问题**: "术后一个月存活率 90%" vs "术后一个月死亡率 10%"。
- **方法论的使用**: 医生的手术/放疗偏好随表述从 84% 翻转到 50%；患者同样被改变治疗选择。
- **结论**: 专家在生死决策上也不免疫。
- **结果**: 作者提醒：措辞不影响体验，却显著影响选择——这正是要做框架检验的原因。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 谈判/定价：对方用"损失"措辞向你施压（"错过就是损失"）。
2. 自己对同一件事的態度随"怎么叫它"变化（裁员 vs 优化；支出 vs 投资）。
3. 阅读风险通报、营销话术、绩效反馈时想拆掉措辞放大器。
4. 重大取舍前想确认"我的选择是实质的还是说法的"。

### 语言信号 (用户的话里出现这些就应激活)

- "这算亏还是算花""换个说法好像就不一样了"
- "他是不是在话术我""这个说法有没有陷阱"
- 英文：framing / how is it worded / loss vs cost / reframe

### 与相邻 skill 的区分

- 与 `zero-base-rethink` 的区别：zero-base 换的是**自己的账本**（假设我没投入过）；frame-check 换的是**问题的说法**。同属多框架稳健性家族，常连用。
- 与 `fourfold-risk-locator` 的区别：定位器需要先有参考点（本 skill 的产出）才能定象限。

## E — 可执行步骤 (Execution)

1. **写下当前表述**：问题的原始措辞原样记录。
   - 完成标准：措辞原文落纸
2. **生成改述**：至少两种等价表述（用损失↔成本、失去↔保留、比率↔频率、附加费↔折扣等互换）。
   - 完成标准：≥2 个改述版本
3. **各答一遍**：对每个版本独立作答。
   - 完成标准：每个版本下有明确选择
4. **判定**：答案一致 → 稳健，放行；翻转 → 被框架驱动，改用更宽更包容的框架重答（沉没成本入一般账户、把损失重述为成本）。
   - 判停条件：无翻转 → 结束
5. **参考点定位 + 防操纵**：写明"相对什么而言"；若措辞来自利益相关方，自动换算成对立措辞复核一遍。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 执行层的紧迫决定（改述的时间成本不划算）。
- 措辞差异本身承载道德内容的场景（"安乐死"vs"终结生命"的分歧是价值差异，不是框架错觉——作者在附录B承认部分"偏差"可能是合理的价值分歧）。

### 作者在书中警告的失败模式

- 框架效应如错觉般不可免疫，"学过"不等于"免疫"（ce57）。
- 操纵者主动选措辞：折扣 vs 附加费的行业游说、"每1000人中1人"的风险通报（ce57）。

### 作者的盲点 / 时代局限

- "更宽的框架更好"本身是一种未被完全论证的偏好承诺（书中以组合学论证支撑，但宽框架也有认知成本）；本 skill 把"更宽"作为默认裁决规则，适用于金钱与资源类决策，道德争议场景应改为"并列呈现、明示价值分歧"。

### 容易混淆的邻近方法论

- `zero-base-rethink`：换账本（自己的投入历史）vs 换说法（问题的措辞）。
