# 替代自检：我刚才回答的是哪个问题

## R — 原文 (Reading)

> "我们的问题是这位候选人能否胜出，我们回答的问题似乎是她接受采访时是否表现得好。请不要替换问题。"
>
> — 丹尼尔·卡尼曼，第9章

---

## I — 方法论骨架 (Interpretation)

面对难题，系统1不会说"我答不上来"，而是悄悄把问题换成一道更简单的相关问题作答，并且你毫无察觉——"心理活动最突出的特点就是很少被问题难住"，因为难题根本没被回答。

常见的替换对：
- 我喜欢他/她 → 他/她值得投资/能胜任吗
- 我容易想起例子 → 这件事常见吗
- 描述像不像 → 概率是多少
- 表现精彩 → 结果会好吗
- 画面生动 → 数量大吗（总量忘了乘数量）
- 刚上头条 → 重要吗

防呆程序只有一句话：**把目标问题钉在墙上**。写下原问题，作答，然后回看"我刚才实际回答的是哪个问题"。发现替换就回到原问题，去找统计性证据。

## A1 — 书中的应用 (Past Application)

### 案例 1: 福特高管买股票
- **问题**: 一位首席投资官刚刚买入福特汽车数千万美元股票。
- **方法论的使用**: 作者问他怎么做的决定。答案：刚参加了一个车展，感觉很棒。"该买福特股票吗"被替换成了"我喜欢福特吗"（情感启发式）。
- **结论**: 专业人士的直觉并不都来自专业知识——没有反馈环境时，直觉只是换了道简单题。
- **结果**: 作者以此案例作为全书"替代"机制的序言开场。

### 案例 2: 面试候选人与"能否胜出"
- **问题**: 招聘决策需要预测候选人未来表现。
- **方法论的使用**: 作者指出面试官实际回答的是"她面试表现好吗"——把预测题换成了印象题。
- **结论**: 发现替换后，正确路径是回到原问题、改用结构化评分（公式与结构化面试的出处）。
- **结果**: 引出第21章的结构化面试程序（以色列军沿用45年）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 对人/项目/投资形成了强烈好恶，正要把它当成预测或决策依据。
2. 用户自己纳闷"为什么我觉得这事很严重/很乐观"。
3. 审查别人的论证：结论与论据之间似乎错位。
4. 决策特别顺、没有任何卡壳——顺滑本身是替换的气味。

### 语言信号 (用户的话里出现这些就应激活)

- "我特别看好他""一听就很靠谱""说不上来为什么"
- "总觉得这事有风险""第一感觉"
- 英文：gut feeling, what am I really answering, substitution

### 与相邻 skill 的区分

- 与 `high-stakes-slow-thinking` 的区别：总闸决定何时慢下来；本 skill 是慢下来后的第一道工序。
- 与 `base-rate-first` 的区别：发现替换后的统计性作答由后者接手；本 skill 只负责"抓回原问题"。

## E — 可执行步骤 (Execution)

1. **钉住问题**：把目标问题写成一句话（可判真伪的形式）。
   - 完成标准：问题原文落在纸面/对话里
2. **作答并标注**：写下直觉答案。
3. **回看对照**：问"我刚才实际回答的是哪个问题"，对照常见替换对清单。
   - 完成标准：能明确说"没替换"或"被替换成了……"
   - 判停条件：未替换 → 正常继续
4. **抓回原问题**：被替换后回到原问题，列出其所需的统计性证据（基率、样本、相关性）。
   - 完成标准：进入 `base-rate-first` 或 `four-step-prediction` 的输入就绪

---

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 目标问题本身就是偏好或审美（"我喜欢哪张海报"没有更"正确"的答案可抓回）。
- 对方明确在做主观表达而非判断（评论、感想）。

### 作者在书中警告的失败模式

- "面对难题时，我们回答的是较简单的问题，而且意识不到问题被替代了"——最难的是承认自己被替换过（ce15）。
- 强度匹配变体：证据的"有利程度"不受其可靠性影响，预测因此对证据质量不敏感（ce18）。

### 作者的盲点 / 时代局限

- 第4章的联想/促发机制（解释替换的底层过程）属于可复制性危机重灾区，引用其生理层面结论时应降级；但"替代"本身在判断实验中证据稳固。

### 容易混淆的邻近方法论

- WYSIATI（所见即一切）：WYSIATI 说的是**信息面**——只用眼前信息编故事；替代说的是**问题面**——回答了另一个问题。两者常同时发生但不是一回事。
