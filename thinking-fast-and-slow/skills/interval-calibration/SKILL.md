# 置信区间校准：对无知定价

## R — 原文 (Reading)

> "为了让意外的发生率保持在期望水平，首席财务官每年都应重复同样的话：'明年标准普尔指数的回报率有80%的可能性在-10%和+30%之间。'正确反映首席财务官知识（更准确地说，是无知）的置信区间比他们所说的宽4倍以上。"
>
> — 丹尼尔·卡尼曼，第24章

---

## I — 方法论骨架 (Interpretation)

区间是人从"最佳估计"向外微调出来的，而微调永远不足——所以几乎所有自称 90% 的区间，实际命中率远低于 90%（CFO 研究：声称 80% 的区间 67% 被突破；专家 98% 区间实际仅约 70% 覆盖）。**窄区间不是专业，是过度自信的输出**；诚实的区间应该宽得让你不舒服。

两个程序：
1. **按历史意外率放宽**：查（或回忆）自己同类估计的历史突破率，把区间放宽到"过去有多大比例被突破"与标称置信度一致。宽区间是对无知的诚实定价。
2. **换提取方式交叉验证**：直接报"90% 分位值"会过窄；改问"超过某值的胜算多大"又会过宽——同一批人换问法从过度极端跳到过度保守。重要区间发布前用两种问法各算一遍，取更宽者。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 杜克 CFO 调查
- **问题**: 高管对股市的把握有多大？
- **方法论的使用**: 11600 份预测与真实值的相关系数略小于 0；自称"80% 置信"的区间 67% 被突破——预期值的三倍多。
- **结论**: 连最该懂不确定性的人也在系统性收窄区间。
- **结果**: 作者给出处方：诚实区间应比 CFO 所说的宽 4 倍以上。

### 案例 2: 乘法自产锚与道琼斯 X90
- **问题**: 区间是怎么被造窄的？
- **方法论的使用**: 附录A演示自产锚：8×7×6×…的升序组中位数 512、降序组 2250（真值 40320）；道琼斯 X10/X90 任务中专家 98% 区间实际仅约 70% 覆盖，换提取方式又变过度保守。
- **结论**: 校准是提取程序的属性，不是判断者的品质。
- **结果**: 对策即"换一种等价问法交叉验证，取更宽者"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 给工期、预算、销量、回报率做区间估计。
2. 发现自己的预测区间"从来没错过"——那它就不是区间。
3. 审查他人的"80% 把握""误差 ±5%"。
4. 团队要把主观概率分布制度化（销售 pipeline、项目里程碑）。

### 语言信号 (用户的话里出现这些就应激活)

- "给个范围""大概什么时候""误差多少""80%把握"
- "我的区间从来没被突破过"（警报句）
- 英文：confidence interval / range estimate / how sure are you / widen the interval

### 与相邻 skill 的区分

- 与 `four-step-prediction` 的区别：四步程序产出**点预测**（收缩后的均值）；本 skill 给它配上诚实的**区间**。重大预测先跑四步，再校准区间。
- 与 `outside-view` 的区别：参考类别的历史分布本身就是最好的"历史意外率"来源——外部视角是本程序的输入。

## E — 可执行步骤 (Execution)

1. **给初始区间**：按直觉写出下限与上限。
   - 完成标准：区间落纸
   - 判停条件：一次性琐事 → 结束
2. **查历史意外率**：同类估计过去被突破的比例是多少？（无记录则用参考类别数据或诚实的回忆）
   - 完成标准：得到一个突破率数字
3. **放宽**：若突破率高于标称（如 90% 区间被破 30%），按比例放大区间直至两数匹配。
   - 完成标准：区间宽度与历史意外率一致
4. **交叉验证**：换一种提取方式（直接报分位 ↔ 问"超过 X 的胜算"）再算一遍，取更宽者。
   - 判停条件：两种问法一致 → 输出区间
5. **输出声明**：报告区间时同步说明"此区间按历史意外率校准"，给伪精确留出反驳接口。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 已做样本外检验的统计模型区间（那是校准过的，别再手工放大）。
- 用"宽区间"当推卸责任的挡箭牌——校准的目标是**匹配**历史意外率，不是越宽越好。

### 作者在书中警告的失败模式

- "有十足把握"出现在高风险预测里：ICU 医生对临终诊断有十足把握的 40% 是错的（ce43）。
- 承认无知受社会惩罚，于是区间越窄越"专业"——组织要把"宽区间是诚实"制度化（ce43）。
- 调整不足来自自产锚：从最佳估计向外微调永远不够（c22）。

### 作者的盲点 / 时代局限

- 书中未给出个人历史意外率的追踪模板；落地需自行建立"预测-结果"台账（这也与 bias-proof-review 的"事前留证"衔接）。

### 容易混淆的邻近方法论

- 统计置信区间：那是从数据分布推导的；本 skill 处理的是**主观区间**的校准，两者用途不同。
