# 决策工厂：组织层纠偏

## R — 原文 (Reading)

> "组织都是制造判断和决策的工厂。每个工厂都要有自己的方法，确保其产品在原始设计、制造过程和最终检验环节中的品质。在决策制定上，这些环节包括表述待解决的问题、收集做决策需要的相关信息，以及反思与回顾。"
>
> — 丹尼尔·卡尼曼，结论

---

## I — 方法论骨架 (Interpretation)

全书最冷峻的结论：**个人无法自我纠偏**（"系统1不愿意受教育"，作者自己的直觉也没变好），改善判断主要靠组织——因为组织能慢下来、能实施有序流程、能把纠偏外包给程序。把决策当产品做质量管理：

**三环节**：
1. **设计（表述）**：问题是如何被措辞的？——措辞即框架，换说法答案会变（接 `frame-check`）。
2. **制造（收集）**：决策信息是如何收集的？——独立性（先写后议）、参考类别（外部视角）、公式化（结构化评分）。
3. **检验（回顾）**：事后有没有对齐"结果与过程"的反思？——防结果偏差与后见之明改写。

**四件套工具**：①检查清单（对抗遗漏与跳步）；②参考类预测（对抗规划谬误）；③事前分析/premortem（对抗过度自信与集体思维）；④**组织专属的偏差词汇**——"这是锚定""窄框架了"，形成互警文化：旁观者的精准批评比决策者临场自省更可行。

**选择架构**：为他人设计选项时假设用户不读细则——把对长期利益有利的选项设为默认（默认项被视为正常项，背离它需要更多思考且更易后悔）；器官捐献率由表格勾选方向决定（奥地利 ~100% vs 德国 12%）是它的最强实证。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 以色列军选拔体系
- **问题**: 直觉面试对预测新兵表现几乎无效。
- **方法论的使用**: 作者 1955 年把选拔改造成决策工厂：6 项特质定义（表述）、逐项事实化提问与打分（收集）、公式合成（加工）；面试官的"闭眼"直觉只保留为参考项。
- **结论**: 组织能实施个人无法坚持的程序。
- **结果**: 体系沿用 45 年以上——这是全书组织层处方最长周期的实证。

### 案例 2: 器官捐献的默认项
- **问题**: 文化相近的欧洲邻国，捐献率为何天差地别？
- **方法论的使用**: 奥地利 ~100%、德国 12%；瑞典 86%、丹麦 4%——差异全部来自驾照表格的默认勾选方向。系统2的懒惰使"不思考"成为压倒性行为。
- **结论**: 选择架构在生死问题上都有效力，也意味着**设计者承担伦理责任**。
- **结果**: "有力的证据表明，大多数人的选择都是轻率的"——助推是把双刃剑。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队同类决策反复翻车，想装程序性防线。
2. 设计评审会、立项流程、招聘流程、复盘制度。
3. 想把偏差词汇变成团队互警文化（"你这是锚定"能被接受）。
4. 为用户/客户设计选择环境（表单、默认项、合同呈现）。

### 语言信号 (用户的话里出现这些就应激活)

- "团队老在同一类决策上翻车""帮我设计决策流程""复盘走过场"
- "会上没人敢说真话""审批全靠拍脑袋"
- 英文：team keeps making the same mistake / decision process / debias meetings / organizational decision quality

### 与相邻 skill 的区分

- 与单体 skill 的区别：decision-factory 是**装配线**——它不替代 premortem/outside-view/formula-over-intuition，而是决定在哪个环节装哪个、以及如何制度化。四个工具 skill 是它的"设备"。
- 与 `independent-judgment` 的区别：先写后议是"制造"环节的一个装置；本 skill 管全流程。

## E — 可执行步骤 (Execution)

1. **选靶**：挑一类反复出问题的高价值决策（不要一上来改造所有决策）。
   - 完成标准：靶决策类已定义，含年频率
   - 判停条件：无重复性（一次性决策）→ 直接用单体 skill
2. **表述环节**：为该决策类写"问题模板"——固定表述方式、必答的参考点/框架检验项。
   - 完成标准：模板成文
3. **收集环节**：装入独立判断（先写后议）、参考类别（基线数据源）、结构化评分（若属评估类）。
   - 完成标准：每个装置有负责人与触发时机
4. **回顾环节**：设复盘规则——过程分/结果分分离、"知道"词汇纪律、预测台账（配合 interval-calibration 的意外率追踪）。
   - 完成标准：复盘有固定模板与台账
5. **文化装置**：约定团队偏差词汇表（锚定/窄框架/WYSIATI……），主持人在会上有权点名；批评对"决策方式"不对"个人"。
   - 判停条件：领导不愿放弃先表态 → 四件套效果减半，如实告知
6. **选择架构**：凡面向他人（含未来自己的）表单，检查默认项方向与可读性。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 单次个人决策——流程开销大于收益，直接用单体工具。
- 领导层无意让权的组织——装出来的程序会被"先表态" ritual 掏空（premortem 的时机条件即失效）。

### 作者在书中警告的失败模式

- 集体思维压制质疑：领导表态后质疑=不忠诚（ce44）——程序必须先于表态。
- 默认项懒惰被滥用：操纵性默认项、小字体合同在"经济人无需保护"的假设下合法收割普通人（ce59）——设计者伦理是硬约束。
- 改进不能等灾难：应做持续质量管理，而非事故后的全面审查（f51）。

### 作者的盲点 / 时代局限

- "谁来保证助推者善意"书中未答——组织自我授权的纠偏权力需要外部治理（本 skill 以"批评对方式不对个人+默认项伦理审查"部分补位，但需如实告知这是延伸设计）。
- 以色列军体系的组织纪律强度不可默认复制到企业环境。

### 容易混淆的邻近方法论

- 通用流程管理（PDCA 等）：决策工厂的特异点是**用认知偏差目录来定位每个环节的风险**（清单对抗遗漏、参考类对抗内部视角、premortem 对抗乐观、词汇对抗盲视）。
