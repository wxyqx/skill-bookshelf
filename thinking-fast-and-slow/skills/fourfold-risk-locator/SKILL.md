# 四重模式定位器（含损失厌恶换算与止损警报）

## R — 原文 (Reading)

> "人类的许多不幸都位于右上角的单元格。面对极其不利的选项，人们会孤注一掷，接受大概率雪上加霜的事，以换取避免重大损失的一线希望。这种冒险行为往往会将可控的失败变成灾难。"
>
> — 丹尼尔·卡尼曼，第29章

---

## I — 方法论骨架 (Interpretation)

风险态度不是性格，是**位置**。把当前决策放进"损益方向 × 概率高低"的四格，人的倾向系统性翻转（四重模式）：

| | 概率高 | 概率低 |
|---|---|---|
| **收益侧** | 求稳锁定（风险厌恶） | 买彩票式冒险（风险寻求） |
| **损失侧** | 孤注一掷不肯认栽（风险寻求）★最危险 | 买保险式避险（风险厌恶） |

底层是两个机制：损失厌恶（亏 100 的痛≈赚 200 的乐，系数约 2:1）与决策权重失真（确定性被过度加权、小概率要么被高估要么被忽略）。

用法三步：定位参考点（相对什么算赚亏）→ 定象限 → 检查"我的勇气/恐惧是不是这个格的标配情绪"。两个警报：
- **右上格警报**（大概率损失下的风险寻求）：加倍下注、押上全部救项目、败局已定仍拖延——触发止损审查"如果今天刚接手这个局面，我还会继续吗？"，并把翻盘幻想与期望值分开算。
- **过度避险警报**：拒绝正期望的混合赌局；为微小风险支付不成比例的保费——重复发生就是复利式失血，交给风险政策处理。

## A1 — 书中的应用 (Past Application)

### 案例 1: 四重模式预测法律行为
- **问题**: 原告与被告在什么条件下和解、什么条件下硬扛？
- **方法论的使用**: 格思里把四重模式用于民事诉讼：强原告×弱被告（原告在收益侧求稳）应速和解；弱原告×强被告（原告在损失侧冒险）会硬扛滥诉——纽约 200 起滥诉的算术显示坚持诉讼的预期收益（2000 万）远高于立即和解（1000 万），却因"确定损失"的痛而系统性拖延。
- **结论**: 四重模式能预测真实制度行为。
- **结果**: 预测被法学实验与真实和解数据证实。

### 案例 2: 损失厌恶换算与拉宾定理
- **问题**: "同等概率下，亏 100 需要赚多少才肯接受？"多数人答约 200。
- **方法论的使用**: 作者展示该系数外推的荒谬：坚持 2:1 的人必须拒绝"50% 亏 200 / 赢 2 万"这类正期望赌局（拉宾定理）。
- **结论**: 单次窄框架下的损失厌恶会把人锁死在过度避险里。
- **结果**: 解药是宽框架与风险政策（见相关 skill），而非硬着头皮冒险。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 持仓浮亏，纠结"割肉还是加仓摊平"。
2. 项目已亏损，讨论"要不要追加投入赌翻盘"。
3. 面对保险、延保、保修、对冲等"确定小成本 vs 小概率大损失"的选择。
4. 任何"翻本""扳回一局"的心动时刻。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要止损""再赌一把/加仓/翻本""都亏这么多了"
- "买不买保险""万一呢"
- 英文：double down / cut loss / sunk and risky / loss aversion

### 与相邻 skill 的区分

- 与 `frame-check` 的区别：本 skill 的第 1 步"定位参考点"由 frame-check 提供；定位后本 skill 专管象限与警报。

## E — 可执行步骤 (Execution)

1. **定参考点**：写明"相对什么而言算赚/亏"（现状？买入价？年初目标？）。
   - 完成标准：零点已写明
2. **定象限**：结果在收益侧还是损失侧？概率算高还是低？
   - 完成标准：落在四格之一
3. **对照标配情绪**：检查当前的"勇气/恐惧"是否正是该格的系统性倾向。
   - 完成标准：一句话说清"我的情绪是格子给的还是证据给的"
4. **右上格→止损审查**：问"如果今天刚接手这个局面，我还会选继续吗？"把翻盘幻想与期望值分开计算。
   - 判停条件：答案为"不会"→ 执行退出/止损
5. **过度避险→换算检查**：亏 X 需要赚多少才肯接受？远超 2X 且决策会重复发生 → 标记过度避险，交给 `wide-frame-trader`（临场重述为序列）或 `risk-policy`（高频场景一次立法）。
   - 判停条件：敞口威胁生计 → 退出是正确答案，不做"反向说服"
6. **确定性审计**：所有"确定/保证"还原为条件概率，剥掉共同前提重算期望。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 生计级敞口：损失厌恶趋无穷时"退出"就是对的，别把"反着做"当成冒险许可证。
- 纯消费无风险决策。

### 作者在书中警告的失败模式

- 右上角灾难：可控失败被拖成彻底灾难（ce48）。
- 过度避险：拒绝正期望赌局、小风险重复投保长期失血（ce47）。
- 前景理论是**描述**模型不是规范模型：作者自认它"无法应对失望、没有建模后悔"，极端概率处理论失语——"反着做"并不总对。

### 作者的盲点 / 时代局限

- 损失厌恶系数 1.5–2.5 只是均值，个体与情境差异大；禀赋效应在资深交易者、低收入人群中显著削弱。换算结果做参考，不做铁律。

### 容易混淆的邻近方法论

- `wide-frame-trader`：交易者思维降低损失厌恶的**情绪反应**（收益侧小赌注序列）；本 skill 负责定位与警报。先定位，再决定用哪个解药。
