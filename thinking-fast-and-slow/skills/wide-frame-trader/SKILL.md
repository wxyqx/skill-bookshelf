# 宽框架：像交易者一样思考

## R — 原文 (Reading)

> "对宽框架决策的要求则是'将自己想象成交易者''每次都这么做''将其视为诸多金钱决策中的一个，这些决策汇聚在一起形成"投资组合"'。……宽框架减轻了受试者对损失的情绪反应，增强了其承担风险的意愿。"
>
> — 丹尼尔·卡尼曼，第31章

---

## I — 方法论骨架 (Interpretation)

损失厌恶 × 窄框架是"代价高昂的诅咒"：把每个决策当孤例评估时，单次损失的情绪权重最大，人要么过度避险（拒绝正期望的小赌注）、要么被单个损失赶出局。实验证据：同一组决策分开呈现时 73% 的人选了被绝对优势支配的组合，组合呈现时只有 3%；把决策重述为"一系列同类决策之一"时，皮肤电导实测的恐惧反应确实下降。

操作：**像交易者一样思考**——"这是我每年要做的 50 个同类决定之一""有赢就有输"，关注组合的长期统计而非单次得失；同时**降低查账频率**（一个季度看一次），因为频繁查看等于亲手把宽框架拆回窄框架。

两条护栏：
- **聚合三条件**：各次决策相互独立、单次损失不威胁总财富、不是高险低胜率赌注——缺一则宽框架失效，别硬用。
- **占优审计**：多个决策并作时，把净结果合并重算一遍再比（分开都合理的选择，合起来可能被绝对占优）。

判断类单例（定价、赔偿、评分）的宽框架版是**联合评估**：强制找同类参照物并列评估，抑制单独评估时的情绪强度匹配。

## A1 — 书中的应用 (Past Application)

### 案例 1: 73% 选 AD
- **问题**: 两个决策分开作答时各自"合理"，合并评估呢？
- **方法论的使用**: 分开呈现：73% 选了 A 与 D；组合呈现：同样的 A+D 组合被 B+C 绝对占优，仅 3% 选择。
- **结论**: 窄框架系统性地产生被支配的组合。
- **结果**: 作者据此宣称"在所有情况下，将多个决策结合在一起考虑，效果都会更好（至少不会差）"。

### 案例 2: 塞勒的 CEO 故事
- **问题**: 25 位部门主管各自面对"等概率亏一笔或赚两倍"的决策，无人愿意冒险。
- **方法论的使用**: CEO 说"我希望所有高管都接受风险"——组织用涵盖 25 个赌注的宽框架消除层层叠加的过度谨慎。
- **结论**: 单次的"理性避险"在组合层面是集体损失。
- **结果**: 作者提出外部视角+风险政策应成为组织目标。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 投资中单次浮亏带来强烈不适，想清仓退出。
2. 反复做同类小决策（报价、接单、押注、投放）。
3. 发现自己天天盯盘/盯数据，情绪随波动起落。
4. 给多个候选对象单独打分，结果前后矛盾。

### 语言信号 (用户的话里出现这些就应激活)

- "亏了难受""要不要就此收手""每次都纠结"
- "这是常规操作之一""长期做下去值不值"
- 英文：wide frame / think in portfolios / stop checking daily / series of bets

### 与相邻 skill 的区分

- 与 `fourfold-risk-locator` 的区别：定位器诊断你在哪个象限、是否被情绪劫持；本 skill 是收益侧反复小赌注的**解药**（损失侧大额止损直接执行，勿用宽框架安慰自己）。
- 与 `risk-policy` 的区别：交易者思维是**临场重述**（把这次放进序列）；风险政策是**事前立法**（一次性立规、机械执行）。重复频率高到不值得每次重述时，升级为政策。

## E — 可执行步骤 (Execution)

1. **识别窄框架信号**：孤立"要不要"式提问、频繁查结果、单次损失剧痛。
   - 完成标准：指认出至少一个信号
   - 判停条件：决策真孤立且巨大（一生一次）→ 不适用宽框架
2. **过聚合三条件**：相互独立？不威胁生计？非高险低胜率？
   - 判停条件：任一不满足 → 放弃聚合，回到单次分析
3. **重述为序列**："这是我每年要做的 N 个同类决策之一"，写明序列的长期期望。
   - 完成标准：能说出 N 与单次期望值
4. **占优审计**：把近期同类决策的净结果合并重算一遍。
   - 完成标准：合并后的组合优劣已确认
5. **降频**：设定查结果的时间表（如季度一次）并写下来。
6. **单例判断**：为定价/评分/赔偿找同类参照物做联合评估（警惕卖方提供的"对照品"）。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 决策高度相关（同一行业集中持仓）——聚合的是伪组合。
- 高险低胜率赌注——"长期总会赢"在这里是数学错误。
- 单次损失可能致命——退出优先。

### 作者在书中警告的失败模式

- 反向滥用：把宽框架当成过度冒险的许可证（ce50 的另一面）——三条件清单是硬闸。
- 频繁查账主动拆掉宽框架（ce50）。

### 作者的盲点 / 时代局限

- 宽框架的合并计算有真实认知成本（需要纸笔，对系统2昂贵）；"所有情况下更好"的论证忽略了这一点——小决策不必强求正式组合审计，话术重述即可。
- 联合评估可被卖方操纵（提供有利的"对照品"）。

### 容易混淆的邻近方法论

- `risk-policy`：立法化的一次性宽框架，适合高频重复场景；本 skill 适合中频、需要个案判断的序列。
