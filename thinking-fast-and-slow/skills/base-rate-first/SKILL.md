# 贝叶斯纪律：锚定基率 + 质疑诊断力

## R — 原文 (Reading)

> "贝叶斯推理的关键可以简单总结为：将你的概率判断锚定在合理的基础比率上。质疑你对证据的诊断力。"
>
> — 丹尼尔·卡尼曼，第14章

---

## I — 方法论骨架 (Interpretation)

人的默认概率算法是"看像不像"（代表性），这会把基础比率整个扔掉：农民比图书管理员多 20 倍，但一个"像图书管理员"的描述足以让人改答图书管理员。两个固定动作矫正它：

1. **先问总量**：这类事件在总体里多常见？把判断锚在这个数字上，再看个案。
2. **再审证据**：这个证据在"假设为真"和"假设为假"两种情形下出现的比例差多少？直觉通常把弱线索当铁证（4:1 的线索被当成"基本确定了"）。

配套纪律：
- 证据可靠性打折时，最终判断应从直觉印象**滑回基率**，而不是停在两者中间的漂亮位置。
- 最危险的不是没有证据，而是**零信息量的证据**（套话简历、模板推荐信、泛泛评价）——它"看起来像那么回事"，会让你把正确的先验整个扔掉（迪克效应）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 汤姆的专业
- **问题**: 给出汤姆的性格描述（喜欢科幻、数学好），让受试者估计他最可能是哪个专业的研究生。
- **方法论的使用**: 受试者按"最像谁"排序，把人数最多的两个专业（人文教育、社会科学）排到最后；统计学家罗宾·道斯在公开演讲里也当场中招。
- **结论**: 相似性排序被直接当成了概率排序。
- **结果**: 附录A同范式再现："概率排序与相似性排序完全相同"。

### 案例 2: 疾病检测的贝叶斯演算
- **问题**: 基率 1/600 的病，检测似然比 25:1，阳性后真实概率是多少？
- **方法论的使用**: 先锚基率，再用发生比演算：阳性后概率仅约 4%——直觉会给出接近 96% 的答案。
- **结论**: 不做两步演算，"像不像"必然淹没"有多少"。
- **结果**: 作者用此例展示完整的贝叶斯发生比程序。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估"某个体属于某类"的概率（招聘、风控、诊断、筛简历）。
2. 读懂检测/评估/风报类结果（医学检测、告警、模型评分）。
3. 听完一段生动个案描述后要给概率或下判断。
4. 自己发现"我好像完全被这个故事带走了"。

### 语言信号 (用户的话里出现这些就应激活)

- "概率多大""可能性大吗""是XX类型的吗""像不像"
- "检测阳性/命中了/评分很高，怎么办"
- 英文：base rate / how likely / prior / false positive rate

### 与相邻 skill 的区分

- 与 `substitution-check` 的区别：本 skill 是抓回原问题后的统计性作答程序；substitution-check 只负责发现"像不像"替换了"有多少"。
- 与 `four-step-prediction` 的区别：本 skill 管分类/概率判断；后者管数量型预测（GPA、销量、工期）。

## E — 可执行步骤 (Execution)

1. **查基率**：这类事件/这类人在总体里的比例是多少？
   - 完成标准：拿到具体数字（哪怕粗糙）
   - 判停条件：查不到任何基率 → 用相邻类别估计并**显式标注不确定性**，禁止假装精确
2. **审诊断力**：该证据在真/假两种情形下出现的机会比是多少？
   - 完成标准：给出似然比或"证据区分度"的定性判断
3. **组合出概率**：按贝叶斯发生比把基率与证据合并（必要时用"100个里有几个"的频率想象辅助）。
   - 完成标准：得出一个数字及区间
4. **收缩检查**：证据可靠性存疑（来源弱、零信息量、相互抄来的）→ 判断向基率收缩。
   - 判停条件：证据为零信息量 → 直接按基率作答，扔掉"描述"

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 因果排查类问题（"机器为什么停了"）：找原因不是估概率，套贝叶斯会答非所问。
- 真正无类可依的全新事物：硬编基率比承认无知更危险。

### 作者在书中警告的失败模式

- 有个案描述就扔基率（ce14）；只有能编进因果故事的基率（"考试太难了"）被使用，纯统计基率被无视（第16章）。
- 零信息量证据挤出先验（附录A迪克问题）。

### 作者的盲点 / 时代局限

- 关于"人能否学会统计思维"，作者引用的实验偏悲观，且吉仁泽等批评者主张频率格式更符合生态理性——本书第15章的频率表示法实验实际站在批评者一边，教学之争未决。

### 容易混淆的邻近方法论

- `four-step-prediction`：那是给"数量"做回归收缩的程序；本 skill 给"概率/类别"做贝叶斯收缩。两者共享"先基率后证据"的次序。
