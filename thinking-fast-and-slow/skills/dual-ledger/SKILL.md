# 双测量评估：体验幸福与生活评价分开计账

## R — 原文 (Reading)

> "（1）体验价值，即在对结果的实际体验中，快乐或痛苦、满足或苦恼的程度；（2）决策价值，即预期结果对选择中某一选项的整体吸引力或厌恶感的作用。"
>
> — 丹尼尔·卡尼曼（附录B结语）；第37章将其落地为"体验幸福/生活评价"两把尺

---

## I — 方法论骨架 (Interpretation)

"哪个更好"常常无解，因为争论双方用的是**两把不同的尺**：
- **体验幸福尺**：时间加权的过程感受（日重现法思路——把日子切成片段逐段打分）。在这把尺下，慢性疼痛、通勤、睡眠权重巨大，"风光时刻"权重有限。
- **生活评价尺**：叙事与标准达成（坎特里尔阶梯——"我过得怎么样"）。在这把尺下，成就、身份、故事价值权重巨大，时长几乎无关。

同一组选项在两把尺下**排序会翻转**（结肠造口患者体验幸福接近常人、生活评价严重受损；失明与耳聋的排序随尺子变化）。程序不是选一把尺，而是**两把尺各排一遍，把翻转摊开在桌面上**，再由决策者声明价值立场。附录B的同源工具是"决策价值/体验价值"双账本：选时的高分不保证用时的高分（快乐适应、社会比较、饥时点菜）——重大取舍分别以两本账各算一遍。

## A1 — 书中的应用 (Past Application)

### 案例 1: 收入-幸福双层曲线
- **问题**: 金钱到底买不买幸福？
- **方法论的使用**: 约 45 万份盖洛普回复显示两条曲线：体验幸福在某个收入点饱和，生活评价随收入持续上升——"收入高低对幸福的影响"这个争论的双方，各自只看到了一把尺。
- **结论**: 单尺提问必然制造伪争论。
- **结果**: 注意：饱和点数值已被作者 2023 年修正——引用时降级，但"双层结构"的框架本身未被推翻。

### 案例 2: 医疗排序的两难
- **问题**: 失明和耳聋哪个更糟？结肠造口患者的生活质量如何？
- **方法论的使用**: 患者的体验幸福与常人无异，但对自身生活评价严重受损；排序医疗资源时两把尺给出不同答案，作者坦承"这个问题没有简单的解决方案"。
- **结论**: 先声明用哪把尺，再排序——否则讨论永远错位。
- **结果**: 这成为"双测量并陈"而非"单尺裁决"的直接理由。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在两条职业路径、两种生活方式、两座城市之间长期权衡。
2. 评估政策/医疗/福利方案的"生活质量"影响。
3. 争论"X 值不值得"而双方各执一词、越吵越僵。
4. 设计用户研究/满意度调查，担心单指标误导。

### 语言信号 (用户的话里出现这些就应激活)

- "哪个更值得""对人生更好""幸福还是成就""值不值这个代价"
- "生活质量怎么算""两套标准打架"
- 英文：quality of life tradeoff / experienced vs remembered / two measures disagree

### 与相邻 skill 的区分

- 与 `two-selves-check` 的区别：two-selves 是个人单次选择的核查（含后悔矫正）；dual-ledger 是**方案排序框架**，输出两列排序供价值声明。
- 与 `peak-end-design` 的区别：设计体验用峰终；评估排序用双尺。

## E — 可执行步骤 (Execution)

1. **列出选项**：把待排序的方案写成清单。
   - 完成标准：选项齐备
   - 判停条件：仅剩一个可选 → 无排序需求
2. **体验幸福尺排序**：按"时间加权的过程感受"逐项打分排序（考虑日常注意力结构：睡眠、通勤、社交、压力）。
   - 完成标准：一列完整排序
3. **生活评价尺排序**：按"叙事、成就、标准达成"再排一遍。
   - 完成标准：第二列排序
4. **对照声明**：两列一致 → 直接选；翻转 → 把翻转点摊开，由用户声明本次用哪把尺（两者皆合法）。
   - 完成标准：价值立场被显式说出，而非默认
5. **附录B检查**：对重大取舍补算"决策价值账"（选时的吸引力），与体验价值对照，标注预期偏差（适应、社会比较）。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 纯财务或合规决策（金额与法规主导，两把尺无分歧）。
- 用"体验幸福尺"否决他人的人生选择——书中的规范立场是**并陈**，不是裁决（作者明确拒绝在失明/耳聋类问题上给出单一答案）。

### 作者在书中警告的失败模式

- 记忆/体验混淆：把"对体验的记忆"当体验本身，是难以抵御的认知错觉（ce61）。
- 一次性生活满意度问卷被当下心情污染（复印机一角钱实验）——两把尺都要多时点采样。
- 收入饱和线的时代局限：引用"金钱与幸福"结论必须带修正标注。

### 作者的盲点 / 时代局限

- 日重现法早期样本几乎全为女性（作者自注），U 指数活动排序来自美国中西部女性样本——跨人群外推需谨慎。
- 两把尺冲突时没有裁决算法——这是作者公开承认的规范性悬置，本 skill 只能把它显式化。

### 容易混淆的邻近方法论

- 多准则决策（MCQ）：通用的加权评分法会**预先合并**两把尺；本 skill 的核心动作恰恰是**拒绝合并**、并陈翻转。
