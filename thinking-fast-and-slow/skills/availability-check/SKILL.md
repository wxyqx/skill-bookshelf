# 可得性自检两问：例子是怎么进脑子的

## R — 原文 (Reading)

> "你必须重审自己的印象和直觉，提出这样的问题：'我们认为青少年盗窃是重大问题，是因为社区最近发生了几起青少年盗窃案吗？''我觉得没必要接种流感疫苗，是不是因为去年我的熟人都没患流感？'"
>
> — 丹尼尔·卡尼曼，第12章

---

## I — 方法论骨架 (Interpretation)

"容易想起"被系统1当作"经常发生"的证据。但想起的容易程度不取决于真实频率，而取决于四个污染源：**媒体渲染**（意外死亡被高估 300%）、**近因**（上周的新闻）、**亲历**（我一个朋友……）、**情感负荷与生动性**（吓人的画面更好想）。 Worse：有人刻意喂养这个通道——"可得性企业家"靠制造新闻循环放大小风险，恐惧本身成为新故事。

自检程序只有两问：
1. **来源问**：我的例子是最近才变多的吗？是被媒体、亲历还是情感负荷塞进脑子的？
2. **数据问**：真实频率是多少？——然后真的去找分母和数据，而不是停留在"再想想"。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 政客出轨的自我误判（作者亲历）
- **问题**: 作者曾坚信"政客比医生或律师更容易出轨"。
- **方法论的使用**: 追问例子的来源后发现：只是政客的出轨**更容易被媒体曝光**——例子是被记者选题放进脑子的。
- **结论**: 直觉印象"完全来自记者的选题"，判断被推翻。
- **结果**: 作者把它当作全书序言里"发现别人错误容易、发现自己难"的自首式例证。

### 案例 2: 死因排序调查
- **问题**: 人们如何估计各类死因的频率？
- **方法论的使用**: 脑卒中死亡人数是所有意外死亡总和的 2 倍，但 80% 的受试者认为意外更致命——媒体报道的显著性扭曲了风险排序。
- **结论**: 可得性决定公众风险认知。
- **结果**: 该调查成为可得性偏差研究的"标准范例"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估某类风险/现象的普遍性（事故、疾病、骗局、行业趋势）。
2. 刷到连续几条同类新闻后想"是不是变多了"。
3. 用"我身边就有例子"论证判断。
4. 被拉夫运河/艾拉恐慌式的舆论风暴裹挟，需要校准恐慌。

### 语言信号 (用户的话里出现这些就应激活)

- "最近很多XX吧""我总觉得XX危险""身边全是这种例子"
- "新闻上老是报""刷到好几个了"
- 英文：seems so common / availability / is it really that frequent / media bias

### 与相邻 skill 的区分

- 与 `base-rate-first` 的区别：本 skill 负责**清理输入**（例子的来源），base-rate 负责**组合判断**（拿到基率后怎么和证据合并）。两问做完通常直接接入 base-rate-first。
- 与 `rare-events-check` 的区别：那管小概率的特殊失灵（过度看重/忽视）与表述换算；本 skill 管一般频率印象的来源审计。

---

## E — 可执行步骤 (Execution)

1. **写成频率命题**：把"我觉得很普遍"改写为可查证的命题（"XX 的年发生率约为 N/万人"）。
   - 完成标准：命题含可查的量词
   - 判停条件：命题与频率无关（纯价值判断）→ 不适用
2. **来源两问**：例子是最近变多的吗？被谁放进脑子的（媒体/亲历/情感）？
   - 完成标准：至少指认一个污染源
3. **找分母**：去查真实频率数据；查不到用相邻类别估计并标注不确定。
   - 完成标准：有一个数字或明确的"数据不可得"声明
   - 判停条件：数据可得且与印象一致 → 结束，保留直觉
4. **层叠警报**：若话题正处于舆论风暴（报道量激增），把"担心程度"与"报道量"显式分开打分。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 纯机制解释类问题（"为什么会这样"——找原因不是估频率）。
- 已有权威统计数据且用户已引用——直接读数，别把程序当仪式。

### 作者在书中警告的失败模式

- 幻想灾难场景会**人为抬高**探险风险的评估（附录A：可想象性偏差）——想象力只用于穷举清单，不用于赋值。
- 幻觉相关抗反驳：反例不能自动消除"某类人总是伴随某特征"的语感（ce13），必须靠计数。
- 可得性层叠：担心程度恰好等于最近报道量时，你大概率在风暴眼里（ce24）。

### 作者的盲点 / 时代局限

- 书中承认这种警惕"是苦差事"，但未给出触发它的制度化办法（个人很难记住要自检）——组织版建议把"例子来源审计"写进风险评审模板。

### 容易混淆的邻近方法论

- "别信媒体"：本 skill 不是立场宣言，而是两问+找分母的工序；结论可能是"媒体是对的"。
