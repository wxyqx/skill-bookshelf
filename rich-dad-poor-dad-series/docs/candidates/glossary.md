# 富爸爸穷爸爸系列 — 关键术语表

> 本表从《富爸爸穷爸爸系列（共32册）》中提取作者罗伯特·T·清崎自定义、重新定义或反复强调的核心术语。列：术语、作者用法、与常识的差异。

| 术语 | 作者用法 | 与常识的差异 |
|---|---|---|
| 资产 | 不论你是否工作，都能把钱放到你口袋里的东西；核心是产生正现金流。 | 常识把房子、车、奢侈品也视为资产；作者只看“是否持续产生正现金流”。 |
| 负债 | 把钱从你口袋里取走的东西；造成现金流出的义务或物品。 | 常识把自住房、消费贷、汽车贷款视为正常开支；作者将其归为负债。 |
| 现金流 | 收入流入与开支/债务流出之间的差额，可正可负；是衡量财务健康的第一指标。 | 常识更关注工资高低或账面资产；作者强调每月实际进出的现金。 |
| 现金流象限 (E/S/B/I) | E=雇员、S=自由职业者/小业主、B=企业主（拥有可复制系统）、I=投资者（钱生钱）。 | 不是职业分类，而是收入来源与思维模式的分类。 |
| 财商 | 读懂数字、投资、了解市场、运用法律的综合财务智慧；后期扩展为“5种财商”。 | 常识常等同于“会省钱/会记账”；作者强调“让钱增值并受保护”。 |
| 5种财商 | ①赚更多的钱 ②守住你的钱 ③预算你的钱 ④撬起金钱的杠杆 ⑤改善你的财务信息。 | 常识把财商视为单一能力；作者将其拆分为可量化、可修炼的五力模型。 |
| 被动收入 | 不需要你到场工作就能获得的收入，如租金、股息、版税、企业剩余利润。 | 常识易与“理财收益”混为一谈；作者强调持续性、非劳动性。 |
| 劳动性收入 | 靠出卖时间/劳动换来的收入，即工资或服务费。 | 常识视其为最可靠的收入来源；作者认为过度依赖它是“老鼠赛跑”的根源。 |
| 投资组合收入 | 来自纸资产（股票、债券、期权等）的收入。 | 常识把它与“投资赚钱”简单等同；作者将其与劳动收入、被动收入严格区分。 |
| 老鼠赛跑 | 为恐惧和贪婪驱动，不断加薪、增税、增债、增支出的循环；缺乏资产项的财务陷阱。 | 不是简单的“内卷”，而是特指无资产、靠工资度日的财务循环。 |
| 关注自己的事业 | 把精力集中在资产项，而非收入项或别人的事业；持续买入资产。 | 不等于“辞职创业”，而是持续积累属于自己的资产。 |
| 良性债务 | 由别人或资产替你偿还，并能产生现金流的债务；如出租房贷款。 | 常识以“有无抵押/利率高低”区分；作者以“是否增加资产/现金流”区分。 |
| 不良债务 | 由自己掏腰包偿还、不创造资产的债务；如信用卡债、消费贷、自住房贷。 | 常识把房贷视为“好债务”；作者若房产不能带来正现金流则归为不良。 |
| 财富 | 按时间衡量：停止工作后，现有生活水平能维持的天数。 | 常识以净资产或存款数额衡量；作者强调现金流支撑时间。 |
| B型企业 vs S型企业 | B型企业拥有可复制的系统，创始人可离开；S型企业依赖创始人亲力亲为。 | 常识统称“创业”；作者强调系统/可复制性决定企业价值。 |
| OPM（别人的钱） | 利用他人的资金进行投资、杠杆与放大收益。 | 常识：借钱=风险；作者视其为右侧象限必备的资源杠杆。 |
| OPT（别人的时间） | 利用他人的时间为自己工作、创造现金流。 | 常识视雇佣为成本；作者视其为B/I象限的核心资源。 |
| 投资者的7个等级 | 从“一无所有的第0级”到“捐赠者的第7级”，按财商与行为划分投资者成熟度。 | 常识以资产规模分级；作者以认知、行动和财务结果分级。 |
| 投资者的3种类型 | 特许/合格投资者、成熟投资者、内部投资者。 | 常识认为有钱就能做高级投资；作者强调“成熟”比“有钱”更重要。 |
| 成熟投资者（3个E） | 具备 Education（教育）、Experience（经验）、Excess Cash（充足的现金）。 | 不是仅有钱或收入达标即可，而是三者缺一不可。 |
| 特许投资者/合格投资者 | 仅因年收入/资产达标而具备某些投资资格的人。 | 作者认为“光有钱”不等于成熟，这类人反而容易在复杂投资中损失惨重。 |
| B-I三角形 | 成功企业所需的8个要素：使命、团队、领导力、产品、法律、系统、沟通、现金流。 | 常识把“好点子/好产品”当创业核心；作者认为产品只是顶部，系统才是关键。 |
| 荣誉守则 | 团队/组织/家庭内部简单、有力、不可讨价还价且共同遵守的行为规则。 | 不是宗旨声明或价值观罗列，而是可执行、可问责的具体约定。 |
| 销售狗 | 用五种犬类比喻五种销售人格/风格（如狮子狗、比特犬、金毛猎犬等）。 | 常识把销售视为单一技能；作者提供一套识人、育才的销售人格框架。 |
| 强势投资者 | 关注现金流速度、懂得整合资产与杠杆、让钱持续周转的职业投资者。 | 不是长期持有/被动储蓄者，而是主动管理现金流的人。 |
| 现金流的速度 | 钱必须以较快速度周转，否则会受税收侵蚀、通胀和市场波动掠夺。 | 常识倡导“长期持有/存银行”；作者强调周转与再投资。 |
| 整合（vs 分散化） | 把资本集中到2-3类资产中并让它们协同，实现“1+1=4”。 | 常识：不要把鸡蛋放一个篮子；作者反对盲目分散，主张可控整合。 |
| 资本利得 | 买入与卖出资产的价差；通过资产升值获利。 | 作者认为它不如现金流可靠，是“提水桶”而非“铺管道”。 |
| 硬币另一面 | 同一财务/经济现象中常被忽视的相反视角与机会。 | 常识只看到风险/缺钱的一面；作者训练读者看到机会/金钱遍地的一面。 |
| 不公平的优势 | 财商教育、对税收/法律/杠杆/现金流的理解所带来的竞争优势。 | 常识认为优势来自关系或背景；作者认为财商本身就是不公平优势。 |
| 退休方舟 | 在货币贬值、养老金危机、经济动荡等“大洪水”来临前，为自己建造的财务避难所（资产组合）。 | 不是单纯存养老金，而是主动构建能抵御系统性风险的资产结构。 |
| 第二次致富机会 | 当旧有金钱规则失效时，用新的财商思维重新创造现金流与资产的机会。 | 常识把危机视为损失；作者强调危机=呼之欲出的变革=新机会。 |
| 财富基因 | 孩子天生具有的创富潜能、金钱直觉与学习能力。 | 常识认为创富靠后天学历；作者认为教育应“引出”而非压制这种基因。 |
| 财务独立 | 不用为钱工作，每月被动收入≥生活支出；拥有选择权。 | 比“变富”更强调自由与自主，不依赖丈夫、老板或政府。 |
| 财务自由 | 被动收入足以覆盖支出，能够自由选择是否工作、做什么。 | 常识以收入高低衡量成功；作者以是否摆脱“为钱工作”衡量。 |
| 富女人 | 经济上独立、掌控自己财务生活、拥有选择权与自信的女性。 | 打破“女性应依赖他人”的传统观念，重新定义女性与金钱的关系。 |
| 社会企业家 | 以商业手段解决社会问题、兼具使命驱动与商业可持续的创业者。 | 不只是慈善或公益，而是把社会价值与企业盈利结合。 |
| 强行增值/提高附加值 | 低价买入问题资产，解决其内在问题后使其价值回升到市场价。 | 不是等待市场升值，而是主动通过管理/改造创造增值。 |
| 公司面纱 | 公司实体将个人资产与公司负债/风险隔离的法律保护。 | 不只是注册公司，而是维护法律结构的完整性以保护个人财富。 |
| 现金的现金回报率 | 某项投资年现金流/投入现金，衡量真实现金回报。 | 常识看总价升值；作者优先看投入现金能产生多少持续现金流。 |
