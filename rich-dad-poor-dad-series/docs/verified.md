# 阶段 1.5 — 三重验证结果

## 去重说明

127 条原始框架候选来自 `candidates/frameworks.md`，按主题去重后得到 32 个独立框架。淘汰标准为：跨域迁移性弱、仅为术语解释/指标、缺乏案例支撑的预测力、或与已入选/已有 skill 高度重叠。最终保留 18 条可独立成 skill 的框架。
