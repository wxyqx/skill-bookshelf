# 儿童财商教育

## R — 原文 (Reading)

> “给孩子零花钱就是在教孩子为钱工作而不是去创造钱。如果你不教自己的孩子学习理财知识，会有其他人愿意这么做的。”
>
> — 罗伯特·T·清崎，《富爸爸发现你孩子的财富基因》· 第3章 / 《富爸爸别让你的孩子长大为钱所困》· 前言

---

## I — 方法论骨架 (Interpretation)

1. 家庭是孩子的第一所财商学校，父母是无可替代的老师。
2. 用“现金流语言”替代“买不起/要省钱”等雇员语言。
3. 通过真实场景教学：现金流游戏、三个小猪存钱罐、观察银行、为富爸爸免费工作。
4. 区分资产与负债、良性债务与不良债务、三种收入类型。
5. 不给孩子“为钱工作”的零花钱，而是教他们创造、控制和管理金钱。
6. 保护和发现孩子的“财富基因”，用适合其天赋的方式引导。

---

## A1 — 书中的应用 (Past Application)

### 案例 1：三个小猪存钱罐——教孩子“先支付自己”
- **问题**：富爸爸教罗伯特从小就使用三个存钱罐：储蓄、投资和慈善/什一税。
- **方法论的使用**：每次获得收入，先按比例放入这三个罐子，再支付其他账单，这就是“先支付自己”的儿童版实践。
- **结论**：把抽象的财富原则转化为孩子可操作的日常习惯。
- **结果**：养成先投资储蓄再消费的习惯，成年后仍沿用这一原则。

### 案例 2：为富爸爸免费工作与当高尔夫球童
- **问题**：罗伯特从9岁起每周为富爸爸免费工作，下午去高尔夫球场当球童赚钱。
- **方法论的使用**：富爸爸不支付工资，是为了训练他像资本家一样思考，而非像雇员一样为工资工作。
- **结论**：童年时期的劳动可以是为了学习商业模式，而不仅仅是为了换取零花钱。
- **结果**：从小理解OPT、OPM和企业运营，为成年后的创业与投资奠定思维基础。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 孩子做家务要钱，家长想用零花钱培养财商却不知怎么做。
2. 孩子看到广告想要玩具，家长想借机讲资产与负债。
3. 青少年对“找工作/上大学”只有单一雇员思维。

### 语言信号 (用户的话里出现这些就应激活)

- “怎么教孩子理财 / kids financial education”
- “该不该给孩子零花钱”
- “孩子财商怎么培养”

### 与相邻 skill 的区分

- 与 `asset-liability-filter` 的区别：儿童财商是把资产/负债概念翻译成孩子能理解的语言和行为，不是成人购买决策。
- 与 `cashflow-quadrant` 的区别：儿童财商侧重家庭教育场景，不是个人象限定位。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **转换家庭金钱语言**
   - 完成标准：家庭成员列出5句常用语的替代说法（如“买不起”→“我们怎么让钱工作”）。

2. **建立可视化现金流工具**
   - 完成标准：用三个存钱罐或电子账本把收入分成储蓄、投资、消费/慈善，孩子每周能自主分配一次收入。

3. **设计真实场景练习**
   - 完成标准：每月至少带孩子完成1次真实金钱体验（观察银行、玩现金流游戏、为家庭小型“创业”记账）。

4. **区分收入类型与债务类型**
   - 完成标准：孩子能用自己的话复述资产与负债的定义，并举出1个生活中的例子。

5. **发现并保护财富基因**
   - 完成标准：记录孩子的3个财商强项和1个待引导点，并设计对应的练习。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 孩子年龄过小、无法理解抽象概念时强行灌输；先培养习惯和语言。
- 把成人投资产品/杠杆直接套用到孩子身上。

### 作者在书中警告的失败模式

- **给孩子零花钱却教他们为钱工作**：用零花钱教孩子“劳动换钱”，而非创造现金流（rd31）。
- **教孩子找安稳工作**：向孩子传递“上学—找工作—求安稳”的路径（rd32）。
- **学校不教财商却教孩子存钱**：让学校承担财商教育，而学校只传授过时的金钱规则（rd06）。
- **盲目追求高学历和安稳工作**：把教育和职业目标限定为“高学历+高薪雇员”（rd05）。

### 作者的盲点 / 时代局限

- 成书于20世纪末，对数字支付、电子钱包、在线游戏经济、短视频带货等现代儿童金钱场景覆盖不足。
- 部分建议（如让孩子免费为富爸爸工作）在当代劳动法规和文化环境中需要谨慎本地化。
- 模型假设父母本身具备财商，若父母自身财商不足，可能难以有效传递。

### 容易混淆的邻近方法论

- `asset-liability-filter`：成人购买决策框架。
- `cashflow-quadrant`：个人象限定位。
- `pay-yourself-first`：现金流纪律，可用于儿童版但场景更窄。
