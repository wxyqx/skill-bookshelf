# OPM/OPT 杠杆模型

## R — 原文 (Reading)

> 如果你想致富，你需要懂得如何用别人的钱，而不是你自己的钱致富。
>
> — 罗伯特·T·清崎，《富爸爸杠杆致富》· 导言

---

## I — 方法论骨架 (Interpretation)

杠杆模型的核心是：用你缺乏的资源（资金或时间）去撬动能够产生正现金流的资产。

1. **OPM（Other People's Money，别人的钱）**：银行贷款、合伙人资金、债券、卖方融资、信用卡短期资金等。
2. **OPT（Other People's Time，别人的时间）**：雇员、外包团队、合伙人、顾问、系统化的流程。
3. **使用前提**：借来的钱或时间必须投向能创造现金流的资产；若用于消费或投机，则变成不良债务。
4. **安全边际**：确保资产现金流即使在利率上升、空置率上升或收入下降时仍能覆盖服务成本。
5. **目标**：让别人的资源替你工作，从而把有限自有资金放大到更大的资产规模。

## A1 — 书中的应用 (Past Application)

### 案例 1: 毛伊岛公寓——第一次 100% OPM 投资
- **问题**: 罗伯特发现一处无抵押品赎回权的公寓，售价 1.8 万美元，自有资金不足。
- **方法论的使用**: 卖家提供 90% 融资；他用信用卡支付 10% 首付，实现完全使用他人资金购房。
- **结论**: 当资产本身能产生正现金流时，借钱不是风险，而是放大收益的工具。
- **结果**: 每月获得约 25 美元正现金流，验证了用债务杠杆创造财富的可行性。

### 案例 2: 为富爸爸免费工作与当高尔夫球童——OPT 的童年训练
- **问题**: 9 岁的罗伯特想在富爸爸身边学习，但富爸爸不付工资。
- **方法论的使用**: 富爸爸用“无薪工作”训练他像资本家一样思考；罗伯特下午当球童赚取生活费用，把上午时间用于学习商业模式。
- **结论**: 时间是比钱更稀缺的资源，学会购买或换取别人的时间是 B/I 象限的核心能力。
- **结果**: 从小理解 OPM、OPT 和企业运营，为成年后的创业与投资奠定思维基础。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点可动用的外部资源**
   - 完成标准: 列出用户可获得的 OPM（银行贷款额度、合伙人、卖方融资、信用卡额度等）和 OPT（可雇佣/合作的人力、可外包的流程）。

2. **确认目标资产的现金流能力**
   - 完成标准: 用保守估算验证资产在扣除运营成本和债务服务后仍能产生正现金流。
   - 判停条件: 若资产现金流为负或无法估算，则暂停杠杆建议，先转 `real-estate-cashflow` 或 `asset-liability-filter`。

3. **设计杠杆结构**
   - 完成标准: 给出具体的融资比例、利率上限、还款来源、最坏情况下的现金流缺口与应对方案。

4. **设定风险红线**
   - 完成标准: 明确“利率上升到多少、空置率达到多少、收入下降到多少”时必须止损或追加资本金。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户想借钱消费、还信用卡账单或周转不良债务——应优先处理现金流和债务问题，而非加杠杆。
- 用户完全没有可产生现金流的资产标的——杠杆没有附着点，建议先积累资产或财商。

### 作者在书中警告的失败模式

- **过度杠杆**：在缺乏现金流和财商的情况下借钱投资，市场一下行就会爆仓。
- **把工具当根源**：有人因滥用信用卡而剪卡，却没改变消费习惯；清崎认为“扔掉信用卡不会致富，只会带来不便”。

### 作者的盲点 / 时代局限

- 书中大量案例基于美国房地产、C/S 型公司税法和 1031 交换条款，中国读者在房贷政策、首付比例、利率、公司结构上差异很大。
- 清崎对“良性债务”的强调可能诱导风险偏好不足者过度借贷；真实世界中破产、诉讼、家庭破裂的代价常被低估。

### 容易混淆的邻近方法论

- `bi-triangle` 中的“团队”和“系统”也涉及 OPT，但 B-I 三角形聚焦企业八要素的整体架构；本 skill 聚焦“资源放大”这一单一杠杆动作。
