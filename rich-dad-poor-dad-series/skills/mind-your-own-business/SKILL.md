# 关注自己的事业 / 资产项优先

## R — 原文 (Reading)

> 为了财务安全，人们需要关注自己的事业。你的事业的重心是你的资产项，而不是你的收入项。职业是别人的事业，自己的事业是不断积累资产。
>
> — 罗伯特·T·清崎，《富爸爸穷爸爸》第三课

---

## I — 方法论骨架 (Interpretation)

“你的事业”不是你现在的工作岗位，而是你不断积累的资产项。这个框架要求你：
1. **区分工作与事业**：工作是帮别人建资产；事业是建自己的资产。
2. **把额外收入/精力投入资产项**：租金房产、能产生现金流的企业、股票/债券股息、版税、知识产权等。
3. **让资产项增长成为主要目标**：收入只是暂时现金流，资产才是长期财务安全。
4. **不等辞职**：即使仍在E/S象限工作，也可以边工作边买入资产，逐步让资产收入超过工资。

它不等于“辞职创业”。它是把注意力从“如何赚更多工资”转向“如何建立和扩大能持续产生现金流的资产”。

## A1 — 书中的应用 (Past Application)

### 案例 1: 从关注“收入项”转向关注“资产项”
- **问题**: 罗伯特一度把所有精力放在提高销售额和收入上。
- **方法论的使用**: 在凤凰城爬山时意识到，真正带来财富的是《现金流》游戏和《富爸爸穷爸爸》这些资产，而不是销售额或工资。
- **结论**: 把注意力从“如何赚更多收入”转向“如何建立和扩大资产项”。
- **结果**: 富爸爸公司围绕书籍、游戏、课程等资产持续增长，收入不再依赖单一劳动。

### 案例 2: 富爸爸带孩子观察银行
- **问题**: 如何让孩子理解“别人的事业”与“自己的事业”。
- **方法论的使用**: 带罗伯特和迈克坐在银行外观察存款人和借款人，指出银行用存款人的钱放贷赚取利差，这是银行自己的事业。
- **结论**: 理解资金流动和资产项优先思维，从小建立资本家视角。
- **结果**: 孩子形成关注资产项、利用OPM的思维基础。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 工作多年，想知道自己除了工资还积累下什么。
2. 想开始“自己的事业”，但不确定是辞职创业还是在职买资产。
3. 纠结应该把精力投向升职加薪还是投向买房/投资/副业资产。

### 语言信号 (用户的话里出现这些就应激活)

- "关注自己的事业是什么意思"
- "工作是别人的事业吗"
- "我该把精力放在资产项还是收入项"
- "除了工资我还能建什么资产"
- "我不为别人打工还能做什么"

### 与相邻 skill 的区分

- 与 `cashflow-quadrant` 的区别: ESBI判断象限位置；关注自己的事业强调把精力持续投向资产项。
- 与 `asset-liability-filter` 的区别: 资产/负债区分法判断单笔现金流方向；关注自己的事业是长期行为策略。
- 与 `rat-race-detector` 的区别: 老鼠赛跑识别循环；关注自己的事业给出跳出循环的方向。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点现有资产项**
   - 完成标准: 列出用户名下所有能产生现金流的资产，并计算每月被动收入。

2. **区分工作与事业**
   - 完成标准: 帮助用户明确：工作是获取现金流和经验的手段，事业是持续增长的资产组合。

3. **制定资产优先行动**
   - 完成标准: 建议下一步买入或建立的资产类型（房地产、企业、纸资产、知识产权等），匹配用户象限迁移目标。
   - 判停条件: 若用户当前无任何资产且现金流紧张，建议先配合 `pay-yourself-first` 建立第一笔资本。

4. **设定资产项增长指标**
   - 完成标准: 设定可量化的短期目标，如“6个月内买入第一个产生正现金流的资产”或“资产月收入增加X元”。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户在问具体某笔支出是不是资产——应转 `asset-liability-filter`。
- 用户在问如何跳槽、写简历、谈薪资——这是普通职业规划问题。
- 用户在问企业B-I三角形的系统搭建——应转B-I三角形框架（未在本次6个skill中）。

### 作者在书中警告的失败模式

- 只关注收入不关注资产：一生追求更高工资，却不积累能产生现金流的资产（rd09）。
- 把S型企业当B型企业：创业却没有可复制系统，只是换了一份更累的工作（rd21）。
- 亲力亲为导致无法扩展：收入=时间×费率，被个人时间天花板限制（rd22）。
- 小视野只看眼前：只关注工资、存款、还清债务，忽视资产和象限迁移（rd23）。

### 作者的盲点 / 时代局限

- 对创业失败的美化：书中低估破产、诉讼、家庭破裂等真实代价。
- 可复制性被高估：普通人很难复制清崎的书籍、游戏、研讨会等成功路径。
- 忽视结构性约束：起点资本、家庭资源、地域差异等对财富积累的影响被淡化。

### 容易混淆的邻近方法论

- 创业导师常说的“做自己热爱的事”：关注自己的事业不是找热情，而是建资产。
- 职场发展/个人品牌：个人品牌可能是资产，也可能只是S型劳动收入的放大器。
- 副业/斜杠：多做一份兼职仍在卖时间；关注自己的事业要求买入或建立资产。
