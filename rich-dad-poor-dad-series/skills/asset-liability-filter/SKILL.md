# 资产与负债区分法

## R — 原文 (Reading)

> 资产是能把钱放进我口袋里的东西，不管我工作与否；负债是把钱从我口袋里取走的东西。富人不断买入资产，穷人只有支出，中产阶级购买自以为是资产的负债。
>
> — 罗伯特·T·清崎，《富爸爸穷爸爸》第二课

---

## I — 方法论骨架 (Interpretation)

这个方法论只用一个标准判断一切：现金流方向。
- **资产**：即使你不工作，也能持续把钱放进你口袋的东西（租金、股息、版税、企业利润等）。
- **负债**：持续把钱从你口袋里取走的东西（房贷、车贷、信用卡债、维护费等）。
- **支出**：一次性花掉、不再产生后续现金流的钱（日常消费）。

它不在乎账面名称或市场价格。自住房、豪车、名牌包在常识里可能是“资产”，但只要它们每月让你掏钱维持，就属于负债。富人持续买入资产，中产误把负债当资产，穷人只有支出。

## A1 — 书中的应用 (Past Application)

### 案例 1: 富爸爸讲授资产与负债的核心分法
- **问题**: 9岁的罗伯特和迈克不懂得钱为什么让大人那么焦虑。
- **方法论的使用**: 富爸爸用两句话定义资产/负债，并用简单现金流图说明。
- **结论**: 从此以后判断每笔支出只看“钱往哪流”。
- **结果**: 罗伯特形成持续买入资产、关注现金流的习惯，最终建立富爸爸资产组合。

### 案例 2: 1985年无家可归后重建资产负债表
- **问题**: 尼龙钱包生意失败后，罗伯特和金身无分文、负债82万美元。
- **方法论的使用**: 他们没有只看“欠了多少钱”，而是重新盘点哪些是真正产生现金流的资产、哪些是消耗现金的负债。
- **结论**: 必须先诚实面对资产负债结构，才能东山再起。
- **结果**: 数年后重建事业与资产，最终创办富爸爸教育公司。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 准备买房、买车或买大件，想知道这是资产还是负债。
2. 看到别人晒房晒车，困惑为什么自己“资产”很多却存不下钱。
3. 想整理个人/家庭资产负债表，判断哪些是真正值钱的资产。

### 语言信号 (用户的话里出现这些就应激活)

- "房子是不是资产"
- "这车/包买了是资产还是负债"
- "我有多少资产，为什么还这么穷"
- "现金流方向怎么判断"

### 与相邻 skill 的区分

- 与 `cashflow-quadrant` 的区别: ESBI判断人的收入来源象限；资产/负债区分法判断单笔物品或账户的现金流方向。
- 与 `good-debt-bad-debt` 的区别: 债务框架判断“借钱”本身的性质；资产/负债框架判断“买来的东西”是流入还是流出。
- 与 `mind-your-own-business` 的区别: 关注自己的事业强调持续买入资产的行为方向；资产/负债区分法提供买入前的判断标准。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出待判断对象**
   - 完成标准: 让用户明确具体物品/账户（房子、车、股票、生意等）。

2. **询问现金流方向**
   - 完成标准: 问“每个月/每年它给你多少钱？你为它花多少钱？包括贷款、税费、维护、折旧等。”
   - 判停条件: 若用户只谈升值预期而不谈现金流，提示“清崎只看现金流”。

3. **归类并打标签**
   - 完成标准: 给出结论——净现金流入=资产；净现金流出=负债；一次性花费=支出。

4. **给出行动建议**
   - 完成标准: 若是负债/支出，问“能否把它转化为资产？”（如出租、产生现金流）；若是资产，问“如何继续买入更多同类资产”。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户在问企业估值、股票PE/PB等投资分析——应转更专业的投资框架。
- 用户在问情感性消费决策（“我该不该买这个包奖励自己”）——资产/负债法可给出财务判断，但不能替代价值观选择。
- 用户在问某笔债务的利率、期限、信用影响——应转 `good-debt-bad-debt`。

### 作者在书中警告的失败模式

- 把自住房当作最大资产：自住房持续产生房贷、税费、维护等现金流出（rd04）。
- 把账面资产当实际财富：市值会波动，账面财富可能随市场逆转而蒸发（rd28）。
- 购买消费品和不良债务：中产阶级把奖金用于汽车、更大房子等消费品，进一步增加负债（rd07）。
- 忽视现金流只追资本利得：只看价格涨跌，不关心资产是否产生正现金流（rd34）。

### 作者的盲点 / 时代局限

- 美国房地产语境：自住房的税法和抵押制度与中国不同，不能简单照搬。
- 对资产价格波动的低估：房产、股票等资产价格可能长期下跌，现金流也可能中断。
- 对消费品质的忽视：过度强调现金流，可能低估自住、教育、健康等“负债”的人生价值。

### 容易混淆的邻近方法论

- 会计准则的资产定义：会计按所有权和公允价值记账，可能把自住房、车列为资产；富爸爸只看现金流。
- 极简主义/断舍离：那是消费控制方法，不判断现金流方向。
- 会计学“净资产=资产-负债”：账面净资产高不等于财务自由，关键是现金流。
