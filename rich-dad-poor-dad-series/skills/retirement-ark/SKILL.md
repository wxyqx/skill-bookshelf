# 退休方舟 / 财富大趋势

## R — 原文 (Reading)

> “通过集中精力实现向右侧象限的转变，艾伦在成功脱离‘老鼠赛跑’陷阱的同时，也为自己打造了财务方舟。”
>
> — 罗伯特·T·清崎，《富爸爸财富大趋势》· 第20章

---

## I — 方法论骨架 (Interpretation)

1. 不要把退休安全交给雇主养老金、政府社保或401k等单一渠道。
2. 把退休视为“财务方舟”：在货币贬值、经济动荡的大洪水来临前，建造多元资产组合。
3. 方舟的核心是现金流管道：企业、房地产、纸资产三类资产相互支撑。
4. 关注宏观趋势（通胀、货币规则、养老金危机），用财商调整资产结构。
5. 年轻时就开始把劳动收入转化为被动收入和投资组合收入。
6. 目标是被动收入 ≥ 生活支出，而非某个固定数字。

---

## A1 — 书中的应用 (Past Application)

### 案例 1：1971年尼克松取消美元金本位
- **问题**：1971年尼克松宣布美元与黄金脱钩，美元从贵金属支撑的现金变成债务凭证。
- **方法论的使用**：历史事件说明，货币规则变化会重塑财富分配；持有现金流资产和硬资产才能保护自己。
- **结论**：退休方舟必须考虑货币贬值与系统性风险，不能只依赖现金或固定养老金。
- **结果**：美元购买力长期下降，推动作者强调现金流、黄金、房地产等硬资产。

### 案例 2：1974年ERISA法案——退休金风险从雇主转向雇员
- **问题**：美国通过ERISA法案，固定福利养老金逐渐转向401(k)等固定缴款计划，投资风险从雇主转移给雇员。
- **方法论的使用**：富爸爸认为这一变化强迫不具备投资教育的雇员承担专业投资者的风险。
- **结论**：不懂财商的人在规则变化中被动受损，财商教育是应对制度变化的护城河。
- **结果**：普通雇员被迫成为401(k)投资者，但多数人缺乏财商准备，风险暴露加剧。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 发现自己完全依赖公司年金/社保/401k，担心未来不够用。
2. 中年想了解如何把工资收入转化为退休现金流。
3. 经历通胀/经济动荡后想重新配置资产。

### 语言信号 (用户的话里出现这些就应激活)

- “我的退休计划安全吗”
- “怎么打造退休方舟 / retirement ark”
- “只靠养老金够吗”

### 与相邻 skill 的区分

- 与 `put-money-to-work` 的区别：退休方舟是长期、抗系统性风险的资产结构；put-money-to-work 强调让每笔资金承担明确现金流任务。
- 与 `real-estate-cashflow` 的区别：退休方舟使用多元资产（企业、房产、纸资产），不单指房地产。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **盘点现有“退休依赖”**
   - 完成标准：列出养老金、社保、401k、房产、储蓄等，标注哪些是他人承诺、哪些是现金流资产，画出退休现金流来源占比图。

2. **识别宏观风险敞口**
   - 完成标准：评估通胀、货币贬值、养老金缺口、税收变化对你的影响，写出最担心的2个系统性风险。

3. **设计三类资产方舟**
   - 完成标准：企业/房地产/纸资产按能力、年龄、风险承受配置，设定每类资产目标占比和最低被动收入目标。

4. **制定右侧象限迁移计划**
   - 完成标准：明确从E/S向B/I迁移的时间表和里程碑，12个月内有第一项非工资现金流资产启动。

5. **动态再平衡规则**
   - 完成标准：每半年复查现金流覆盖支出的比例、资产价格与负债结构，建立触发再平衡的量化阈值。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 短期市场预测或择时；那是 `four-pillars-investing`。
- 没有任何现金流资产时过度依赖杠杆；先走 `good-debt-bad-debt`。

### 作者在书中警告的失败模式

- **依赖401k等退休金计划**：把退休安全完全寄托于波动市场和他人的投资产品（rd11）。
- **依赖政府社保和福利**：把养老责任完全交给政府（rd12）。
- **用工业时代思维应对信息时代**：沿用“稳定工作—养老金—退休金”的旧路径（rd13）。
- **忽视通货膨胀**：只存现金或低收益储蓄，让购买力被通胀侵蚀（rd24）。
- **把自住房当作最大资产**：误以为自住房是退休资产（rd04）。

### 作者的盲点 / 时代局限

- 大量案例、税法（401k、IRA）基于美国制度，对中国读者的社保、企业年金、税收环境适用性有限。
- 对平台经济、远程自由职业、加密货币/DeFi等21世纪新形态基本没有系统讨论。
- 清崎对房地产“永远看涨”、黄金/白银对抗法币的判断带有特定经济周期色彩。

### 容易混淆的邻近方法论

- `put-money-to-work`：强调资本效率，退休方舟强调长期安全结构。
- `real-estate-cashflow`：只聚焦房地产现金流。
- `good-debt-bad-debt`：用于判断债务性质，不是退休规划。
