# 老鼠赛跑识别与跳出

## R — 原文 (Reading)

> 起床，上班，付账，再起床，再上班，再付账……他们的生活永远被这两种感觉所控制：恐惧和贪婪。给他们更多的钱，他们就会以更高的开支重复这种循环。这就是我所说的“老鼠赛跑”。
>
> — 罗伯特·T·清崎，《富爸爸穷爸爸》第一章

---

## I — 方法论骨架 (Interpretation)

老鼠赛跑不是简单的“忙”或“穷”，而是一种由情绪驱动的无资产循环：
1. **恐惧没钱** → 拼命工作换取工资。
2. **工资到手** → 欲望膨胀，消费升级、负债增加。
3. **开支上升** → 更需要工资，恐惧加深。
4. **加薪/跳槽** → 再次提高开支，循环重启。

打破循环的关键不是赚更多，而是**建立能产生现金流的资产项**，让被动收入逐步覆盖支出。只有当资产现金流 > 生活支出时，才算跳出老鼠赛跑。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 马丁夫人便利店——每小时10美分的工作课
- **问题**: 罗伯特和迈克在便利店工作，每小时仅10美分，想放弃。
- **方法论的使用**: 富爸爸不给他们工资，是为了逼他们意识到：如果只为钱工作，就永远在老鼠赛跑里。
- **结论**: 真正的教育不是如何找到更高薪的工作，而是如何让钱为自己工作。
- **结果**: 罗伯特学会跳出“为工资工作”的思维，转向寻找资产和机会。

### 案例 2: 罗伯特和金发明《现金流》游戏
- **问题**: 如何让人们直观理解老鼠赛跑并学会跳出。
- **方法论的使用**: 把收入、支出、资产、负债、市场机会做成桌面游戏，让玩家反复体验循环。
- **结论**: 只有被动收入超过支出，才能从“老鼠跑道”进入“快车道”。
- **结果**: 游戏成为全球财商教育载体，帮助无数人可视化老鼠赛跑。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 工资年年涨，但存款和净资产几乎没增长，感觉越忙越穷。
2. 刚拿到奖金/加薪就换车、换房、升级消费，随后压力更大。
3. 害怕失业、不敢辞职，收入来源只有工资，没有被动收入。

### 语言信号 (用户的话里出现这些就应激活)

- "我好像在老鼠赛跑里"
- "工资涨了但存款没涨"
- "越赚越穷，越忙越焦虑"
- "一停止工作就没收入"
- "起床上班付账循环"

### 与相邻 skill 的区分

- 与 `cashflow-quadrant` 的区别: ESBI解释收入来源象限；老鼠赛跑识别是否陷入“无资产循环”的情绪机制。
- 与 `pay-yourself-first` 的区别: 先支付自己是打破循环的具体现金流纪律；老鼠赛跑是诊断循环的框架。
- 与 `mind-your-own-business` 的区别: 关注自己的事业强调把精力投向资产项；老鼠赛跑强调识别恐惧-贪婪驱动的循环。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认老鼠赛跑信号**
   - 完成标准: 检查用户是否有“加薪→增支→更怕失业→更拼命工作”的循环。

2. **盘点资产项**
   - 完成标准: 询问用户当前有哪些持续产生现金流的资产（租金、股息、版税、企业利润等）。
   - 判停条件: 若资产项为零或接近零，确认仍在老鼠赛跑中。

3. **量化跳出条件**
   - 完成标准: 计算“被动收入 ≥ 月支出”所需的资产规模或现金流目标。

4. **给出跳出动作**
   - 完成标准: 建议先支付自己、削减不良负债、把第一笔可投资现金投入能产生现金流的资产，而不是消费升级。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只是短期遇到一笔大额支出（如医疗费、学费）——这是现金流管理问题，不是结构性老鼠赛跑。
- 用户想讨论具体投资标的——应转投资分析或 `good-debt-bad-debt`。
- 用户只是想记账或做预算——应转 `pay-yourself-first`。

### 作者在书中警告的失败模式

- 为钱工作陷入老鼠赛跑：工资越高，开支越高，永远离不开工作（rd02）。
- 被恐惧和贪婪控制财务决策：用情绪代替思考，做出短视选择（rd03、rd18）。
- 认为工作带来安全感：把稳定工作等同于安全，忽视收入来源单一化（rd08）。
- 追求快速致富：因急于跳出而陷入骗局或不切实际投机（rd14）。

### 作者的盲点 / 时代局限

- 过度强调情绪驱动：忽视了低收入群体真实的生存压力，不是所有人都有余裕“先支付自己”。
- 对消费升级的道德化：有时把正常的生活改善也视为“贪婪”。
- 时代背景：清崎成书于美国1970s-2000s，对当代租房、零工经济、AI替代等场景覆盖不足。

### 容易混淆的邻近方法论

- 普通“时间管理/效率提升”：老鼠赛跑不是忙，而是无资产循环。
- 极简主义/FIRE运动：FIRE强调降低支出和储蓄率；老鼠赛跑强调建立资产现金流。
- 职业规划/跳槽涨薪：这些仍在E/S象限内优化，不改变老鼠赛跑结构。
