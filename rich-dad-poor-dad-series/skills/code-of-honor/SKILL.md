# 荣誉守则 / 团队建设

## R — 原文 (Reading)

> “大多数人直到面临压力时才真正认清他们团队中的成员是些什么人，等到此时再开始谈论团队守则就为时已晚。团队守则为成员们创建了一个框架，使得每个人不仅明白在顺境时如何彼此相处，而且懂得在逆境时如何相互合作。”
>
> — 罗伯特·T·清崎，《富爸爸胜利之师》· 第1章

---

## I — 方法论骨架 (Interpretation)

1. 团队崩溃常不是因为没才华，而是没约定。荣誉守则是提前写下的“高压下的行为规则”。
2. 守则必须简单、有力、不可讨价还价，涵盖职业精神、诚信、沟通、合作。
3. 守则在顺境和逆境都适用；压力越大，守则越能防止内斗与甩锅。
4. 每个人都要参与制定并公开承诺，违反要有明确的问责机制。
5. 荣誉守则不是价值观口号，而是可执行、可衡量的团队契约。
6. 定期复盘守则执行情况，必要时升级条款。

## A1 — 书中的应用 (Past Application)

### 案例 1：美好世界书店——社会企业的商业向善模式
- **问题**：美好世界书店想通过商业模式解决社会问题，同时保持财务可持续。
- **方法论的使用**：运用B-I三角形和使命驱动，把社会价值与企业盈利结合，形成了清晰的团队守则与合作规则。
- **结论**：使命驱动的团队需要荣誉守则将“向善”变成可执行、可问责的日常行为。
- **结果**：为公益筹集1000万美元，同时建立可持续的盈利企业。

### 案例 2：尼龙钱包创业——从热销到被山寨再到东山再起
- **问题**：罗伯特的尼龙钱包公司快速成功后，因缺乏法律保护、系统与品牌而濒临倒闭。
- **方法论的使用**：重建时不仅需要补齐B-I三角形要素，也需要让团队围绕共同使命和规则重新合作。
- **结论**：企业遇到逆境时，荣誉守则能帮助团队聚焦问题而不是互相指责。
- **结果**：经历破产与东山再起，学到品牌、法律与系统的重要性。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 合伙创业前想先约定“分钱、决策、退出”规则。
2. 团队扩张后出现甩锅、信息不对称、信任下降。
3. 家庭共同理财/创业时，成员对金钱观冲突。

### 语言信号 (用户的话里出现这些就应激活)

- “我们要不要先定个荣誉守则”
- “合伙创业前怎么约定规则”
- “团队文化落不了地”

### 与相邻 skill 的区分

- 与 `bi-triangle` 的区别：荣誉守则聚焦“团队”要素中的文化与问责机制，不是整个企业八要素诊断。
- 与 `sales-dogs` 的区别：荣誉守则是团队契约，不是销售人格模型。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **明确守则覆盖的高压场景**
   - 完成标准：列出团队最可能冲突的3-5个情境（分钱、加班、客户归属、信息透明、退出），成员达成共识。

2. **制定3-5条不可讨价还价的守则**
   - 完成标准：每条守则具体、可观察、可问责；所有成员能用一句话复述。

3. **公开承诺与签字**
   - 完成标准：每位成员书面承诺并明确违约后果，形成可回看的团队守则文档。

4. **顺境/逆境双测试**
   - 完成标准：用最近一次成功和一次挫折复盘守则是否被遵守，识别至少1个守则漏洞并修订。

5. **定期审计与升级**
   - 完成标准：每季度评估守则执行情况，必要时升级条款。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 个人决策或一对一冲突调解；那是沟通/谈判技巧。
- 团队尚未形成、目标未明确时强行定守则；先完成 `startup-ten-lessons`。

### 作者在书中警告的失败模式

- **创业没有系统**：只凭热情创业，没有团队规则与法律结构（rd38）。
- **亲力亲为导致无法扩展**：创始人包揽一切，团队无法成长（rd22）。
- **用情绪代替思考**：压力下互相指责，而不是按守则解决问题（rd18）。
- **把S型企业当B型企业**：缺乏可复制系统，团队离开创始人就停摆（rd21）。

### 作者的盲点 / 时代局限

- 强调面对面团队和体育/军事隐喻，远程/异步团队需调整执行方式。
- 合伙法律细节（股权、退出机制）因地区差异大，需本地化律师补充。
- 模型更适合小型创业团队，大型组织的文化落地需要更复杂的变革管理。

### 容易混淆的邻近方法论

- `bi-triangle`：团队只是八要素之一。
- `startup-ten-lessons`：创业前的整体准备。
- `sales-dogs`：销售团队的风格搭配。
