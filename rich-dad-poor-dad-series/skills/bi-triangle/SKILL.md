# B-I 三角形（企业八要素）

## R — 原文 (Reading)

> 每种生意都由8个元素组成，而不知道如何拥有这8个元素是许多人失败和不赢利的原因所在。
>
> — 罗伯特·T·清崎，《富爸爸成功创业的10堂必修课》· 第1讲

---

## I — 方法论骨架 (Interpretation)

B-I 三角形是清崎用来诊断和构建可扩张企业的八要素模型：

1. **使命**：企业为何存在，解决什么问题。
2. **团队**：拥有互补技能的合伙人、员工与顾问。
3. **领导力**：把团队凝聚在使命周围并做出决策的能力。
4. **产品**：位于三角形顶部，是企业对外的价值交付物。
5. **法律**：公司结构、合同、知识产权、合规与资产保护。
6. **系统**：可复制、可脱离创始人的流程与标准。
7. **沟通**：销售、品牌、对内对外信息传递。
8. **现金流**：企业血液，三角形底部，决定生死。

关键洞察：好产品只是顶部一角；若缺乏系统、法律、现金流和团队，企业只能停留在 S 型小作坊，无法成为 B 型企业。

## A1 — 书中的应用 (Past Application)

### 案例 1: 尼龙钱包创业——从热销到被山寨再到东山再起
- **问题**: 1977 年罗伯特创办尼龙钱包公司，产品风靡全球，但很快被亚洲制造商大量仿冒，公司濒临倒闭。
- **方法论的使用**: 他意识到失败的关键不是产品不好，而是缺乏法律保护（专利）和强势品牌系统。
- **结论**: 创业不能只靠产品，必须同时建设 B-I 三角形中的法律、系统和品牌要素。
- **结果**: 后来获得摇滚乐队授权，转型为品牌生产商，零售价重回 10 美元，东山再起。

### 案例 2: 麦当劳——不是做汉堡，而是做房地产与系统
- **问题**: 雷·克罗克如何把一家快餐店扩展为全球品牌？
- **方法论的使用**: 他把“汉堡”仅视为产品，真正的核心资产是：选址系统、加盟系统、现金流系统，以及繁华十字路口的房地产。
- **结论**: B 型企业的价值在于可复制系统，而非创始人亲自做汉堡。
- **结果**: 麦当劳成为全球最大房地产持有者之一，并形成企业、房地产、纸资产三类资产互相连接的管道。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 准备创业，想知道除了“好点子”还需要哪些要素。
2. 公司已运行一段时间，但创始人离不开一线，想诊断缺少哪个系统要素。
3. 提到“B-I 三角形”或“企业八要素”，需要展开解释与应用。

### 语言信号 (用户的话里出现这些就应激活)

- “我要创业，需要准备哪些关键要素？”
- “B-I 三角形 / BI triangle / 企业八要素 / 使命团队领导力产品法律系统沟通现金流”
- “为什么我的公司离不开我？”

### 与相邻 skill 的区分

- 与 `startup-ten-lessons` 的区别：创业十堂课更侧重“创业前的心态、目标与准备清单”；B-I 三角形更侧重“企业持续运转所需的八要素结构”。
- 与 `opm-opt-leverage` 的区别：后者解决“资源放大”问题；B-I 三角形解决“企业架构完整性”问题。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **画出用户的 B-I 三角形**
   - 完成标准: 让用户为使命、团队、领导力、产品、法律、系统、沟通、现金流八项分别打分或描述现状。

2. **识别最危险的缺口**
   - 完成标准: 找出 1–3 个“若缺失则企业会停摆或无法扩张”的要素，并解释其连锁影响。
   - 判停条件: 若用户尚未启动任何创业动作，则把重点放在“使命验证”和“最小可行团队”上。

3. **制定 90 天补全计划**
   - 完成标准: 针对每个缺口给出 1 个具体动作、1 位需要引入的角色/资源、1 个可验收的里程碑。

4. **验证现金流与可复制性**
   - 完成标准: 确认企业能在创始人不亲自到场的情况下产生现金流；若不能，说明仍停留在 S 型，需要补系统。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只是想选择一份更好的工作或在公司内部晋升——应使用 `cashflow-quadrant` 做职业定位。
- 用户完全没有创业意图，只是问“我适合做什么生意”——应先讨论 ESBI 象限与个人能力圈，而非直接给八要素。

### 作者在书中警告的失败模式

- **把 S 型企业当 B 型企业**：以为创业就是自由职业或小作坊，没有建立可复制系统，结果“没有我就不转”。
- **只盯着产品**：许多人失败不是因为产品不好，而是因为缺法律、系统、现金流和团队。

### 作者的盲点 / 时代局限

- 清崎的 B-I 三角形形成于 20 世纪 90 年代至 2000 年代，对平台经济、SaaS、远程团队、AI 辅助创业等新形态覆盖不足。
- 八要素看似简单，但每一要素都需要大量专业知识；本框架不能替代律师、会计师、HR 和系统工程师的具体工作。

### 容易混淆的邻近方法论

- `cashflow-quadrant` 用 E/S/B/I 区分人的收入来源；`bi-triangle` 用八要素区分企业的内部结构。两者可组合：B 型企业通常拥有完整的 B-I 三角形。
