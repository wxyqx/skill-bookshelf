# 先支付自己

## R — 原文 (Reading)

> 在支付他人之前先支付自己，即先将钱分配给自己的资产项。从你的每份工资或每份其他来源的收入中拿出一个固定份额，存入投资储蓄账户。一旦存入，就永远不要取出，直到准备用它投资为止。
>
> — 罗伯特·T·清崎，《富爸爸穷爸爸》第八章 / 《富爸爸财务自由之路》第12章

---

## I — 方法论骨架 (Interpretation)

传统做法是“收入 − 支出 = 储蓄”，花剩了才存；清崎把它反过来：**收入 − 投资/储蓄 = 支出**。核心是“先支付自己”：
1. 收入一到账，先把固定份额转入资产项（投资账户、应急储备、教育基金等）。
2. 用剩余资金支付账单和消费。
3. 如果剩余不够，优先削减支出或增加收入，而不是挪用投资份额。

它不是简单存钱，而是把“买入资产”作为每月第一笔支出，强迫资产项优先增长。

## A1 — 书中的应用 (Past Application)

### 案例 1: 三个小猪存钱罐
- **问题**: 富爸爸如何从小培养孩子的财富纪律。
- **方法论的使用**: 让罗伯特用三个存钱罐分别放储蓄、投资和慈善/什一税；每次有收入先按比例放入罐子，再支付其他。
- **结论**: 把抽象原则变成孩子可操作的日常习惯。
- **结果**: 罗伯特养成先投资储蓄再消费的习惯，成年后仍沿用。

### 案例 2: 控制现金流：自动化先支付自己
- **问题**: 许多人存不下钱是因为习惯先花后存。
- **方法论的使用**: 从每份工资中自动转出固定份额到“投资储蓄账户”，这笔钱只在投资时使用，绝不用于消费。
- **结论**: 自动化让纪律不依赖意志力。
- **结果**: 逐步积累资本，用于购买产生现金流的资产。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 工资到账不到两周就花光，想建立储蓄或投资习惯但做不到。
2. 想每月自动存一笔钱，但不知道该先还信用卡还是先投资。
3. 家庭有固定开销，想挤出第一桶金买资产但总觉得没余钱。

### 语言信号 (用户的话里出现这些就应激活)

- "先支付自己怎么操作"
- "工资到账应该先存钱还是先还账"
- "月光族怎么开始投资"
- "我想自动转账存一笔钱"
- "怎么让储蓄变成第一优先级"

### 与相邻 skill 的区分

- 与 `rat-race-detector` 的区别: 老鼠赛跑诊断无资产循环；先支付自己是打破循环的具体现金流纪律动作。
- 与 `asset-liability-filter` 的区别: 资产/负债区分法判断钱花出去买的是资产还是负债；先支付自己关注“何时把资金优先拨给资产项”。
- 与 `mind-your-own-business` 的区别: 关注自己的事业强调把精力投向资产项；先支付自己强调把现金优先拨给资产项。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确定支付比例**
   - 完成标准: 根据用户收入和刚性支出，建议一个固定比例（如5%-20%），优先确保可持续而不是完美。

2. **设立隔离账户**
   - 完成标准: 建议开设独立“投资储蓄账户”，与日常消费账户物理隔离，减少挪用冲动。

3. **设置自动化转账**
   - 完成标准: 工资到账当日或次日自动转出固定比例到投资账户，做到“看不见、花不掉”。
   - 判停条件: 若用户有高额不良债务（如信用卡循环利息），需先协调“先支付自己”与“消灭不良债务”的优先级。

4. **明确资金用途**
   - 完成标准: 账户里的钱只用于买入能产生现金流的资产，不用于消费、旅游或应急（应急需另设基金）。

5. **压缩剩余支出**
   - 完成标准: 如果支付自己后账单不够付，优先削减可变支出或寻找增加收入的方法，而不是降低投资比例。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已经陷入债务危机、基本生活难以保障——应优先处理生存和债务重组。
- 用户在问企业现金流如何分配——这是企业财务问题，不是个人“先支付自己”。
- 用户在问具体买哪只股票/基金——这是投资选择问题。

### 作者在书中警告的失败模式

- 储蓄是失败者所为：只存钱不投资，购买力会被通胀侵蚀（rd01、rd24）。
- 购买消费品和不良债务：把奖金用于车房消费，无法形成资本（rd07）。
- 把信用卡当现金流：刷卡消费并只还最低额，债务雪球越滚越大（rd25）。
- 光想不干：学习很多理财知识但从未建立自动化投资机制（rd20）。

### 作者的盲点 / 时代局限

- 忽视生存线：对月光或负债人群，先支付自己可能导致逾期、罚息和心理崩溃。
- 利率环境变化：在零利率甚至负利率时代，储蓄账户收益极低，需要更快转入资产。
- 对低收入群体不够友好：固定比例储蓄对收入波动大的零工经济从业者挑战更大。

### 容易混淆的邻近方法论

- 50/30/20预算法：那是支出分类比例；先支付自己是把投资置于消费之前的反向预算。
- 极简主义/节俭：节俭关注少花钱；先支付自己关注把钱优先投向资产。
- 普通定投：定投是投资执行方式；先支付自己是建立自动拨款的纪律框架。
