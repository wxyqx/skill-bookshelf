# 现金流象限（ESBI）

## R — 原文 (Reading)

> E代表雇员，S代表自由职业者或小企业主，B代表企业主，I代表投资人。我们每个人都至少位于现金流象限图4个象限中的一个。雇员和自由职业者都位于左侧，那些从自己的企业或投资中获得现金流的人则位于右侧。在现金流象限中，处于右侧的这两种人拥有财务自由。
>
> — 罗伯特·T·清崎，《富爸爸财务自由之路》

---

## I — 方法论骨架 (Interpretation)

现金流象限不是职业分类，而是按“钱从哪里来”和“思维方式”把人分成四类：
1. **E（雇员）**：为别人工作，用时间换工资，追求稳定与保障。
2. **S（自由职业者/小业主）**：为自己工作，收入依赖个人技能与时间，典型如医生、律师、个体户。
3. **B（企业主）**：拥有可复制系统，让别人和钱为自己工作，自己可离开企业。
4. **I（投资者）**：让钱生钱，以资本和资产现金流为收入来源。

左侧（E/S）靠劳动收入，税负高、自由度低；右侧（B/I）靠被动/资本收入，可利用系统、税法与杠杆。财务自由的核心是从左侧迁往右侧，而非单纯提高工资。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1985年无家可归，仍拒绝回到E象限
- **问题**: 罗伯特和尼龙钱包生意失败后失业、破产、无家可归。
- **方法论的使用**: 他们没有回到“安全”的雇员工作，而是坚持迁往B/I象限，把危机视为迁移的代价。
- **结论**: 从E/S迁往B/I需要承受短期痛苦，换取长期系统与资本收入。
- **结果**: 最终建立富爸爸公司，实现财务自由。

### 案例 2: 麦当劳——做房地产而非汉堡
- **问题**: 如何把单一快餐生意变成可持续财富机器。
- **方法论的使用**: 雷·克罗克把汉堡店当作现金流入口，真正的核心资产是十字路口的房地产；再借助股市放大。
- **结论**: B型企业通过可复制系统+多类资产组合，实现脱离创始人的持续收益。
- **结果**: 麦当劳成为全球最大房地产持有者之一。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在考虑职业转型或副业方向，不确定该做雇员、自由职业、创业还是投资。
2. 发现工资涨了但税和支出同步上涨，想知道为什么高收入没带来自由。
3. 讨论“创业”时，其实只是把S型工作做得更辛苦，想区分S型与B型企业。

### 语言信号 (用户的话里出现这些就应激活)

- "我在哪个现金流象限"
- "工资越高税越多，是不是该创业/投资"
- "自由职业和真正的企业家有什么区别"
- "我不想一辈子为钱工作"

### 与相邻 skill 的区分

- 与 `asset-liability-filter` 的区别: 资产/负债区分法判断“一笔钱是资产还是负债”；ESBI判断“一个人/企业的收入模式和象限位置”。
- 与 `rat-race-detector` 的区别: 老鼠赛跑识别是否陷入“恐惧-贪婪-加薪-增支”循环；ESBI给出循环背后的象限结构解释。
- 与 `good-debt-bad-debt` 的区别: 债务框架判断杠杆好坏；ESBI判断收入性质与象限迁移路径。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位当前象限**
   - 完成标准: 列出用户当前主要收入来源（工资/服务费/企业利润/投资回报），并判断属于E/S/B/I。
   - 判停条件: 若用户主要收入来自2个以上象限，分别标注占比。

2. **诊断左侧/右侧特征**
   - 完成标准: 询问用户是否满足B/I象限的关键特征（可复制系统/资产现金流/他人与钱为自己工作）。
   - 判停条件: 若用户只是高收入的E/S，提示“高收入≠右侧象限”。

3. **给出迁移路径建议**
   - 完成标准: 基于用户当前象限，建议下一步迁移动作（E→边工作边建资产；S→建立系统脱离亲力亲为；B/I→持续买入资产）。

4. **澄清常见误解**
   - 完成标准: 明确区分“S型高收入专业人士”与“B型企业主”，并指出左侧迁往右侧需要思维、语言、朋友圈的转变。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已经明确在具体问“这套房算不算资产”——应转 `asset-liability-filter`。
- 用户只想讨论信用卡还款或月度预算——应转 `pay-yourself-first` 或一般记账建议。
- 用户在问某笔债务该不该借——应转 `good-debt-bad-debt`。

### 作者在书中警告的失败模式

- 把S型企业当B型企业：以为自己创业就自由，实际只是换了一份更累的工作（rd21、rd22）。
- 盲目追求高学历和高薪雇员工作：进入税负最高的E/S象限却以为安全（rd05、rd33）。
- 把工作安全感等同于财务安全：忽视收入来源单一化风险（rd08、rd13）。

### 作者的盲点 / 时代局限

- 美国中心主义：税法、401(k)、公司结构等案例基于美国背景，对中国读者需本地化。
- 可复制性被高估：清崎本人成功依赖个人品牌和时代红利，普通人迁移B/I需要更长时间和更多试错。
- 忽视结构性约束：起点资本、家庭资源、地域差异等被“选择象限”叙事过度淡化。

### 容易混淆的邻近方法论

- 职业兴趣测评（霍兰德等）：ESBI不关注兴趣，只关注收入来源与系统可复制性。
- 单纯“副业/斜杠”建议：ESBI区分“多做一份S型兼职”与“建立B/I型资产”。
- 工资谈判/升职加薪：ESBI认为单纯加薪仍在左侧象限，不改变财务结构。
