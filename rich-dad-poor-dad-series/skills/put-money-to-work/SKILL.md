# 给你的钱找一份工作

## R — 原文 (Reading)

> 财商不是你能赚多少钱，而是你能保有多少钱，知道怎样让钱为你工作，你能为后代留下多少钱。
>
> — 罗伯特·T·清崎，《富爸爸给你的钱找一份工作》· 第一章

---

## I — 方法论骨架 (Interpretation)

“给你的钱找一份工作”意味着把每一笔资本都视为可以创造现金流的劳动力：

1. **不养闲钱**：现金长期闲置会被通胀和税收侵蚀，必须给它分配明确的任务。
2. **按现金流招聘**：每项投资都要说明它承担什么工作——租金现金流、股息现金流、版税、资本增值还是税务盾牌。
3. **关注周转速度**：钱不能只“长期持有”，而要不断产生可再投资的现金流，形成复利。
4. **从储蓄者思维转向强势投资者思维**：先学习做更好的投资者，再让好交易来找你。
5. **用资产现金流购买奢侈品**：只有当钱已经替你工作后，才用增值或现金流去消费。

## A1 — 书中的应用 (Past Application)

### 案例 1: 凤凰城教育基金房产——7900 美元首付变月现金流 3000 美元
- **问题**: 罗伯特的同学每月为 4 个孩子存 300 美元教育基金，担心大学费用不足。
- **方法论的使用**: 他建议用部分教育基金在凤凰城萧条期买入一处三室两卫房产，让钱去“工作”而不是继续低息储蓄。
- **结论**: 把教育基金从储蓄账户转移到能产生现金流的出租资产，是让钱找工作的典型做法。
- **结果**: 首付仅 7900 美元，几年后该房产每月产生 3000 美元现金流，大学费用压力大幅缓解。

### 案例 2: 16% 收益的税收留置权投资
- **问题**: 罗伯特希望为闲置资金找到高于银行存款的稳定回报。
- **方法论的使用**: 他在书店发现高收益税收留置权投资方法，一周内读完书并到税务办公室请教实际操作者，第二天找到两笔交易。
- **结论**: 让钱工作的关键是：寻找新思想 + 向做过的人学习 + 快速行动。
- **结果**: 每年获得 16% 稳定利息收益，远高于当时银行存款利率。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手头有一笔闲钱，不知道投向哪里才能产生持续回报。
2. 感叹“钱躺在银行贬值”，想让钱替自己工作。
3. 看到“给你的钱找一份工作”这一说法，希望理解并落地。

### 语言信号 (用户的话里出现这些就应激活)

- “我手头有 X 万闲钱，该怎么投？”
- “让钱为我工作 / put your money to work / 给你的钱找一份工作”
- “钱放在银行就是贬值，想提高资金效率。”

### 与相邻 skill 的区分

- 与 `asset-liability-filter` 的区别：后者帮你判断“这笔支出是资产还是负债”；本 skill 帮你决定“已有资本该派往哪个工作岗位”。
- 与 `real-estate-cashflow` / `four-pillars-investing` 的区别：后两者是具体资产类别的分析工具；本 skill 是资本配置的整体视角。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点所有“待业”资金**
   - 完成标准: 列出用户手中现金、货币基金、低息存款、可变现资产及其当前年化回报。

2. **为每笔资金定义“工作岗位”**
   - 完成标准: 明确每笔钱应承担的任务：现金流产出、税务优化、保值、成长、流动性备用。

3. **筛选匹配的现金流资产**
   - 完成标准: 根据用户能力圈和时间精力，列出 2–3 类可选资产（出租房产、股息股票、期权策略、小型企业等），并给出每类的预期现金流特征。
   - 判停条件: 若用户尚未具备任何投资基础知识，则先推荐财商学习资源，暂缓配置建议。

4. **设定再投资规则**
   - 完成标准: 明确每笔资产产生的现金流如何再投资，以及何时把“工作成果”用于消费或提取。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只想做月度预算或还消费贷——应先解决现金流纪律问题，而非投资配置。
- 用户追求保本储蓄、完全不能承受波动——本 skill 强调资产与现金流，可能不适合风险厌恶者。

### 作者在书中警告的失败模式

- **把推销说辞当理财教育**：把“长期投资、购买、持有、多样化”当成真理，结果资金被高费用产品低效配置。
- **光想不干**：读了很多书、上了很多课，却从未让钱真正进入资产。

### 作者的盲点 / 时代局限

- 清崎活跃于 20 世纪 90 年代至 2000 年代，对被动指数投资、REITs、加密货币、去中心化金融等现代工具讨论有限。
- 他强调主动投资和控制，但实证研究显示，扣除费用后多数主动投资者长期跑输被动指数；用户需结合自身能力圈谨慎选择。

### 容易混淆的邻近方法论

- `pay-yourself-first` 强调“收入到账先投资再支出”，是现金流纪律；`put-money-to-work` 强调“已投资本必须持续产出现金流”，是资本效率。
