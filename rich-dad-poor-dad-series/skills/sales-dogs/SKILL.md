# 销售沟通与销售狗模型

## R — 原文 (Reading)

> “要不断提高你的销售能力和沟通能力，如果你能用自己的技巧来帮助他人，那么你的生活也将得到改善。”
>
> — 罗伯特·T·清崎，《富爸爸销售狗》· 前言

---

## I — 方法论骨架 (Interpretation)

1. 销售=收入，是企业主和投资者必须修炼的核心沟通能力。
2. 用五种“销售狗”类型识别自己和他人的销售风格：比特犬（强势进攻型）、金毛猎犬（关系型）、狮子狗（表演型）、吉娃娃（专业数据型）、杂种狗（综合型）。
3. 没有最好的品种，只有放错位置的狗；要根据客户类型匹配销售风格。
4. 短板不致命，但要刻意练习或组建互补团队。
5. 把被拒绝视为狩猎训练的一部分，用信念和“蹭蹭”策略管理情绪。
6. 最终目标是成为“超级混种狗”：能根据不同情境调用不同风格。

## A1 — 书中的应用 (Past Application)

### 案例 1：施乐销售培训——从最差销售员到分公司前五
- **问题**：罗伯特性格腼腆、害怕被拒绝，但富爸爸建议他去做销售以学会“被拒绝”。
- **方法论的使用**：他选择施乐公司接受专业销售培训，头两年业绩最差，差点被解雇；后两年成为分公司前五。
- **结论**：销售能力是企业主和投资者的核心技能，克服恐惧本身就是资产。
- **结果**：获得顶级销售技能与自信，为日后创业和融资打下基础。

### 案例 2：高中老师“你们将一事无成”的反向激励
- **问题**：高中指导老师当众说罗伯特和迈克“一事无成”，班里好学生也在窃笑。
- **方法论的使用**：这句话深深伤害了他们，但也成为最大的恩惠，激励他们完成学业并建立自己的事业。
- **结论**：外界的负面评价可以转化为“把失望变成资产”的动力，关键在于如何应对。
- **结果**：两人后来成为企业家和投资者，老师的话反而成为长期驱动力。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 个人创业者/自由职业者害怕被拒绝，不敢主动销售。
2. 组建销售团队时不知道如何分配客户类型与风格。
3. 销售转化率低，想识别自己的销售人格并补短板。

### 语言信号 (用户的话里出现这些就应激活)

- “我害怕被拒绝，怎么做销售”
- “销售狗 / sales dogs / 我是什么类型的销售”
- “我的销售团队应该怎么搭配”

### 与相邻 skill 的区分

- 与 `bi-triangle` 的区别：销售狗只处理B-I三角形中“沟通/销售”这一要素，不诊断企业整体八要素。
- 与 `startup-ten-lessons` 的区别：销售狗聚焦销售技能与团队组建，不是创业前的系统准备。

---

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **自评销售狗类型**
   - 完成标准：写出主要类型和1个最需补齐的短板。

2. **客户类型匹配**
   - 完成标准：把现有/潜在客户按决策风格分类，并为每类指定最适合的销售狗风格。

3. **短板训练计划**
   - 完成标准：针对弱项选择3种刻意练习动作，并列出每周练习频次。

4. **组建互补狗窝**
   - 完成标准：评估团队成员风格覆盖度，识别缺哪种风格，制定招聘或协作方案。

5. **被拒情绪管理**
   - 完成标准：建立“拒绝=筛选客户”的反馈循环，连续记录10次被拒并提炼1个改进模式。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 产品/商业模式本身有问题、或现金流断裂危机时，不要指望销售技巧救命；先修产品/现金流。
- 纯粹谈判技巧、商务礼仪培训等不属于销售狗模型范畴。

### 作者在书中警告的失败模式

- **用情绪代替思考**：一焦虑就强行推销或一被拒就放弃（rd18）。
- **光想不干**：只学习销售理论，不实际接触客户（rd20）。
- **害怕犯错而不行动**：因害怕说错话而从不主动报价（rd19）。
- **听推销员和共同基金建议**：把销售话术当理财教育（rd10）。

### 作者的盲点 / 时代局限

- “狗”的类比具有文化特定性，跨文化团队可能需要本地化解释。
- 模型更偏向B2C/直销场景，复杂的B2B企业销售需结合其他方法论。
- 对线上销售、AI辅助销售、社交媒体转化等现代场景覆盖不足。

### 容易混淆的邻近方法论

- `bi-triangle`：沟通只是八要素之一。
- `startup-ten-lessons`：创业前的整体准备。
- `code-of-honor`：团队文化契约，不是销售人格模型。
