# 良性债务 vs 不良债务

## R — 原文 (Reading)

> 良性债务就是由别人替你支付的债务，不良债务就是你用自己的血汗钱支付的债务。简单地说，良性债务就是每月往你口袋里放钱的债务，不良债务就是每月从你口袋里掏钱的债务。
>
> — 罗伯特·T·清崎，《富爸爸财务自由之路》第12章

---

## I — 方法论骨架 (Interpretation)

清崎不以“是否有抵押”或“利率高低”区分债务，而是看债务带来的现金流方向：
- **良性债务**：借钱买入能持续产生正现金流的资产，且资产现金流能覆盖本息；如出租房贷款、企业扩张贷款、资本设备融资等。
- **不良债务**：借钱消费或买入自耗品，最终由自己的劳动收入偿还；如信用卡分期、消费贷、自住房贷（作者视角）、车贷等。
- **债务是杠杆**：良性债务放大收益，不良债务放大负担。没有财商教育就使用债务，如同把枪交给醉汉。

判断三步：借来的钱买什么？它每月给我钱还是向我要钱？它的现金流能否稳定覆盖债务成本？

## A1 — 书中的应用 (Past Application)

### 案例 1: 用信用卡首付购买毛伊岛公寓
- **问题**: 罗伯特发现一处1.8万美元的无抵押品赎回权公寓，想投资但资金有限。
- **方法论的使用**: 用信用卡支付10%首付，完成第一笔100%使用他人资金（OPM）的房地产投资。
- **结论**: 当资产产生正现金流时，借钱可以致富。
- **结果**: 每月获得约25美元正现金流，验证了良性债务的可行性。

### 案例 2: 凤凰城教育基金房产
- **问题**: 罗伯特的同学每月存300美元教育基金，担心4个孩子上大学费用不足。
- **方法论的使用**: 建议用部分基金在凤凰城萧条期买入三室两卫房产，利用租金现金流和杠杆。
- **结论**: 用能产生现金流的资产债务替代单纯储蓄。
- **结果**: 首付7900美元的房产几年后每月产生3000美元现金流，教育费用压力大幅缓解。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 考虑贷款买房、买车、装修，想知道这是不是良性债务。
2. 想用信用卡或消费贷投资，不确定是否合适。
3. 已经背负房贷、车贷、信用卡债，想分清哪些应先还、哪些可保留。

### 语言信号 (用户的话里出现这些就应激活)

- "良性债务和不良债务怎么区分"
- "借钱投资是傻还是聪明"
- "房贷/车贷是好债务吗"
- "信用卡分期算不算不良债务"
- "我能不能用消费贷买房"

### 与相邻 skill 的区分

- 与 `asset-liability-filter` 的区别: 资产/负债框架判断“买来的东西”是否产生现金流；债务框架判断“借钱本身”是否由资产现金流偿还。
- 与 `cashflow-quadrant` 的区别: ESBI判断收入象限；债务框架关注右侧象限如何利用杠杆。
- 与 `rat-race-detector` 的区别: 老鼠赛跑诊断无资产循环；债务框架解释债务在循环中扮演的角色。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确债务用途**
   - 完成标准: 让用户说明借来的钱将用于买什么（消费、自住房、出租房、企业、教育等）。

2. **判断现金流方向**
   - 完成标准: 问“这笔钱买来的东西每月给你钱还是向你要钱？能否覆盖债务本息？”
   - 判停条件: 若用于消费或自耗品，直接判定为不良债务。

3. **评估风险覆盖能力**
   - 完成标准: 即使现金流为正，也要问空置、利率上升、市场下跌、收入中断等风险下是否仍能覆盖。

4. **给出处理优先级**
   - 完成标准: 不良债务优先尽快还清；良性债务在风险可控前提下可保留并继续放大杠杆。

5. **提醒财商门槛**
   - 完成标准: 强调没有财商和现金流分析的债务是危险的，不建议新手过度杠杆。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户在问某样东西是不是资产——应转 `asset-liability-filter`。
- 用户在问企业融资结构设计（股权/债权/可转债）——应转企业金融框架。
- 用户在表达负债导致的焦虑、失眠、家庭矛盾——应优先提供心理支持和债务重组建议。

### 作者在书中警告的失败模式

- 购买消费品和不良债务：把奖金用于车房消费，进一步增加负债（rd07）。
- 滥用信用卡和不良债务：用新卡还旧卡、刷卡度假，最终破产（rd25）。
- 学生贷款陷阱：为逃避就业继续深造，背上不可破产清除的贷款（rd26）。
- 剪信用卡却不改变行为：拒绝所有债务会错失良性杠杆，也不解决消费冲动（rd27）。
- 过度杠杆和滥用债务：在缺乏财商和现金流情况下过度借债，摧毁财务（rd35）。

### 作者的盲点 / 时代局限

- 低估下行周期风险：房地产和股票杠杆在危机中会迅速摧毁普通投资者。
- 美国税法背景：抵押贷款利息抵税、自住房规则等不适用于中国。
- 对“自住房=负债”的激进表述：忽略自住 Stability 和家庭生活的非财务价值。
- 对个人风险偏好差异关注不足：不是所有人都适合使用债务杠杆。

### 容易混淆的邻近方法论

- 信用评分/贷款比价：关注利率、期限、手续费；富爸爸更关注现金流方向。
- 债务雪球/雪崩法：那是还款策略；富爸爸先判断债务性质再决定还或留。
- 传统理财“房贷是好债务”：富爸爸认为若自住房不带来现金流，房贷就是不良债务。
