# BOOK_OVERVIEW — 曼昆《经济学原理》（微观经济学分册）（第8版）

> 阶段 0 产出：Adler 整书理解

## 一、书籍分类

- **类型**：教科书 / 入门教材
- **领域**：经济学 → 微观经济学
- **读者定位**：大学本科一年级经济学入门学生，及对经济学感兴趣的普通读者
- **写作风格**：案例驱动、少数学模型、重直觉与应用

> 原文引用：「本书强调得更多的是经济学原理的应用和政策分析，而不是正式的经济学模型。」——张维迎（推荐语）

## 二、整书统一性（Unity）

本书的核心命题：**用十大经济学原理搭建理解微观经济运行的完整框架，帮助读者像经济学家一样思考，从而理解市场如何运行、何时失灵、以及政策如何影响经济结果。**

全书以「供给与需求」为核心分析工具，以「效率与平等的权衡」为贯穿始终的政策视角，从个人决策 → 市场交易 → 市场结构 → 公共部门 → 劳动市场 → 前沿话题，层层递进。

## 四、作者要解决的核心问题

1. **如何让初学者理解经济学的思维方式？** — 用十大原理做脚手架，用案例代替模型
2. **市场为什么通常是组织经济活动的好方法？** — 用供需均衡与福利经济学证明「看不见的手」
3. **政府什么时候应该干预市场？** — 系统梳理市场失灵的类型（外部性、公共物品、垄断、信息不对称）
4. **效率与平等之间如何权衡？** — 全书反复出现的政策视角
5. **经济学原理如何应用于真实世界的政策讨论？** — 每个原理都配案例研究和新闻摘录

## 五、核心方法论特征

- **原理先行**：先给原理（Ch1），再逐步展开分析
- **供需为纲**：第 2 篇建立供需工具，后续所有章节都是供需工具的应用与扩展
- **案例驱动**：每章含「案例研究」「新闻摘录」「参考资料」等栏目
- **渐进深入**：从完全竞争（理想状态）→ 垄断/寡头（不完全竞争）→ 外部性/公共物品（市场失灵）→ 行为经济学（非理性）
- **政策导向**：几乎每章都讨论政策含义，而非纯理论
