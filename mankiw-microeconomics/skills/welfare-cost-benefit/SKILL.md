# 福利经济学与成本收益分析框架

> 来源：曼昆《经济学原理》Ch7-Ch8 — 消费者、生产者与市场效率 / 应用：税收的代价

---

## R：原理（Rationale）

### 核心思想
福利经济学研究**资源配置如何影响经济福利**。它提供了一套衡量市场结果「好坏」的标准——**总剩余最大化**（效率）。

### 三个核心概念

**1. 消费者剩余（Consumer Surplus）**
- 定义：买者愿意支付的最高价格 - 实际支付的价格
- 几何表示：需求曲线以下、价格以上的面积
- 含义：消费者从交易中获得的「净好处」

**2. 生产者剩余（Producer Surplus）**
- 定义：实际售价 - 生产者的成本
- 几何表示：供给曲线以上、价格以下的面积
- 含义：生产者从交易中获得的「净好处」

**3. 总剩余（Total Surplus）**
- 总剩余 = 消费者剩余 + 生产者剩余
- 总剩余 = 买者的支付意愿 - 卖者的生产成本
- **效率标准**：总剩余最大化的资源配置是有效率的

### 市场效率定理
在完全竞争、无外部性、完全信息、无交易成本的条件下：
> **市场均衡结果是有效率的——总剩余最大化。**

- 供给曲线代表边际生产者的成本
- 需求曲线代表边际消费者的支付意愿
- 均衡点：边际支付意愿 = 边际成本 → 总剩余最大
- 任何产量偏离均衡都会减少总剩余（无谓损失）

### 税收的福利效应
- 税收提高了买者支付的价格，降低了卖者得到的价格
- 税收减少了交易量，缩小了市场规模
- **无谓损失（Deadweight Loss, DWL）**：税收导致的总剩余减少
- DWL 的来源：阻止了买卖双方本可以互利的交易

> 原文引用：「税收的无谓损失源于它使买者少消费、卖者少生产，使市场规模缩小到总剩余最大化的水平以下。那些边际收益大于边际成本的交易没有发生。」

### 拉弗曲线
- 税率为 0 时：税收收入 = 0
- 税率为 100% 时：税收收入 = 0（没人愿意生产）
- 中间有一个税收收入最大值
- 含义：税率高到一定程度后，增税反而减少税收收入

## I：指令（Instruction）

### 福利分析五步法

#### 第一步：确定基准均衡
- 画出（或想象）供需图
- 标记均衡价格 P* 和均衡数量 Q*
- 识别初始状态的消费者剩余和生产者剩余

#### 第二步：识别政策/事件的影响
- 是移动供给曲线、需求曲线，还是直接插入一个「楔子」（税收）？
- 确定新的均衡点（或新的价格、数量）

#### 第三步：计算各方剩余变化

| 角色 | 变化方向 | 判断方法 |
|------|---------|---------|
| 消费者 | 价格上升 → 剩余减少；价格下降 → 剩余增加 | 需求曲线与新价格之间的面积变化 |
| 生产者 | 价格上升 → 剩余增加；价格下降 → 剩余减少 | 供给曲线与新价格之间的面积变化 |
| 政府 | 税收 → 获得税收收入；补贴 → 支出补贴 | 税率 × 税后数量 |

#### 第四步：计算无谓损失（DWL）
- DWL = 总剩余的减少量
- 几何表示：税收楔子与供需曲线之间的三角形面积
- 判断 DWL 大小：
  - 供需弹性越大 → DWL 越大
  - 税率越高 → DWL 越大（且递增，因为 DWL 与税率的平方近似成正比）

#### 第五步：综合评价
- 效率维度：总剩余减少了多少？DWL 有多大？
- 分配维度：谁受益？谁受损？
- 权衡：如果政策有其他目标（如平等、外部性纠正），DWL 是实现该目标的代价

### 成本-收益分析步骤（公共项目）

1. **列举所有成本和收益**（包括直接和间接）
2. **货币化**：将所有成本和收益转化为货币值
   - 难点：非市场物品（如生命、环境、时间）的价值估算
3. **贴现**：将未来的成本收益折算为现值
4. **比较**：总收益 > 总成本吗？
5. **敏感性分析**：关键假设变化时结果是否稳健

## A1：应用场景一 — 税收的福利分析

**场景**：政府对汽油征税，分析福利影响。

**分析过程**：

**第一步：基准均衡**
- 汽油市场的供需均衡：P*, Q*
- 消费者剩余 = 需求曲线以下、P*以上
- 生产者剩余 = 供给曲线以上、P*以下
- 总剩余 = CS + PS

**第二步：税收影响**
- 征税 T → 在买者价格 Pb 和卖者价格 Ps 之间打入一个「楔子」
- Pb - Ps = T
- 交易量从 Q* 减少到 Qt
- 弹性小的一方承担更多税负（汽油需求缺乏弹性，消费者承担更多）

**第三步：各方剩余变化**
- 消费者剩余：减少（因为支付价格上升 + 消费减少）
- 生产者剩余：减少（因为得到价格下降 + 销量减少）
- 政府：获得税收收入 = T × Qt

**第四步：无谓损失**
- DWL = 减少的交易量对应的总剩余
- 那些「支付意愿 > 生产成本」但因税收而没有发生的交易
- 汽油需求缺乏弹性 → DWL 相对较小（数量减少不多）
- 但汽油税同时纠正了外部性（拥堵、污染）→ 可能反而提高效率

**第五步：综合评价**
- 汽油税的 DWL 较小（因为需求缺乏弹性）
- 而且汽油消费有负外部性 → 汽油税是「双重红利」：既增加税收又纠正外部性
- 分配影响：低收入家庭汽油支出占收入比例更高 → 累退性
- 结论：从效率角度看，汽油税是「好税」；从平等角度看，需要配套再分配政策

## A2：应用场景二 — 公共项目成本收益分析

**场景**：是否应该建一座新桥？

**分析过程**：

**第一步：列举成本和收益**

| 成本 | 收益 |
|------|------|
| 建设成本（材料、人工） | 节省的时间（通勤时间减少） |
| 维护成本（每年） | 减少的交通事故 |
| 环境破坏（施工期） | 促进经济发展（交通便利带动商业） |
| 机会成本（资金用于其他项目） | 增加的土地价值 |

**第二步：货币化估算**
- 节省的时间：通勤时间 × 小时工资 × 通勤人数
- 减少的事故：每条生命价值 × 减少的事故数
  - 常用方法：研究高风险工作的工资溢价，或人们为安全支付的意愿
  - 典型估算：一条生命约几百万到一千万美元
- 建设成本：直接的工程预算

**第三步：贴现**
- 建设成本发生在现在，收益发生在未来几十年
- 需要用社会贴现率将未来收益折算为现值
- 贴现率越高，未来收益的现值越低

**第四步：比较**
- 净现值（NPV）= 总收益现值 - 总成本现值
- NPV > 0 → 项目有效率，应该建
- NPV < 0 → 项目无效率，不应该建

**第五步：敏感性分析**
- 如果交通流量增长低于预期，结果如何？
- 如果建设成本超支 20%，结果如何？
- 如果使用更低的贴现率，结果如何？
- 关键假设下 NPV 是否始终为正？

**难点与常见误区**：
1. **重复计算**：如「增加土地价值」和「节省时间」可能重复计算
2. **忽略机会成本**：资金用于这个项目就不能用于其他项目
3. **高估收益**：支持者往往高估收益、低估成本
4. **分配效应**：成本收益分析只看总效率，不看谁受益谁付费

## E：边界与反例（Edge Cases）

### E1：效率 ≠ 公平
- 福利经济学的效率标准只关心总剩余大小，不关心分配
- 一个有效率的结果可能极不平等
- 平等是否重要？重要到愿意牺牲多少效率？这是规范判断，不是经济学能回答的

### E2：支付意愿的局限
- 消费者剩余基于「支付意愿」，但支付意愿受收入影响
- 富人的支付意愿高，不是因为他们更需要，而是因为他们更有钱
- 因此，消费者剩余加总是否是合理的社会福利度量？存在争议

### E3：非市场物品的估值困难
- 生命、健康、环境、时间、名誉等没有市场价格
- 需要用间接方法估算（显示偏好、陈述偏好）
- 估算结果往往有争议、不确定性大

### E4：拉弗曲线的不确定性
- 理论上拉弗曲线是对的，但「我们处于曲线的哪一边」是实证问题
- 多数经济学家认为现实税率还没到下降段，但具体位置有争议
- 不能用「减税就能增税」作为普遍结论

### E5：税收的多重效应
- 福利分析通常只考虑税收的效率损失（DWL）
- 但税收也可能有正面作用：纠正外部性、提供公共物品、减少不平等
- 评价税收要看整体：DWL 是成本，税收带来的好处是收益

### E6：一般均衡效应
- 局部均衡分析只看一个市场
- 但税收/政策可能在其他市场产生连锁反应
- 例如：对汽油征税可能增加公共交通需求、减少拥堵
- 完整的福利分析需要考虑各市场的综合效应

## B：适用边界（Boundary）

### ✅ 适用场景
- 税收、补贴、价格管制等政策的效率评估
- 公共项目成本收益分析
- 市场干预的福利效应比较
- 谁受益谁受损的分配分析
- 不同政策方案的效率比较

### ⚠️ 谨慎使用
- 涉及大量非市场物品时（估值困难）
- 分配效应是主要关注点时（效率标准不完整）
- 存在重大外部性时（需先纠正外部性再评估）
- 长期动态效应显著时（技术进步、经济增长）

### ❌ 不适用场景
- 纯道德/价值判断（「应该不应该」的终极问题）
- 市场严重失灵且无法量化时
- 数据严重不足、关键参数只能靠猜测时
- 追求精确数字（定性方向判断更可靠）
