# 市场结构分析框架

> 来源：曼昆《经济学原理》Ch13-Ch17 — 生产成本 / 竞争市场上的企业 / 垄断 / 垄断竞争 / 寡头

---

## R：原理（Rationale）

### 核心思想
市场的**竞争程度**（企业数量、产品差异、进入壁垒）决定了企业的行为（定价、产量、创新）和市场结果（价格、效率、福利）。不同市场结构位于从「完全竞争」到「完全垄断」的连续谱上。

### 四种市场结构对比

| 特征 | 完全竞争 | 垄断竞争 | 寡头 | 垄断 |
|------|---------|---------|------|------|
| 企业数量 | 很多 | 很多 | 少数 | 一个 |
| 产品差异 | 同质（无差异） | 有差异 | 相似或有差异 | 唯一产品 |
| 进入壁垒 | 无（自由进入） | 无（自由进入） | 有 | 很高 |
| 定价权 | 无（价格接受者） | 有限 | 有（策略互动） | 强（价格制定者） |
| 长期利润 | 零经济利润 | 零经济利润 | 正利润可能 | 正利润 |
| 效率 | 最高（P=MC=ATC最低） | 有过剩生产能力 | 介于中间 | 最低（P>MC，DWL） |
| 典型行业 | 小麦、农产品 | 餐馆、服装店 | 汽车、航空 | 自来水、电力 |

### 成本结构基础

**关键成本概念**：
- **固定成本（FC）**：不随产量变动（租金、设备）
- **可变成本（VC）**：随产量变动（原材料、人工）
- **边际成本（MC）**：多生产一单位的成本增加
- **平均总成本（ATC）**：总成本 ÷ 产量 = AFC + AVC
- **有效规模**：ATC 最低时的产量
- **规模经济**：产量增加时 ATC 下降（高固定成本行业）
- **规模不经济**：产量增加时 ATC 上升（过大导致协调困难）

**企业决策核心原则**：
- 利润最大化产量：**MR = MC**（边际收益 = 边际成本）
- 短期停止营业：P < AVC（收入连可变成本都覆盖不了）
- 长期退出：P < ATC（收入连总成本都覆盖不了）
- 沉没成本：决策时应忽略（覆水难收）
> 原文引用：「生意冷清的餐馆和淡季的小型高尔夫球场——即使顾客稀少，只要收入能覆盖可变成本，就值得继续营业。」

### 博弈论与策略互动（寡头）

**囚徒困境**：
- 两个嫌疑人分别被审讯
- 都坦白 → 都判中等刑期
- 都沉默 → 都判轻刑（合作结果）
- 一方坦白一方沉默 → 坦白者释放，沉默者重判
- **占优策略**：坦白（无论对方选什么，自己坦白更好）
- **纳什均衡**：都坦白（各自最优，但集体不是最优）

**囚徒困境的普遍意义**：
- 军备竞赛、广告战、价格战、公共资源开采…
- 合作对双方都好，但个体有背叛的激励
- **重复博弈**中，合作可能通过「以牙还牙」等策略维持
> 原文引用：「囚徒困境的比赛——以牙还牙策略（第一回合合作，之后复制对方上一回合行为）在比赛中获胜。」

## I：指令（Instruction）

### 市场结构分析六步法

#### 第一步：识别市场结构
根据以下三个维度判断：

| 维度 | 判断问题 |
|------|---------|
| 企业数量 | 市场上有多少家企业？是几个、几十个、还是成百上千个？ |
| 产品差异 | 产品是同质的、有差异的，还是唯一的？ |
| 进入壁垒 | 新企业进入难不难？有什么壁垒？（法律、技术、规模经济、品牌） |

**快速判断**：
- 很多企业 + 同质产品 + 自由进入 → **完全竞争**
- 很多企业 + 差异产品 + 自由进入 → **垄断竞争**
- 少数企业 + 策略互动 + 进入壁垒 → **寡头**
- 一个企业 + 唯一产品 + 高进入壁垒 → **垄断**

#### 第二步：分析成本结构
- 固定成本 vs 可变成本的比例
- 边际成本是递增、递减还是不变？
- 是否存在规模经济？（固定成本高 → 规模经济 → 自然垄断倾向）
- ATC 的最低点在哪里？（有效规模）

#### 第三步：预测企业行为

**完全竞争企业**：
- 产量决策：P = MC
- 短期：P ≥ AVC 时生产，否则停业
- 长期：P = ATC 最低点（零经济利润）

**垄断企业**：
- 产量决策：MR = MC（MR < P）
- 价格：根据需求曲线，在最优产量上定价
- 价格歧视：如果能区分消费者，可以通过价格歧视增加利润、减少 DWL

**垄断竞争企业**：
- 短期：类似垄断（P > MC，有正利润）
- 长期：新企业进入 → 需求下降 → P = ATC（零经济利润），但 P > MC，且产量 < 有效规模（过剩生产能力）
- 非价格竞争：广告、品牌、产品差异化

**寡头企业**：
- 策略互动：我的决策影响对手，对手的决策影响我
- 合作结果（共谋）：像垄断一样定价，分享利润
- 非合作结果（纳什均衡）：产量高于垄断、价格低于垄断
- 博弈论分析：找出占优策略和纳什均衡

#### 第四步：评估市场结果
- **效率**：P = MC 吗？有无谓损失吗？
- **产量**：高于还是低于社会最优？
- **价格**：高于还是低于边际成本？
- **创新**：市场结构对创新的影响？（熊彼特假说：大企业更有创新动力）
- **消费者选择**：产品多样性如何？

#### 第五步：政策含义
- **完全竞争**：不需要干预（市场最优）
- **垄断**：反托拉斯法、价格管制、公有制、不作为（各有优劣）
- **寡头**：反托拉斯法禁止共谋，但要区分合谋和正常竞争
- **垄断竞争**：通常不需要干预（产品多样性是福利），但广告可能过度

#### 第六步：动态考虑
- 市场结构不是固定不变的
- 技术变化可能改变成本结构和进入壁垒
- 创新可能颠覆现有市场结构
- 「可竞争市场」理论：即使只有一家企业，如果进入自由，也可能接近竞争结果

## A1：应用场景一 — 行业分析（以航空业为例）

**场景**：分析航空业的市场结构和企业行为。

**分析过程**：

**第一步：市场结构？**
- 企业数量：少数几家大航空公司主导，但也有廉航
- 产品差异：基本服务相似（从 A 到 B），但有服务质量、时刻、品牌差异
- 进入壁垒：高（飞机贵、机场 slot 有限、航线审批、规模经济）
- **结论**：寡头市场（少数大企业，策略互动强）

**第二步：成本结构**
- 固定成本高（飞机、机组人员、地勤、机场费用）
- 边际成本低（多一个乘客的成本几乎只是一顿餐食和一点燃油）
- 规模经济明显（航线网络越大，单位成本越低）
- → ATC 随运量下降，有自然垄断倾向

**第三步：企业行为**
- **价格竞争激烈**：座位是「易腐」商品（起飞后空座就没用了）→ 有强烈降价动机
- **价格歧视严重**：同一航班票价差异巨大（提前购票、周末停留、舱位等级）
- **策略互动**：一家降价，其他家通常跟进；一家涨价，其他家不一定跟进
- **囚徒困境**：都不降价 → 都有高利润；都降价 → 都利润低；但每家都有偷偷降价的激励
- **结果**：价格战频繁，行业利润率低

**第四步：市场结果**
- 价格通常高于边际成本（有市场势力）
- 但长期利润不高（竞争激烈 + 高固定成本）
- 产品有一定差异（服务、时刻、常旅客计划）
- 消费者选择较多

**第五步：政策含义**
- 反托拉斯监管：防止航空公司合谋抬价
- 但也要注意：行业利润率低，过度竞争可能导致服务质量下降
- 机场 slot 分配是关键政策工具（影响进入壁垒）

## A2：应用场景二 — 企业定价策略（以垄断/垄断竞争为例）

**场景**：一家新开业的咖啡店，如何定价？

**分析过程**：

**第一步：市场结构？**
- 企业数量：咖啡店很多
- 产品差异：位置、口味、环境、服务都有差异
- 进入壁垒：低（租个店面、买设备就能开）
- **结论**：垄断竞争市场

**第二步：成本结构**
- 固定成本：租金、设备、装修
- 可变成本：咖啡豆、牛奶、杯子、人工（部分是半固定）
- 边际成本：一杯咖啡的原料成本（很低，约几元）
- 规模经济：有限（一家店的容量有限）

**第三步：定价策略**

**基础定价**：
- 找到 MR = MC 的产量 → 需求曲线上对应的价格
- 但因为是垄断竞争（有差异），P > MC
- 价格 = 成本 + 加成（加成大小取决于需求弹性）

**价格歧视（增加利润）**：

| 方式 | 原理 | 例子 |
|------|------|------|
| 数量折扣 | 量大价低（区分高需求和低需求顾客） | 第二杯半价、大杯更划算 |
| 优惠券/会员 | 对价格敏感的顾客提供折扣 | 集点卡、会员价 |
| 时段定价 | 不同时段需求弹性不同 | 早鸟优惠、下午茶套餐 |
| 产品版本 | 不同版本区分不同支付意愿 | 普通咖啡 vs 精品手冲 vs 特调 |

**非价格竞争**：
- 产品差异化：独特口味、特色饮品
- 环境：装修风格、座位舒适度
- 服务：速度、态度
- 品牌：故事、文化、社区感

**第四步：长期均衡**
- 短期如果有正利润 → 新咖啡店进入 → 每家需求减少 → 利润下降
- 长期均衡：P = ATC（零经济利润），但 P > MC
- 过剩生产能力：店内座位经常坐不满
- 持续的进入退出：咖啡店开了又关、关了又开

## E：边界与反例（Edge Cases）

### E1：市场定义的重要性
- 市场结构的判断取决于如何定义市场
- 例如：可口可乐在「可乐市场」是双寡头（与百事），在「饮料市场」是垄断竞争，在「饮品市场」接近完全竞争
- 市场定义越窄，市场势力越强

### E2：零利润 ≠ 零收入
- 完全竞争和垄断竞争的长期零经济利润，是指经济利润为零
- 会计利润仍然为正（包含了所有者的机会成本）
- 企业获得的是正常收益率，不是赚不到钱
> 原文引用：「如果竞争企业利润为零，为什么它们要留在市场上？——因为零经济利润意味着收益覆盖了所有机会成本，包括所有者的时间和资本的正常回报。」

### E3：沉没成本谬误
- 人们在决策时常常考虑沉没成本（「已经投入了这么多，不能放弃」）
- 正确做法：只考虑边际成本和边际收益
- 案例：「生意冷清的餐馆仍开门」「淡季的高尔夫球场仍营业」
- 生活中的例子：看了一半的烂电影要不要看完？

### E4：囚徒困境不一定是坏事
- 囚徒困境对参与者是坏事（合作失败）
- 但对社会可能是好事
- 例如：寡头之间的价格战 → 对企业不利，对消费者有利（价格更低）
- 例如：军备竞赛 → 对两国都不好，但可能维持平衡

### E5：反托拉斯的争议
- 什么是「反竞争行为」？什么是「正当竞争」？
- 低价可能是掠夺性定价（反竞争），也可能是正常竞争
- 捆绑销售可能是垄断势力延伸，也可能是提高效率
- 反托拉斯政策执行中充满争议

### E6：可竞争市场
- 即使市场上只有一家企业，如果进入壁垒低、退出无成本，潜在进入的威胁就会约束企业行为
- 「打了就跑」的进入策略使垄断者不敢定高价
- 含义：市场结构不是唯一重要的，进入条件也很重要

### E7：网络效应与平台市场
- 传统市场结构分析假设产品价值独立
- 但平台市场（社交网络、操作系统、支付系统）有网络效应：用户越多价值越大
- 网络效应可能导致「赢者通吃」→ 自然垄断
- 传统的供需和市场结构分析需要调整

## B：适用边界（Boundary）

### ✅ 适用场景
- 行业竞争格局分析
- 企业定价策略制定
- 市场进入/退出决策
- 并购评估（反托拉斯视角）
- 行业利润率预测
- 政策（反托拉斯、管制）影响分析

### ⚠️ 谨慎使用
- 平台市场/网络效应行业 → 传统分析需要调整
- 快速变化的科技行业 → 市场结构不稳定
- 高度管制的行业（如金融、医疗）→ 政策比市场结构更重要
- 非营利组织/公共部门 → 目标不是利润最大化

### ❌ 不适用场景
- 完全计划经济（企业没有自主决策权）
- 以政治/权力为主要竞争方式的市场
- 初创企业早期（产品和市场都在变化）
- 纯艺术/创意产品（价值高度主观，供需模型不适用）
