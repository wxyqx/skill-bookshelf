## 诱饵测试详情

### L1：兄弟 Skill 混淆 — supply-demand-analysis
- **测试用例**：T4
- **输入**：「如果小麦丰收了，小麦价格会怎么变？农民收入会增加吗？」
- **预期**：should_not_call → 应调用 supply-demand-analysis
- **结果**：✅ 通过
- **分析**：小麦是完全竞争市场的典型例子，标准供需分析即可回答。市场结构分析的优势在于不完全竞争市场（垄断、寡头、垄断竞争），完全竞争不是其独特价值所在。

### L2：兄弟 Skill 混淆 — market-failure-diagnosis
- **测试用例**：T5
- **输入**：「垄断导致的效率损失有多大？怎么计算无谓损失？」
- **预期**：should_not_call → 应调用 welfare-cost-benefit
- **结果**：✅ 通过
- **分析**：用户问的是「损失多大」（量化计算），不是「市场结构是什么、企业怎么定价」。无谓损失计算是福利分析工具。

### L3：反向验证 — 价格歧视（边缘案例）
- **测试用例**：T7
- **输入**：「为什么商场里同一种衣服每家店价格不一样？」
- **预期**：should_call（这是价格歧视，属于市场结构分析）
- **结果**：✅ 通过
- **分析**：虽然用户没直接提「垄断」「市场结构」，但价格差异背后是市场势力和价格歧视，属于市场结构分析范畴。description 中提到「企业定价策略」可以覆盖此类场景。
