## 诱饵测试详情

### L1：兄弟 Skill 混淆 — supply-demand-analysis
- **测试用例**：T4
- **输入**：「如果进口关税降低，汽车价格会降多少？销量会怎么变？」
- **预期**：should_not_call → 应调用 supply-demand-analysis
- **结果**：✅ 通过
- **分析**：用户问的是价格和数量变化，不是分工决策。比较优势回答「谁该生产什么」，供需分析回答「价格数量怎么变」。

### L2：领域不匹配 — 股权分配
- **测试用例**：T5
- **输入**：「我和朋友合作开公司，股权应该怎么分？」
- **预期**：should_not_call
- **结果**：✅ 通过
- **分析**：股权分配涉及贡献评估、控制权、风险分担等，不是比较优势能解决的。比较优势是生产决策工具，不是利益分配工具。

### L3：兄弟 Skill 混淆 — welfare-cost-benefit
- **测试用例**：T7
- **输入**：「自由贸易对谁有利对谁不利？总福利是增加还是减少？」
- **预期**：should_not_call → 应调用 welfare-cost-benefit
- **结果**：✅ 通过
- **分析**：用户问的是福利分配和总剩余，不是分工模式。比较优势回答「该不该贸易」，福利分析回答「谁赢谁输」。
