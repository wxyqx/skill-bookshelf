- id: f01
  title: 钓鱼思维 (Bait-the-Fish Thinking)
  type: framework
  source_chapter: 第一篇 · 第三章
  source_quote: |
    "每一年夏天我都去梅恩钓鱼。我喜欢吃杨梅和奶油，可是水里的鱼爱吃小虫。
    所以我去钓鱼的时候，不想我所要的，而想牠们所需要的。"
  summary: |
    面对任何人时，先问"他想要什么"，然后把他想要的和你想要的连接起来。
    不是从自己的需求出发说服别人，而是从对方的需求出发设计"饵"。
    这是一个可迁移的说服起点：用在孩子身上（吸烟→不能参加棒球队）、
    用在客户身上、用在伴侣身上。关键不是"我要什么"而是"什么能让他行动"。
  tags: [persuasion, empathy, other-centered]

- id: f02
  title: Yes-Ladder 苏格拉底法
  type: framework
  source_chapter: 第三篇 · 第五章
  source_quote: |
    "跟人们谈话时，别开始就谈你们意见相左的事，不妨谈些彼此间赞同的事情。
    使对方在开始的时候，连连说'是！是！'，如果可能的话，尽量防止他说'不！'"
  summary: |
    说服不是一次性的信息传递，而是一系列"是"的阶梯。
    先找到双方都认同的共同点，让对方连续说"是"，建立合作基调，
    再逐步引入分歧点。心理学原理：一旦说了"不"，人格尊严要求坚持到底；
    一旦说了"是"，惯性会推动继续认同。这是一个对话节奏控制框架。
  tags: [persuasion, dialogue, momentum]

- id: f03
  title: 同理心转换公式
  type: framework
  source_chapter: 第三篇 · 第八章
  source_quote: |
    "为什么这个人有那样的思想和行动，一定有他的理由。我们探求出那个隐藏着的理由来，
    对他的行动、人格，就可以很清楚的了解了。你把自己处在他的情况下，你这样对自己说：
    '如果我处在他的困难中，我将有如何的感受，又作如何的反应？'"
  summary: |
    面对冲突或不可理解的行为时，暂停评判，先问"如果我是他，
    在他的处境下，我会怎么想、怎么做？"这不是道德要求，而是策略工具。
    它能解除对方的防御（因为你先理解了他），也能找到真正的解决方案
    （因为从对方视角看到了真实障碍）。卡耐基称之为"奇迹公式"。
  tags: [empathy, conflict-resolution, perspective-shift]

- id: f04
  title: 意见所有权转移
  type: framework
  source_chapter: 第三篇 · 第七章
  source_quote: |
    "你对你自己所发现的意念，是不是比别人代你说出的更信得过？
    如果提出意见，启发别人自己去得到他的结论，这不是一个更聪明的办法吗？"
  summary: |
    说服的最高境界不是让对方接受你的观点，而是让对方"自己想出"你的观点。
    方法：不直接给结论，而是提问题、给线索、创造环境，让对方自己推导。
    因为人对自己得出的结论有100%的信任，对被告知的结论有天然抵触。
    这是一个从"推"到"拉"的说服范式转换。
  tags: [persuasion, influence, ownership]

- id: f05
  title: 声誉锚定 (Reputation Anchoring)
  type: framework
  source_chapter: 第四篇 · 第七章
  source_quote: |
    "如果你要对某人改变看法，就请做出好像他已经是那样的。给狗取个好名字，
    不如给它一个坏名声。琴德太太说：'我相信你说的是没有根据的，妳穿的很整洁……
    我可以打赌，妳收拾房间，一定同你的人一样整洁干净。'"
  summary: |
    要改变一个人的行为，先公开赋予他一个正面的声誉/标签，他会自觉向该标签靠拢。
    心理学原理：人本能地维护自己被赋予的身份认同，即使这个身份是他还没达到的。
    与直接批评相反——批评锁定"你是坏的"，声誉锚定锁定"你是好的"。
    前提：标签必须可信且对方在乎这个身份。
  tags: [influence, identity, positive-framing]

- id: f06
  title: 批评三明治 (Praise-Criticism-Praise)
  type: framework
  source_chapter: 第四篇 · 第一章
  source_quote: |
    "柯立芝总统对女秘书说：'妳今天穿的衣服很漂亮，真是位年轻漂亮的女孩子。'
    接着又说：'别难为情，我刚才的话，是为使妳感到高兴；从现在起，
    我希望妳对公文的标点上，要稍微注意一点。'"
  summary: |
    改变他人行为的结构化反馈公式：先真诚赞美（打开心门）→指出问题
    （在开放状态下更容易接受）→给予鼓励（维持动力）。理发师用热毛巾
    在顾客脸上敷一下再刮胡子——先软化再行动。核心：批评前必须有真诚赞美铺垫，
    批评后必须有正面收尾，否则批评只会制造防御。
  tags: [feedback, criticism, communication]

- id: f07
  title: 挑战激励法
  type: framework
  source_chapter: 第三篇 · 第十二章
  source_quote: |
    "司华伯向工人问：'你们这一班，今天完成了几个单位？'那工人回答说：'六个。'
    司华伯听到这样，一字不说，在地上写了一个'6'字就走了。夜班工人看到，
    问是什么意思。日班工人说：'司华伯来过，问我们做了几个，我们说六个，他就在地上写了个6字。'
    第二天早晨，司华伯又来，夜班已做七个单位，他把6擦去，写了一个7。"
  summary: |
    当赞美、说服、批评都失效时，用好胜心作为最后的激励手段。
    方法：不直接命令"做更多"，而是创造一个可见的竞争情境（写数字在地上），
    让人自发地想要超越。心理学原理：人对"超越他人"的渴望比对"完成任务"的渴望更强。
    前提：对方有好胜心且情境允许良性竞争。
  tags: [motivation, competition, last-resort]

- id: f08
  title: 戏剧化呈现法
  type: framework
  source_chapter: 第三篇 · 第十一章
  source_quote: |
    "费城晚报将一天中各项阅读资料剪下，再加以分类编成一本书，书名就叫'一天'。
    这部书竟有三百零七页，和一本价值两元的书，页数差不多，而该报只售两分钱。"
  summary: |
    当事实和数字不足以说服人时，把它们转化为戏剧化、可视化的呈现。
    不是说"我们的新闻很多"，而是把一天的内容编成一本307页的书放在面前。
    适用于：提案、推销、说服、教学。核心：让信息从"被听到"变成"被体验"。
  tags: [communication, presentation, visualization]

- id: f09
  title: 认错先行术
  type: framework
  source_chapter: 第三篇 · 第三章
  source_quote: |
    "如果我在指出她的错误前，先说我自己的错误，那么她接受起来就容易多了。
    承认自己的错误，就算是你还没有改正，也有助于帮助另一个人改变他的行为。"
  summary: |
    在指出他人错误前，先承认自己的错误或不足，能立即解除对方的防御机制。
    心理学原理：当对方发现你也在"自我批评"，他的"被攻击感"消失，
    取而代之的是"同类感"。承认的必须是真实的错误，不是虚伪的自贬。
    在冲突中，谁先认错谁掌握主动权。
  tags: [conflict-resolution, humility, disarming]

- id: f10
  title: 倾听引导法
  type: framework
  source_chapter: 第三篇 · 第六章
  source_quote: |
    "很多人，当需人们赞同他的意见时，就是话说得太多了。你应该让对方尽量说出他的意见来。
    他对于自己的事，或是他的问题，当然要比任何人知道得多。所以你应该问他问题，
    让他来告诉你一些事。"
  summary: |
    说服不是"说更多"，而是"让对方说更多"。方法：提问→倾听→继续提问。
    让对方充分表达后，他往往自己会得出你希望他得出的结论。
    沉默本身就是说服工具——当对方说完所有想说的话，他才开始"听"。
    适用于：销售、调解、访谈、任何需要对方"打开"的场景。
  tags: [listening, persuasion, questioning]
