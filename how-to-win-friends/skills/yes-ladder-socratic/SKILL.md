# Yes-Ladder 苏格拉底法 (Yes-Ladder Socratic)

## R — 原文 (Reading)

> "跟人们谈话时，别开始就谈你们意见相左的事，不妨谈些彼此间赞同的事情。使对方在开始的时候，连连说'是！是！'，如果可能的话，尽量防止他说'不！'"
>
> — 戴尔·卡耐基, 第三篇·第五章

---

## I — 方法论骨架 (Interpretation)

Yes-Ladder 是一种对话节奏控制框架——通过让对方在对话初期连续说"是"，建立合作心理基调，再逐步引入分歧点。心理学依据：一旦说出"不"，人格尊严要求坚持到底，整个心理-神经系统都进入对抗状态；一旦说出"是"，惯性推动继续认同，心理姿态从防御转为开放。不是欺骗，而是先建立共识基础再讨论分歧——你确实认同那些"是"的点是真实的。这与苏格拉底的对话法一脉相承：从对方不得不承认的前提出发，通过连续提问让对方自己推导出结论。

## A1 — 书中的应用 (Past Application)

### 案例 1: 奥弗斯德教授的"不"字障碍理论
- **问题**: 为什么有些人一旦说了"不"，就再也无法说服？
- **方法论的使用**: 奥弗斯德教授指出，"不"字反应是最难克服的障碍。当一个人说出"不"后，他的人格尊严要求他坚持到底——不仅是对外坚持，内心的态度也会随之固化。相反，当一个人说"是"时，他的心理处于开放和接纳状态。
- **结论**: 说服的关键不是论证有多强，而是不让对方进入"不"的心理状态。一旦对方说了"不"，你面对的不再是事实问题，而是对方的自尊问题。
- **结果**: 这一理论成为销售和谈判的核心原则——开场的首要目标不是展示你的方案，而是让对方说"是"。

### 案例 2: 洛克菲勒对罢工工人——先承认共同点
- **问题**: 洛克菲勒面对科罗拉多燃料公司的罢工，工人对他极度敌视。如何开口？
- **方法论的使用**: 洛克菲勒没有先谈分歧（工资、条件），而是先说："这是我一生中最值得纪念的日子……我能和你们见面，参观你们的家庭，看到你们的妻儿……我们不是陌生人，而是朋友。"
- **结论**: 在最敌对的关系中，先找到共同点（"我们都是人，都有家庭"），让对方在心理上无法说"不"。一旦建立了"朋友"的基调，后续的实质性讨论就容易得多。
- **结果**: 罢工工人从敌对转为合作——洛克菲勒的演讲被视为劳资关系的经典案例。

### 案例 3: 赛尔滋让推销员自己说需求
- **问题**: 赛尔滋是汽车推销员，如何让客户接受他的建议而非被拒绝？
- **方法论的使用**: 赛尔滋不直接推销，而是先问一系列客户不得不说"是"的问题——"你需要一辆可靠的车吧？""你希望省油吧？""安全性对你很重要吧？"等客户连续说"是"后，再介绍符合这些需求的车型。
- **结论**: 让对方先说"是"，不是说你在操控他——那些"是"是真实的。你在建立真实共识的基础上引入你的方案，让方案看起来像共识的自然延伸。
- **结果**: 客户不觉得自己被推销，而觉得自己在选择——因为每一个"是"都是他自己说的。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 提出提案或方案，担心被直接拒绝，需要降低对方的心理防御。
2. 需要让团队或对方接受一个新想法、新流程或新规范。
3. 销售场景中需要引导客户逐步认同产品价值，而非一上来就推销。
4. 谈判中需要逐步推进，而非一步到位引发对方说"不"。
5. 想让团队采用新的代码审查流程，大家觉得太麻烦——需要用连续"是"降低阻力。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么让对方同意" / "how to persuade"
- "他肯定会说不" / "对方会拒绝"
- "苏格拉底法" / "yes ladder" / "让对方说yes"
- "得到同意" / "怎么说服"
- "他一听就反对" / "他总是说不"
- "怎么让他接受我的想法"

### 与相邻 skill 的区分

- 与 `listening-as-persuasion` 的区别: yes-ladder 是控制对话节奏（你主导提问让对方说"是"）；倾听引导是让对方充分表达（你主导沉默让对方说）。前者适合你已有明确方案需要推进时，后者适合你还不了解对方需求时。如果对方一开始就说"不"，应降级到倾听引导法。
- 与 `bait-the-fish-thinking` 的区别: yes-ladder 关注对话结构（先共识后分歧的节奏控制）；钓鱼思维关注说服内容（找到对方需求并设计满足路径）。两者可组合——用钓鱼思维确定说什么内容，用 yes-ladder 确定以什么节奏说。
- 与 `argument-avoidance` 的区别: 避免争辩是消极策略（不要直接对抗）；yes-ladder 是积极策略（用共识积累代替对抗）。避免争辩后，可用 yes-ladder 提供替代的说服路径。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **共识清单**
   - 列出双方都认同的 3-5 个事实或观点。
   - 关键动作: 这些共识必须是对方必然说"是"的——不是你认为他应该认同的，而是他实际上已经认同的。如"大家都希望减少线上bug吧？"比"你觉得代码审查重要吧？"更安全。
   - 完成标准: 每条共识都是对方必然会认可的事实或价值观，且与你最终要提出的方案有逻辑关联。
   - 判停条件: 如果列不出3个以上的真实共识，说明你对对方的立场了解不足——先用 `listening-as-persuasion` 收集信息。

2. **连续提问**
   - 从最无争议的点开始，逐个提问让对方说"是"。
   - 关键动作: 每个问题都是封闭式的、指向明确的认同。不要用开放式问题（可能引出"不"），而用"……对吧？""……是不是这样？"等引导确认的句式。一次只问一个问题，等对方说"是"后再问下一个。
   - 完成标准: 对方连续说了3个以上"是"，且你能感受到对话氛围从防御转为合作。
   - 判停条件: 如果对方在某个问题上说"不"或"不一定"，不要强行推进——转用 `listening-as-persuasion` 让对方解释为什么说不。

3. **桥接分歧**
   - 用"既然我们都认同X，那么关于Y……"引入分歧点。
   - 关键动作: 把分歧点包装成已建立共识的自然延伸，而非全新话题。如"既然我们都希望减少bug（共识），而提前发现问题是减少bug的关键（共识延伸），那么在提交阶段增加一道检查（分歧点）是不是值得考虑？"
   - 完成标准: 分歧点在共识基调下被提出，对方的防御心理已被前期的"是"惯性削弱。

4. **方案呈现**
   - 把你的方案与已建立的共识连接。
   - 关键动作: 方案不是"我的提议"，而是"我们刚才讨论的自然结论"。如"基于我们刚才达成的几点，我建议……"而非"我认为应该……"。
   - 完成标准: 方案看起来像共识的自然延伸，而非你单方面的要求。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **对方已有强烈反对立场时**: 如果对方已经明确说"不"或表达了强烈反对，yes-ladder 的前提已被打破。此时应先用 `listening-as-persuasion` 让对方充分表达，理解其反对的原因，再考虑是否重新启动 yes-ladder。
- **需要对方做出重大让步时**: yes-ladder 只适合渐进推进。如果需要对方在核心利益上做出重大让步（如大幅降价、改变战略方向），用话术节奏控制无法替代实质性利益谈判。
- **需要展示客观数据而非话术时**: 如果说服应基于事实和数据（如科学论证、法律辩论），不应话术包装。yes-ladder 适用于态度和方案的接受，不适用于事实真伪的判定。

### 作者在书中警告的失败模式

- **机械式"是"陷阱**: 如果对方察觉你在刻意设套让他连续说"是"，然后利用惯性推出他不同意的结论，信任会崩溃。yes-ladder 的前提是那些"是"必须是你也真实认同的——你是在建立真实共识，而非设置话术陷阱。
- **共识与分歧之间逻辑断裂**: 如果你的共识点和最终方案之间没有真实的逻辑连接，对方会在你说"那么"的时候意识到跳跃，前期的"是"全部白费。

### 作者的盲点 / 时代局限

- 未讨论"如果对方一开始就说'不'怎么办"——这是 yes-ladder 最常见的失败入口。卡耐基的案例都预设对方还没有明确立场，现实中对方往往已经有了。此时需要降级到 `listening-as-persuasion`。
- 1936 年的信息环境相对简单；现代信息过载中，人们更容易对"话术"保持警惕，yes-ladder 如果执行不自然，容易被识别为销售技巧而适得其反。

### 容易混淆的邻近方法论

- **与"倾听引导法"的区别**: yes-ladder 是你主导提问让对方说"是"（控制节奏）；倾听引导是你主导沉默让对方说（释放信息）。前者适合你已有方案需要推进，后者适合你还不了解对方。如果 yes-ladder 失败（对方说不），应降级到倾听引导。
- **与"钓鱼思维"的区别**: yes-ladder 是"怎么说"（对话节奏）；钓鱼思维是"说什么"（说服内容）。先钓鱼思维确定对方需求和说服内容，再 yes-ladder 设计对话节奏，组合效果最佳。
- **与"诱导性提问"的区别**: yes-ladder 的每个"是"必须是对方真实认同的；诱导性提问是通过误导让对方说出非本意的"是"。前者建立真实共识，后者是欺骗。
